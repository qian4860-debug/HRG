# A0–A3 的质量评估与后面该做什么

日期：2026-11-03
对象：`research/` 下 A0–A3 四个研究包（`f83d46b`…`bb622a9`）
判据：只问三件事——**证据站不站得住、对论文值多少、对芯片值多少**

---

## 1. 质量评估：先说结论

**工程执行质量：高。科学证据等级：中。对决策的可用性：高。**
它把"测量物理"这一层从零建到了能自证的程度，但**四条证据链都悬在同一套合成二阶模型上，且没有一条进入闭环**。

### 1.1 做得好的三点

| 点 | 证据 |
|---|---|
| **证据结构完整** | 每个包都是 `generate → fit → score → independent_check → dashboard → manifest 哈希`，有真值隔离目录、无真值重放、冻结后新种子（A3 加了 8 个） |
| **失败样本保留** | A0 保留首轮多项式工具变量过度拒绝；A1 保留 SI 量纲病态警告；A2 保留短窗失败；A3 保留 NaN 与短缺测 |
| **自我限制写得比多数论文严** | 四份 `scores.json` 的 scope 字段分别写明"拒绝不等于精度通过""经验裕量不是严格置信保证""不证明无参考或高噪性能""非硬件或闭环稳定性通过" |

### 1.2 必须指出的三个弱点

**(a) 23/23、27/27、30/30、46/46 这些数字，验的是"实现忠实度"，不是"判据正确性"。**

A0 的 23/23 里，`accepted 11 / rejected 12 / false_accepts 0 / false_rejects 0`——但"预期行为"本身就是由同一套门限定出来的。所以它证明的是**代码按设计跑**，不是**设计对不对**。真正能支撑判据的是另一条：5 个有噪正例的留出角 RMS ≤ 5.90×10⁻⁴ rad。

**(b) 可用工作区很窄。** A1 的 9 个主例里只有 **4 个被接受、5 个被拒绝**。这说明方法在"充分信息 + 弱失配"时能用，一旦 AFE/Cs 失配或噪声偏大就拒绝认证。**这是诚实的，但也意味着论文必须把"适用区间"画出来，而不能只报 27/27。**

**(c) 全部条件化在同一套合成物理上。** A0 自述"归一化二阶条件模型"；A1 接了 `pcn_plant` 12 状态但仍是合成 SI 参数；A2/A3 明确"未接 AGC/PLL 反馈"。**四层证据的共同前提一旦被真表头推翻，要同时重跑。**

### 1.3 一处需要修正我的表述

我上一轮说"5 Hz × 7 ms 吃满预算"。更准确的读法是：

- A2 的 `config.json` 里 `reference_loop_bandwidth_Hz=5`、`additional_phase_budget_rad=0.2` 都是**自设的调参预算**，不是任务指标，也不是实测相位裕量；
- 6.0775 ms × 2π × 5 Hz = **0.1909 rad = 95.5% of 0.2**，算术无误；
- 但 0.2 rad 只是"分配给附加相位"的额度。若原回路裕量 60°，用掉 11.5° 后仍有 ~48.5°，**不构成失稳**。

**所以这是"预算告急"，不是"闭环失败"。** 正确的下一步不是立刻改架构，而是**先测真实相位裕量**（我上一轮列的 N2）。

## 2. 这套东西对三个目标各值多少

| 目标 | 值多少 | 说明 |
|---|---|---|
| **论文（测量类）** | **高** | A0+A1+A2+A3 可以合成一篇 Measurement/TIM：可辨识几何 + 去嵌 + 因果预算 + 协方差认证。四层证据链正好是审稿人要的"方法—验证—边界" |
| **论文（电路类）** | **低（目前）** | 一行没进 RTL/综合/PPA。要变成 TCAS 类论文，还差"合同 + 定点 + 资源" |
| **芯片** | **中（间接）** | A2 的因果时序与 A3 的协方差门控**就是**芯片要实现的软硬件边界；把它们的精度要求翻成 Q 格式/valid/延迟，就是接口契约 |
| **决策** | **高** | A1 的"忽略加载 → 3.6%""AFE 失配 → 7.95%"直接告诉我们**电路校准精度要多高**（≤0.5% 量级）；这是本轮最有工程价值的数字 |

**一句话**：A 链已经能回答"凭什么说角度可信"，但还回答不了"这个可信度用什么电路实现、代价多少"。

## 3. 后面应该做什么：三个决策 + 三件建设 + 三个停止条件

### 3.1 三个决策（本周内定，不定就没法排期）

| # | 决策 | 选项 | 我的建议 |
|---|---|---|---|
| **D1** | 5 Hz 是任务指标还是预算假设？ | (a) 硬指标 → 改控制率到 2 kHz 或砍流水；(b) 假设 → 把带宽降到 2 Hz 写进规格 | **先按 (b) 冻结规格，同时测真实裕量**；若实测裕量 >45°，再考虑 (a) |
| **D2** | A 链冻结在 A3 吗？ | (a) 冻结 → 出接口契约，启 B；(b) 加 A4（闭环接入） | **冻结 + 只做一次 A4**：把 A2/A3 接进 v10 闭环，**唯一目的是测相位裕量**，不做新算法 |
| **D3** | 主模型修不修？ | (a) 修 θ̇ 系数；(b) 另开分支 | **修，另开验证分支**。不修，A 链与主链物理不一致，论文无法自洽 |

| # | 建什么 | 输入 | 产出 | 判据 |
