# 文献里的分时复用（TDM）到底为了什么？"多采点"还是"相位校准"？

日期：2026-11-03
缘起：你记得全角陀螺文献里有分时复用算法，怀疑其动机是"分时/相位精确校准，以便采集更多的点"
结论先说：**你的两个猜想，一个方向对但要看维度，一个把因果搞反了。**

## 2. TDM 在文献里的三个真实目的（按证据强度）

| # | 目的 | 证据 | 换来了什么 |
|---|---|---|---|
| **1** | **省硬件**：一套电荷放大/ADC 服务两轴或多电极 | R06 标题即"single-channel"；CN114396927B | 面积、功耗、通道间失配 |
| **2** | **隔离驱动与检测**：驱动时检测端被强信号淹没，先卸荷再读 | 浦云飞三态（激励/读出/卸荷）；CN116929322A | 动态范围、避免前端过载 |
| **3** | **获得空间多电极覆盖**：8 个电极都能读，而不只是 2 个 | CN116929322A 八电极 | 可平均电极失配、可做谐波抵消 |

**第 3 条才是"采集更多点"——但那是"空间上更多"，不是"时间上更多"。**

---

## 3. 你的两个猜想，逐条判

### 3.1 "采集更多的点" —— 时间上恰恰相反

设总观察时间固定为 `T`、电极数 `N`、单 ADC：

- 不分时：每轴拿到 **T** 的时间（但只有 2 个空间点）；
- 分时：每个电极只拿到 **T/N** 的时间（但拿到 N 个空间点）。

**总采样点数不变，只是把"时间分辨率"换成了"空间分辨率"。** 对白噪声，每路积分时间降 N 倍 → 每路信噪比降 **√N**。

所以"分时=多采点"在**时间维度上是错的**；在**空间维度上是对的**，而且只有一种情况下划算（见 §4.3）。

### 3.2 "相位精确校准" —— 这是代价，不是目的

TDM 会**制造**相位误差：不同电极在不同时刻采样，载波已经转过了 `ω·Δt`。所以文献里的"相位校准"是为了**消除 TDM 自己引入的误差**，不是为了让采集更多点。

不过你的直觉有一半是对的：**相位校准在全角陀螺里本来就是一等问题**，只是原因不是 TDM，而是**正交泄漏**：

> 解调参考与载波差一个 δ，正交分量就会按 `sin δ` 漏进同相通道。你开题里已经写过这句："实际用于解调的信号会与驱动轴的位移相差一个微小的相位差，该相位差会使正交误差信号部分泄露到检测闭环中。"

所以全角陀螺的相位校准有**两个独立来源**：

| 来源 | 机理 | 量级 |
|---|---|---|
| **正交泄漏** | 参考相位差 δ → 正交量 `Q` 漏成同相，直接进角度 | 一阶 `sin δ` |
| **TDM 时偏** | 不同电极采样时刻差 Δt → 等效相位差 `ωΔt` | 一阶 `ωΔt` |

---

## 4. 量化：三个不等式决定 TDM 值不值得做

### 4.1 时偏必须"已知"，而不是"很小"

取载波 `f₀ = 1 kHz`、控制周期 1 ms、8 个时隙 → 每隙 **125 µs** → 等效相位 **`2π×1000×125µs = 45°`**。

这个 45° 本身不可怕，**可怕的是不知道它**。因为：

```
δ(相位) = ω₀ · δ(Δt)
```

要残余相位误差 ≤ 0.1°，需要 **`δ(Δt) ≤ 0.28 µs`**。

- 用 50 MHz 主时钟打时间戳 → 分辨率 20 ns → **足够 14 倍**；
- 用"开关一合就开始积分"的模拟时序 → 误差几十 µs → **完全不够**。

> **结论：TDM 的相位问题不是"时偏多大"，而是"时偏知不知道"。有数字时间戳就能精确补偿，没有就是系统性错误。**
> 这正是 A2 里那条合同的意义：`φ(t_e) = φ(t_s) + FCW·(t_e − t_s)`。

### 4.2 噪声代价是 √N

N 个电极挤一个通道，每路时间 1/N → 白噪声下每路 SNR 降 **√N**（8 电极降 9 dB）。

### 4.3 空间收益是 1/√N，但只在"失配主导"时才净赚

电极失配是**系统性**误差，平均 N 个 → 降 **1/√N**；噪声是**随机**的 → 升 **√N**。两者相抵的临界条件是：

```
σ_mismatch / σ_noise  >  √N · √N = N
```

**即：电极失配必须比单路噪声大 N 倍以上，TDM 空间平均才净赚。**

用项目实测：A1 里 **AFE/Cs 失配 0.5% 就让留出误差涨到 7.95%/12.18%**——失配项远远大于噪声项。**所以在我们这里，"失配主导"是成立的，空间平均有净收益。**

### 4.4 还有一条机械前提（上一轮算过）

自由衰减 `A(t+T_b)=A(t)e^{−γT_b}`，`γ=πf₀/Q`。取 `f₀=1 kHz`：

| Q | 单时隙(0.5 ms)损失 | 40 时隙累计 |
|---:|---:|---:|
| 1×10⁴ | 0.016% | 0.6% |
| 1×10³ | 0.16% | 6% |
| 1×10² | 1.6% | 47% |

**只要 Q ≳ 1000，分时在机械上完全可行**——障碍只在电气侧（压电电荷记忆、介质吸收、开关注入、过载恢复）。

## 5. 对我们项目的含义

| 条件 | 若不满足 | 若满足 |
|---|---|---|
| **电极可独立寻址** | TDM 只剩"省通道"，而我们已用单 ADC 40 kS/s，省通道意义很小 → **不做** | 可做空间平均/谐波抵消 → 值得做 |
| **有数字时间戳** | 相位误差不可补偿 → **必须先建时间戳** | 可精确补偿 → TDM 可用 |
| **电极失配 ≫ 噪声** | 噪声主导 → TDM 反而更差 | 失配主导 → 净赚（本项目成立） |

**所以 TDM 在我们这里的正确位置**：不是"为了多采点"，也不是"为了相位校准"，而是——

> **在电极可独立寻址、且失配主导的前提下，用"单前端分时轮询"换取"空间多电极覆盖"，代价是 √N 的噪声与必须精确知道的时间戳。**

这三条同时成立时，它才等价于**空间换向/谐波抵消**（我前几轮说的 HSCR）；否则它只是"省一套前端"，对 40 kS/s 单 ADC 的架构没有吸引力。

---

## 6. 给论文/汇报用的一句话

> 文献中的全角分时复用主要解决**前端共享**与**驱动-检测隔离**，而非增加采样点；其引入的时偏必须由数字时间戳补偿（`ωΔt` 精度决定残余相位），而空间多电极覆盖的收益只有在电极失配主导时才成立。本项目在 40 kS/s 单 ADC 架构下不需要"省通道"，因此 TDM 的价值应重新表述为**空间平均/谐波抵消的可实现性**，而不是时分复用本身。
