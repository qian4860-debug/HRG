## 0. 这份整合要解决什么

项目现在有三类材料，但从来没有对齐过：

1. **教材与经典**（Lynch、Bryan、Rozelle、Ragot、Jeanroy、赵小明《谐振陀螺仪与系统技术》）——讲"机械怎么变成三个慢变量"；
2. **2023–2026 的期刊论文**（TIM / Measurement / S&A A / MSSP / MINE / 航空学报）——讲"某一项误差怎么辨识怎么补"；
3. **项目自己的总书**（45 章 + 第五版逐式贯通）——讲"从零推到电路"。

三者的问题不是"读得少"，而是**没有共同的坐标系**。结果是：

- 写引言时把 Lynch 当万能依据，可 Lynch **根本不管电路误差**；
- 做电路指标时找不到理论锚点，只能"看波形拍脑袋"；
- 查新时以为某项没人做，其实在另一层已经有人做了三年。

所以这份整合只做三件事：**给骨架、给地图、给空位**。

## 1. Lynch 的骨架：它到底管到哪里

Lynch（1995，9 页，库内有两份扫描）把"机械 → 三个慢变量"这一段彻底封死了：

| Lynch | 内容 | 作用 |
|---|---|---|
| 式(1)–(6) | 旋转坐标下的两模态方程 + 阻尼/刚度各向异性 → **四个参数**：1/τ、Δ(1/τ)、ω₀、Δω | 定义"表头能用四个数描述" |
| 式(7)–(11) | Pauli 矩阵表示 | 把两行方程写成一个矩阵方程，便于平均 |
| 式(12)–(17) | 复包络 + 时间平均 | **平均法**：只留慢变项，丢掉 2ω₀ 快项 |
| 式(18)–(23) | 指数映射、2θ 的来源 | 解释为什么各向异性以 2θ（物理角 4θ）出现 |
| 式(24)–(31) | 四个 IQ → 七个量（E、Q、R、S、L、…） | 给出"电路能算什么"的清单 |
| 式(32)–(39) | 四个慢变量的完整动力学 | **项目物理模型的全部来源** |
| 式(40)–(46) | 能量/正交/角度/PLL 四类控制 | 给出控制通道的物理含义 |

### 1.1 Lynch 不管什么（这一点比"管什么"更重要）

```
Lynch 管：机械(四参数)  ──→  三个慢变量 (E, Q, θ)
Lynch 不管：换能（电荷/电容/压电）、电极几何、
            电路增益与相位、量化与定点、采样与延迟、
            估计与辨识、控制实现、验证方法
```

**这就是项目"物理对、电路指标定不下来"的根因**：从"慢变量"到"电路指标"这一段，Lynch 没有给骨架，只能靠零散文献拼。

### 1.2 一条必须记住的换算

Lynch 用 **2θ**，项目用 **4θ**。因为 Lynch 的 θ 是"模态角"，而项目用物理驻波角：

```
θ_Lynch = 2·θ_物理      →      cos2θ_L = cos4θ_物理
```

**这不是错误，是记号。** 把它当成错误去改，会把对的改成错的；反过来，把 4θ 文献直接塞进 Lynch 的 2θ 式子，会得出系数差 2 倍的结果——本项目代码正好踩了这个坑（见 §4.3）。

## 4. 记号统一表（这一步不做，跨文献引用必错）

十几篇文献用了至少五套记号。下表把常用量对齐：

| 物理量 | Lynch | 常见中文文献 | 项目代码 | 备注 |
|---|---|---|---|---|
| 物理驻波角 | θ_L（模态角） | θ | `theta` | **θ_L = 2θ** |
| 各向异性谐波 | cos2θ_L | cos4θ | cos4(θ−θ_τ) | 同一件事 |
| 平均阻尼率 | 1/τ | 1/τ、γ、ω₀/(2Q) | `meanDamping = π f₀/Q` | 三者相等：γ = 1/τ = ω₀/(2Q) |
| 品质因数 | Q = ω₀τ/2 | Q | `Q` | 别把 Q 和 1/τ 混 |
| 阻尼差 | Δ(1/τ) | Δ(1/τ)、Δγ | `dampingAnisotropy` | 1/s |
| 频率裂 | Δω（**半裂**） | Δf（**全裂，Hz**） | `frequencySplitHz`（全裂）+ `splitRad=2πΔf` | **最大的坑：差 2 倍** |
| 长短轴 | a, q | A, B；a, q | `mainAmplitude`, `quadAmplitude` | |
| 不变量 | E, Q, R, S, L | E, Q, R, S | `E,Q,R,S,L` | **L 有三种定义，见下** |

### 4.1 `L` 的三种定义（最容易串味）

- Lynch：与相位误差成正比，供 PLL；
- R25 等中文文献：有时指"频差信号"；
- 项目：`L = 2(Cx·Sx + Cy·Sy)`，即两通道 I/Q 的内积，正比于载波相位误差。

**引用时必须写清是哪一种**，否则"用 L 做锁相"和"用 L 做频差辨识"会得出相反的符号。

### 4.2 符号约定

| 量 | 项目约定 | 风险 |
|---|---|---|
| θ 正方向 | 逆时针 | 与部分文献相反 |
| B 的符号 | `θ̇ = −B·Ω` | 直接抄 `θ̇ = +B·Ω` 会反号 |
| Q 的正负 | `Q = 2(CxSy − CySx)` | 换一种 IQ 排列就变号，`q` 的恢复要带符号（第五版总书式(39) 已指出） |

### 4.3 我实测的系数（与代码不一致，必须记住）

用两自由度 ODE 反演（`research/project_master_plan_20261102/evidence/`）：

| 项 | 项目代码 | ODE 反演（正确） |
|---|---|---|
| Ė 阻尼 | −2γE − Δ(1/τ)cos4(θ−θ_τ)E | 一致 |
| θ̇ 阻尼 | **+0.5**·Δ(1/τ)·sin4(θ−θ_τ) | **+0.25** |
| θ̇ 频裂 | **+0.5**·Δω·(Q/E)·cos4(θ−θ_ω) | **−0.25** |
| Q̇ 频裂 | **−2**·Δω·E·sin4(θ−θ_ω) | **−1** |

> 换算口诀：**"半裂配四分之一，全裂配二分之一，两个都用就翻倍"**。项目代码相当于把"全裂"当"半裂"用，于是整体 ×2。

## 5. 三篇经典各补什么（不要重复读）

## 9. 引用纪律（避免把不同层级混用）

| 层级 | 定义 | 能写进论文的什么位置 |
|---|---|---|
| **F1 全文精读** | 逐式核对过 | 方法对比、公式引用、实验对照 |
| **F2 全文略读** | 读过摘要+方法+实验 | 相关工作、基线描述 |
| **F3 仅摘要** | 只读官方摘要 | 只能写"有工作研究了…"，**不能引具体数字** |
| **F4 仅条目** | 只有题名/DOI | 只能写"存在相关研究"，**不能写结论** |
| **F5 二手** | 转述他人综述 | **一律不引**，除非同时引原文 |

**本项目已知的踩坑点**：R08、R15、R16、R21、R23 有部分只到 F3/F4，任何"某文献达到 X °/h"的写法都必须先补全文。库内 `02_最新技术进展与文献对照_20261010.md` 已逐条记录阅读范围，引用时以它为准。
