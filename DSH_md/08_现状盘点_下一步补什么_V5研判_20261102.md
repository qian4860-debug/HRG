# 第二部分　V5 可行性研判

## 2.1 对 V5 八条纠正的判定

| V5 纠正我的 | 判定 | 说明 |
|---|---|---|
| `rank(G)=rank(H)=2` 是充要条件 | **V5 对，我错** | V5 式(1) 的 SISO 例：`G=[1,1]ᵀ, H=[1,0.7]` 都秩 1，但四阶系统可控可观，两对极点都能看到 → 端口秩只是 V3 方阵求逆的**充分前提**，不是必要条件 |
| 我把机械谱叫"Lynch 四参数" | **V5 对，命名要改** | Lynch 式(5) 的四参数是 1/τ、Δ(1/τ)、ω₀、Δω；但**规范变量**是 a、q、θ、φ′。我混了"参数"和"变量"。改为"**机械谱参数（对应 Lynch 式(5)）**" |
| "频裂小则 B₂ 近奇异" | **V5 对，我错** | `B₂=G⁻¹H⁻¹` 不含频裂；我把"模态分辨率"和"矩阵条件数"混了 |
| C1+C2 证明逐周期等价 | **V5 对，我太薄** | 时间戳不约束算法/舍入/饱和/状态。V5 给了 ties-away vs ties-even 的反例（同一 x=0.5，C1–C3 全满足，结果 1 vs 0） |
| 0.094/0.188/2.36 Hz 证明延迟不是瓶颈 | **V5 对，我错** | 那是旧 tune **目标值**、`autoApply=false`、不是实测交越；**压电分支是 4–5 Hz**（见 §1.2）→ 延迟真吃了预算 |
| 32 帧估计只改输出 | **V5 对，我错** | 估计 I/Q 已进能量/正交/PLL/方向预测 |
| `τ*∝(σ/α)^{2/5}` 是通用最优 | **部分对**：指数对，形式我错 | V5 §6.1 严格推出 `T*=(144N₀/a²)^{1/5}`，即 `144^{1/5}(σ/\|a\|)^{2/5}` —— **指数 2/5 被证实**；我的错在把动态误差写成 `τ²\|Ω̈\|/ωn²`（量纲不对，且把 χ 当 Ψ） |
| `rank=1` 则信息增益为零 | **V5 对，我说太绝** | 秩不增仍可沿已有方向降方差；应比较 `F_new−F_old` 与**目标风险**，不是只看秩 |

**采纳：8 条全采纳。** 我的 V4 在这八处都过强。

## 2.3 V5 自身需要补强的三处

### (a) A 的"需要多大扰动才能认证"没有定量门槛

V5 §3.4 说"越对称越难盲校准"，§3.5 给了方向误差界 `sin∠(ẑ,z) ≤ ε_C/σ₂(Ĉ)`。**但没反解出"要多大的各向异性/扰动才够"。**

这一步可以补：由 §3.5 的界，认证条件等价于 `σ₂(C) > ε_C/ sin(δ_max)`，其中 `δ_max` 是允许的角度误差。而 `σ₂(C)` 随各向异性单调增。所以：

```
可认证的必要条件： 各向异性 × 几何因子 > ε_C / sin(δ_max)
```

**这就能回答"扰动要多大"**——把 A 从"能算"变成"能设计"。建议补一条曲线：横轴各向异性（10⁻¹…10⁻³），纵轴可认证的最大 δ，画上 ε_C 的等值线。

### (b) B 与 V10.1 已有结果的重叠必须写清

`revision_v10_1/evidence/multiload_results.json` 已经证明：本征 γ 恢复、全部电气组合可恢复、留出负载/频点通过、双计阻尼被拒。**如果 B 只是"再做一次多负载"，会被指为重复自己的旧结果。**

B 的 delta 必须收紧成一句：**"用互易性 `Y(s,Ω)ᵀ=Y(s,−Ω)` 与功率平衡式(11)作为约束，把现有 1.69e6 的条件数压下来，并证明约束不引入偏差"**。这是一个可测量的改进，不是新框架。

### (c) D 的 T* 只对"角度域白噪声 + 局部二次"成立

V5 §6.2 自己指出 I/Q 曲率含 `χ̇²` 项。所以需要给一个**适用判据**：

```
角度域近似成立的条件：χ̇²·A·T²/2  ≪  a·T²/12
即     χ̇² ≪ a/6
```

不满足时 T* 只能当上下界用。这个判据应当写进 D 的验收，否则实测套公式会错。
