# 从机械表头到电路：一步一步的推导（大白话版，可手算复现）

日期：2026-11-02
用途：把"表头长什么样"一路推到"每个电路块要满足什么数"，中间不留跳步
读法：每一步都是"**已知什么 → 用什么式子 → 算出什么数 → 这个数交给谁**"。带 ★ 的是可以手算复现的算例
参数来源：当前项目假设值（f₀=5 kHz、Q=2×10⁶、B=0.277、E=1），**表头实测后逐个替换，方法不变**

---

## 写在前面：整条链只有五句话

1. 表头是一个**二维弹簧振子**，转动时花纹会跟着转（科里奥利效应），转多少由 Bryan 系数决定。
2. 花纹的"形状"用三个慢变量描述：**多强（E）、多圆（Q）、朝哪（θ）**。
3. 这三个量随时间怎么变，由表头的**四个参数**决定：漏能快慢、漏能不均、两个方向频率差、Bryan 系数。
4. 电路的任务只有两件：**把 θ 读出来**（检测链），**把 E 和 Q 按住**（驱动链）。
5. 所以整条设计链是：**角度精度 → 角度噪声 → 四个 IQ 的误差 → ADC 噪声 → 电荷噪声 → 各电路块指标**。

下面一步一步走。

---

# 第一步：把表头看成一个二维振子

## 1.1 为什么是"二维"

半球谐振子工作在 n=2 模态：**四个波腹、四个波节**，像一个"哑铃"绕一圈摆四瓣。这种振型有个特点：它在平面上的任意状态，都可以用**两个互相垂直方向上的位移** `x` 和 `y` 完全描述。

所以不需要做有限元、不需要知道壳的厚度，只需要两个数。

## 1.2 它的方程就是中学的弹簧振子，只是两个

```
m·ẍ + c·ẋ + k·x = 力
m·ÿ + c·ẏ + k·y = 力
```

对陀螺来说，两个方向不是完全一样的（加工永远有误差），所以写成：

```
m·ẍ + c_x·ẋ + k_x·x = 力
m·ÿ + c_y·ẏ + k_y·y = 力
```

**四个"要测的东西"就藏在这里**：

| 符号 | 大白话 | 单位 |
|---|---|---|
| ω₀ = √(k/m) | 平均谐振频率（两个方向差不多时的共同频率） | rad/s |
| 1/τ = c/(2m) | 能量漏掉的快慢（Q 值就是它的倒数关系） | 1/s |
| Δ(1/τ) = 1/τ_x − 1/τ_y | **两个方向漏能不一样多** | 1/s |
| Δω = (ω_x − ω_y)/2 | **两个方向频率不一样**（"频裂"） | rad/s |

注意：`Δω` 是**半裂距**（两个方向差多少的一半），这一点后面会反复用到，也是本项目代码里出错的地方。

## 1.3 ★算例：把假设值代进去

- f₀ = 5000 Hz → ω₀ = 2π×5000 = **31416 rad/s**
- Q = 2×10⁶，且 `Q = ω₀τ/2` → τ = 2Q/ω₀ = 4×10⁶/31416 = **127.3 s**
- 于是 1/τ = **7.85×10⁻³ /s**（这就是"能量每秒漏掉千分之八"）
- 频裂 Δf = 0.008 Hz → Δω = 2π×0.008 = **0.0503 rad/s**

> **检查一下**：Q=2×10⁶ 意味着振起来以后，能量衰减到 1/e 需要 127 秒。这就是为什么全角陀螺能"记住"角度。

# 第二步：为什么要用"椭圆"来说话

## 2.1 振动的样子是一个椭圆

想象你在表头上撒一层细沙：振起来以后沙子会聚成四条线（波腹）。如果两个方向相位、幅度都不同，四条线就不在正十字上，而是**一个倾斜的椭圆**。

任何时刻这个椭圆只需要三个数：
- **长轴多长** `a`（振得多厉害）
- **短轴多长** `q`（"不圆"的程度，理想是 0）
- **长轴朝哪** `θ`（花纹方位角）

外加一个"振动进行到哪一步了"的相位 `φ`。`φ` 一秒变化 5000 次，太快，电路不关心；我们只关心 `a, q, θ` 这三个**慢**变量。

## 2.2 三个"电路能直接算出来"的量

电路中真正能算的不是 `a` 和 `q`，而是它们的组合：

```
E = a² + q²        （总能量）
Q = 2·a·q          （正交量：椭圆有多"胖"）
R = (a²−q²)·cos4θ  （方位向量的 x 分量）
S = (a²−q²)·sin4θ  （方位向量的 y 分量）
```

**为什么是 4θ 而不是 θ**：因为模态是"哑铃形"，转 90° 以后长得一模一样。用 4θ 就把"90° 一个周期"变成"360° 一个周期"，普通的角度公式才成立。

于是：

```
θ = atan2(S, R) / 4        ← 这就是全角模式测角的全部秘密
```

## 2.3 为什么电路能算出 E、Q、R、S

检测电极上量到的是载波（5 kHz 正弦）被这三个慢变量"调制"过的信号。把载波乘回去、再低通，就得到四个数：

```
Cx, Sx  ← x 方向电极的 同相/正交 分量
Cy, Sy  ← y 方向电极的 同相/正交 分量
```

然后：

```
E = Cx² + Sx² + Cy² + Sy²
Q = 2(Cx·Sy − Cy·Sx)
R = Cx² + Sx² − Cy² − Sy²
S = 2(Cx·Cy + Sx·Sy)
L = 2(Cx·Sx + Cy·Sy)      ← 这个是"载波相位对不对"，给锁相环用
```

**这五个式子就是数字电路里那 8 个乘法器的全部工作。** 代入 `Cx=a·cos2θ, Cy=a·sin2θ, Sx=−q·sin2θ, Sy=q·cos2θ` 可以验证 `R=(a²−q²)cos4θ`、`S=(a²−q²)sin4θ`——这一步建议自己拿纸推一遍，五分钟。

# 第三步：三个慢变量怎么随时间变（物理模型）

## 3.1 三个方程，每项都有物理意思

```
Ė = −2γE − Δ(1/τ)·cos4(θ−θ_τ)·E + 驱动
Q̇ = −2γQ + Δω·sin4(θ−θ_ω)·E + 正交驱动
θ̇ = −B·Ω + 0.25·Δ(1/τ)·sin4(θ−θ_τ) − 0.25·Δω·(Q/E)·cos4(θ−θ_ω) + 虚拟进动
```

逐项翻译：

| 项 | 大白话 |
|---|---|
| `−2γE` | 没有驱动时，能量按 2γ 的速度漏掉（γ=1/τ） |
| `−Δ(1/τ)cos4(θ−θ_τ)E` | 漏能不均匀：花纹转到"漏得快"的方向就掉得快，转到"漏得慢"的方向就掉得慢 |
| `+Δω·sin4(θ−θ_ω)E` | 频裂会把"圆"振成"椭圆"：Q 会自己长出来 |
| `−B·Ω` | 载体转 Ω，花纹反向转 B·Ω（B≈0.277，转 1 圈花纹转 0.277 圈） |
| `0.25Δ(1/τ)sin4(θ−θ_τ)` | 漏能不均匀会把花纹"拉向"漏得慢的轴（这就是零速漂移的来源之一） |
| `−0.25Δω(Q/E)cos4(θ−θ_ω)` | 频裂 + 残留正交 → 又一个漂移（正交没控好，这个就大） |

> **⚠️ 重要提醒（本项目的实测发现）**：当前 MATLAB 代码里 θ̇ 的两项写成了 `0.5` 和 `+0.5`（符号也不对）。我用两自由度方程独立反演，正确值是 **`0.25`** 和 **`−0.25`**。也就是说：**代码把漂移算大了 2 倍，而且方向反了**。这一条不改，后面所有漂移数字都不能用。详见 `research/project_master_plan_20261102/evidence/`。

## 3.2 ★算例：不加任何补偿，花纹自己会飘多快

- 漏能不均项：0.25 × 2.5×10⁻⁴ = 6.25×10⁻⁵ rad/s
- 换成 °/h：6.25×10⁻⁵ × 57.3 × 3600 = **12.9 °/h**
- 频裂项（正交没控住时，Q/E≈0.015）：0.25 × 0.0503 × 0.015 = 1.9×10⁻⁴ rad/s = **39 °/h**
- 频裂项（正交通道工作，Q/E 压到 10⁻⁴）：0.25 × 0.0503 × 10⁻⁴ = 1.26×10⁻⁶ rad/s = **0.26 °/h**

**这三个数字说明了整机的设计重点**：
1. 不补偿时漂移几十 °/h，离导航级差 100 倍；
2. **正交通道必须工作**，它一松，频裂项立刻放大 150 倍；
3. 剩下的漏能不均要靠标定/补偿，这就是 FRP 那类方法存在的理由。

# 第四步：从"我要多准"反推"角度噪声允许多大"

## 4.1 两个不同的指标，不要混

| 指标 | 意思 | 单位 |
|---|---|---|
| **ARW**（角度随机游走） | 白噪声造成的角度误差，随 √时间 长大 | °/√h |
| **BI**（零偏不稳定性） | 慢漂移造成的底，与时间无关 | °/h |

ARW 对应"噪声"，BI 对应"漂移+1/f"。**电路设计主要跟 ARW 打交道**，因为噪声从第一级就定了。

## 4.2 全角模式有个 1/B 的放大

表头给出的是"花纹角"，惯性角 = 花纹角 / B。B=0.277 → **放大 3.61 倍**。

所以你要求的惯性角精度，要除以 3.61 才是花纹角的精度。这是全角模式的一个"隐性成本"。

## 4.3 ★算例：目标 ARW = 0.03 °/√h

```
0.03 °/√h
 ÷60            → 5×10⁻⁴ °/√s
 ×π/180         → 8.7×10⁻⁶ rad/√s     （惯性角噪声密度）
 ×B (0.277)     → 2.4×10⁻⁶ rad/√Hz     （花纹角噪声密度）
 ÷?            
```

因为控制率 1 kHz，每 1 ms 出一个角度，所以每样本允许的噪声：

```
2.4×10⁻⁶ × √1000 = 7.6×10⁻⁵ rad ≈ 0.0044°
```

**这个数（7.6×10⁻⁵ rad/样本）是整条电路链的"总闸门"。** 后面每一步都要问：这一级贡献的噪声，比 7.6×10⁻⁵ 小多少？

# 第五步：从"角度误差"反推"四个 IQ 的误差"

## 5.1 一条一阶公式，决定了很多设计

`θ = atan2(S,R)/4`，求微分：

```
δθ = (R·δS − S·δR) / [4(R²+S²)]
```

三个直接结论：

1. **公共缩放不敏感**：R 和 S 一起变大变小，θ 不变。所以"能量波动"只要不改变 R/S 的比例，就不影响角度。这解释了为什么 R/S 要"成对一致缩放"（同一个快照、同一组舍入）。
2. **切向误差才致命**：真正伤角度的是"垂直于 (R,S) 向量"的那部分误差。
3. **信号越弱越怕噪声**：分母是 `4(R²+S²)`，当 `|V|=√(R²+S²)` 变小时，同样的 δR 放大得更厉害。`|V|` 正比于 `(a²−q²)`，所以**正交一变大、能量一变小，角度就崩**。这就是为什么代码里要设 `phaseValidThreshold=0.08` 和能量门限。

## 5.2 ★算例

- 若 `|V| = 1`，允许 `δθ = 7.6×10⁻⁵ rad`，则允许 `δR ≈ 4×7.6×10⁻⁵ = 3×10⁻⁴`
- 若 `|V|` 掉到 0.08（门限），同样的 δR 会放大到 `3.8×10⁻⁴ rad` → **已经超过闸门 5 倍** → 所以低能量时必须冻结角度输出，而不是硬算

# 第六步：从 IQ 误差反推"ADC 前面允许多大噪声"

## 6.1 解调本身就是一次"降噪"

解调 = 乘载波 + 低通。低通在这里是"把 40 个样本平均"。白噪声平均 N 个，标准差降 √N；但乘载波会引入 √2 的因子，所以：

```
σ_IQ = σ_adc × √(2/N)
```

N=40（40 kS/s ÷ 1 kHz）→ √(2/40) = 0.224。

## 6.2 ★算例：反推 ADC 输入允许的噪声

前面算过 `δθ = σ_IQ/(2A)`（A=1 时是 σ_IQ/2）。要 `δθ = 7.6×10⁻⁵`：

```
σ_IQ ≤ 1.5×10⁻⁴
σ_adc ≤ 1.5×10⁻⁴ / 0.224 = 6.7×10⁻⁴
```

**结论：ADC 输入端相对噪声要 ≤ 6.7×10⁻⁴（满量程是 2 的话，约 −69 dBFS 在 40 kHz 带宽内）。**

而项目现在设的是 2.5×10⁻⁴ —— **比要求还小 2.7 倍，等效 ARW ≈ 0.011 °/√h**。也就是说：**噪声预算本来就是够的，问题不在噪声。**

# 第七步：ADC 到底要几位

## 7.1 量化噪声的公式

一个均匀量化的 ADC，量化噪声的有效值 = `LSB/√12`。

18 位、满量程 ±2 V（模型里 FS=2）：

```
LSB = 2×2/2¹⁸ = 1.53×10⁻⁵
量化噪声 = 1.53×10⁻⁵/3.46 = 4.4×10⁻⁶
```

跟允许的 6.7×10⁻⁴ 比，**低了 150 倍（43 dB）**。

## 7.2 但"18 位"是标签，不是能力

输入端噪声 2.5×10⁻⁴ ÷ LSB 1.53×10⁻⁵ = **16 个 LSB**。也就是说：

```
有效位数 ENOB ≈ 18 − log₂(16) = 14 位
```

**多出来的 4 位是白给的。** 这一条非常重要的实践含义：**不要再加位宽**，而是要保证"模拟噪声不被后面的数字噪声超过"，以及"前端的动态范围够"。

## 7.3 什么时候位宽才真成问题

三个条件之一成立时：
1. 能量降到很低（`|V|` 小）→ 5.1 节说过，有效位数等于少了 log₂(1/|V|) 位；
2. 把字长砍到 16 位以下（比如为了省面积）；
3. 用定点做递推（RLS/滤波器）时，状态量会累积误差。

# 第八步：从 ADC 噪声反推"电荷放大器的噪声"

## 8.1 压电表头的信号是"电荷"，不是"电压"

压电片受力变形 → 表面产生电荷 q。所以第一级必须把**电荷变成电压**，这就是电荷放大器（charge amplifier）：

```
V_out = −q / C_f
```

`C_f` 是反馈电容。增益完全由 C_f 决定，跟压电片自身的电容无关（这是电荷放大器的好处）。

## 8.2 换算链

```
允许的 ADC 输入电压噪声 V_n,adc
 → 允许的输入电荷噪声 q_n = C_f × V_n,adc
 → 对电荷放大器自身的要求：输入等效电荷噪声 ≤ q_n 的一部分（比如 1/3，留给其他源）
```

## 8.3 ★算例（需要表头给两个数）

假设（**待实测**）：模态振幅 `a = 1 μm`，检测灵敏度 `Θ_s = 10 pC/μm`，则信号电荷 `q_sig = 10 pC`。

- 若 C_f = 1 pF、满量程 ±2 V → 满量程电荷 = 2 pC。**信号 10 pC 超出量程** → 说明 C_f 要加大到 10 pF，或者信号太强。
- 这也说明：**没有 `Θ_s` 和 `a`，这一步算不下去**——这就是为什么"测表头"是整个设计链的唯一缺口。

**公式留在这里，等表头实测填数**：

```
q_n,allowed = C_f · (2/2^18) · 6.7×10⁻⁴/2   [C/√Hz 量级]
```

# 第九步：抗混叠滤波器要几阶

## 9.1 混叠从哪里来

采样率 40 kHz、载波 5 kHz。除了 5 kHz，还有它的"镜像"在 `40−5 = 35 kHz`。35 kHz 的东西采样后会**折回** 5 kHz，跟真信号混在一起，永远分不开。

所以 ADC 前面必须有一个低通，把 35 kHz 压下去。

## 9.2 ★算例：现在够不够

项目里 AFE 是一阶、12 kHz：

```
衰减 = 1/√(1+(35/12)²) = 0.324 → 只有 −9.8 dB
```

如果要求 −40 dB（即压到 1/100），n 阶需要：

```
(1+2.917²)^(n/2) ≥ 100
每阶 9.8 dB → n ≥ 40/9.8 = 4.1 → 需要 5 阶
```

**5 阶低通在片上很贵。** 更聪明的两条路：

| 方案 | 做法 | 代价 |
|---|---|---|
| 提高采样率 | fs 从 40 k 提到 200 kS/s，则镜像在 195 kHz，二阶就够（48 dB） | ADC 功耗 ×5，数字时钟 ×5 |
| 用带通代替低通 | 中心 5 kHz 的带通，把 35 kHz 压掉 | 需要更高 Q 的滤波器，相位匹配难 |

**这就是"采样率 ↔ 抗混叠阶数 ↔ 功耗"的三方权衡**，也是全角陀螺比力平衡陀螺难做的一个具体原因。

# 第十步：驱动侧要多大的电压、多大的电流

## 10.1 稳态时，驱动功率 = 耗散功率

花纹要维持能量 E 不变，就必须把漏掉的补回来：

```
驱动功率 = 2γE
```

代入：2 × 7.85×10⁻³ × 1 = **1.57×10⁻² （归一化功率）**

## 10.2 换成物理量

```
力 F = Θ_d · V_drive        （Θ_d 是驱动灵敏度，N/V）
功率 = F²/(2c)              （c 是阻尼系数）
```

所以：

```
V_drive = √(2·c·P/Θ_d²) = √(2·c·2γE/Θ_d²)
```

**又需要两个表头参数**：`Θ_d`（N/V）和 `c`（或等效的 m/τ）。

## 10.3 还有一个更容易被忽略的约束：**驱动必须能"调制"**

全角模式下，驱动不是"一路正弦"，而是要把三个控制量（能量、正交、虚拟进动）合成到**两对电极**上，并且**乘上 5 kHz 载波**：

```
电极1 电压 = u_E·cos(ω̂t) + u_Q·sin(ω̂t) + u_V·(...)
电极2 电压 = 另一组相位
```

**这一步现在整个项目里是缺的**：数字核只输出三路慢变 DAC 码，没有把载波乘上去。压电表头必须被 5 kHz 载波驱动，所以要么：

- 在数字域用 NCO 乘慢命令，DAC 直接输出调制波（DAC 要跑 40 kS/s）；
- 或者在模拟域用乘法器/开关解调器和外部载波相乘（相位误差直接变成正交串扰）。

**这是全系统第一优先级的架构决策**，比任何算法都靠前。

# 第十一步：时钟和抖动要多准

## 11.1 采样抖动会直接变成角度噪声

采样时刻偏了 δt，相当于把幅度 A 的信号读成了 `A + ẋ·δt`，而 `ẋ = Aω₀`，所以：

```
幅度误差 = A·ω₀·δt
```

## 11.2 ★算例：8 ns 抖动意味着什么

```
幅度误差 = 1 × 31416 × 8×10⁻⁹ = 2.5×10⁻⁴
→ 角度误差 ≈ 2.5×10⁻⁴/(2√2) = 8.9×10⁻⁵ rad
→ 折算 ARW = 8.9×10⁻⁵/√1000 /0.277 ×3438 = 0.035 °/√h
```

**对比闸门 0.03 °/√h：抖动单独一项就已经超标。** 而项目的 AFE 噪声贡献只有 0.011 °/√h。

**结论：当前设计是"抖动受限"，不是"ADC 受限"。** 要去 0.01 °/√h，采样抖动必须降到 **2 ns 以内**（或用更低的载波频率、或用相关采样把抖动转成共模）。

这一条几乎没有项目文档提过，但它是量级最大的单项。

## 11.3 频率跟踪要多大范围

模型里谐振频率温度系数 −18 ppm/℃。−40~+85 ℃ 跨 125 ℃：

```
Δf = 5000 × 18×10⁻⁶ × 125 = 11.25 Hz
```

DPLL 的捕获范围 1200 Hz 远远够。**但要注意**：如果 NCO 和 ADC 用同一个时钟，时钟本身的漂移会被"约掉"；如果用外部载波参考，就不会——这是时钟树设计必须回答的问题。

# 第十二步：延迟预算

## 12.1 把每一段加起来

| 环节 | 延迟 | 怎么来的 |
|---|---|---|
| CIC（3 级，R=40） | **1.46 ms** | 群延迟 = N(R−1)/2 = 58.5 个采样 ÷ 40 kHz |
| FIR（5 抽头，1 kHz） | **2.0 ms** | 2 个控制周期 |
| 控制流水线 | **3.0 ms** | 3 个控制周期（项目设的） |
| DAC 零阶保持 | **0.5 ms** | 半个控制周期 |
| **合计** | **≈7 ms** | |

## 12.2 延迟决定带宽

相位滞后 = 360° × f × 延迟。要 45° 相位裕度：

```
f_max = 45/(360 × 0.007) = 17.9 Hz
```

**也就是说：现在这套数字链，闭环带宽做不过 18 Hz。** 如果指标要求 100 Hz，延迟必须压到 **1.25 ms**——必须砍 FIR（2 ms）和控制流水（3 ms），而不是砍 CORDIC（只有 0.36 μs）。

**这就是"延迟—带宽"的硬约束，也是为什么"少用几级流水"比"优化 CORDIC"重要得多。**

# 附：手算复现清单（拿纸就能做）

按顺序算，每一步都能用计算器验证：

1. `ω₀ = 2π×5000 = 31416`
2. `τ = 2Q/ω₀ = 4×10⁶/31416 = 127.3 s`；`γ = 1/τ = 7.85×10⁻³`
3. 漂移（漏能不均）`0.25×2.5×10⁻⁴×57.3×3600 = 12.9 °/h`
4. 漂移（频裂、Q/E=0.015）`0.25×0.0503×0.015×57.3×3600 = 39 °/h`
5. 允许角度噪声 `0.03/60×π/180×0.277×√1000 = 7.6×10⁻⁵ rad`
6. 允许 IQ 噪声 `2×7.6×10⁻⁵ = 1.5×10⁻⁴`
7. 允许 ADC 噪声 `1.5×10⁻⁴×√(40/2) = 6.7×10⁻⁴`
8. 量化噪声 `(4/2¹⁸)/√12 = 4.4×10⁻⁶` → 比允许值低 43 dB
9. 混叠衰减 `1/√(1+(35/12)²) = 0.324 → −9.8 dB`；要 −40 dB 需 5 阶
10. 抖动噪声 `31416×8×10⁻⁹/(2√2) = 8.9×10⁻⁵ rad` → ARW 0.035 °/√h（超标）
11. 延迟 `1.46+2+3+0.5 = 6.96 ms` → 带宽上限 `45/(360×0.00696) = 18 Hz`
12. 温漂 `5000×18×10⁻⁶×125 = 11.3 Hz`
