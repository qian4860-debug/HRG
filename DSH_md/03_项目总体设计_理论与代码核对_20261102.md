## 0. 先说三个结论

1. **项目不是"一个模型"，而是五个阶段的连续演化，主线一直是对的**：等价性 → 配置化 → 物理分层建模 → 指标推导 → 压电迁移。63 个提问里有 41 个在追同一件事：**"从机械原理一路推到电路指标"**。这件事到目前为止**只完成了文档层，没有完成工程层**。
2. **推导文档（尤其第五版总书）在文献层是扎实的，Lynch 的式(1)–(46) 被逐式走过；但代码里的慢变量方程与文档/物理不自洽**——我做了独立反演，**θ̇ 的阻尼各向异性项大了 2 倍，频裂项大了 2 倍且符号相反**（详见 §3.3）。这不是排版符号问题，是同一物理系统下自洽性检查失败。
3. **学习资料解决的是"怎么做工具流程"，不解决"该定什么数"**。它的思路是"工具手册 + 流程脚本 + 单元范例"；HRG 项目缺的是中间那张**指标分配表**。补法只有一条：**先把表头测出来，再用误差预算倒推，最后用签核矩阵锁死**（§5、§6）。

## 3. 公式推导是否符合 Lynch

分三层判定。**三层必须分开说，混在一起就会得出错误结论。**

### 3.1 文献层：Lynch 的骨架是什么

从原文（9 页扫描，OCR 质量差，但式(5)(6)(10) 可辨）与第五版总书的逐式转写，Lynch 的骨架是：

| 要素 | Lynch 的写法 | 换算到"物理驻波角 θ" |
|---|---|---|
| 四个参数 | `1/τ`（平均阻尼率）、`Δ(1/τ)`（阻尼差）、`ω₀`（平均频率）、`Δω`（频率裂） | 同左 |
| 各向异性角度 | 以 **2θ** 出现在式(6)：`cos2θ_τ, sin2θ_τ` | 物理驻波角 θ 下即为 **4θ**：`cos4θ_τ` |
| 变量 | 复包络 → 四个 IQ → `E, Q, R, S, L`（或 `a, q`） | 同左 |
| 平均法 | Pauli 矩阵 + 旋转参考系 + 只保留慢变项 | 同左 |

**关键一点（也是最容易被误判的一点）**：Lynch 原文里的角度是"模态角"，写成 2θ；项目代码写 4θ 是**同一件事的两种记号**，只要 `θ_Lynch = 2θ_物理`，`cos2θ_L` 就等于 `cos4θ_物理`。**所以"项目用 4θ、Lynch 用 2θ"不是错误。** 第五版总书 §9.1 已经说明这一点。

### 3.2 文档层：项目的推导书符合，而且比原文细

第五版总书做到了三件多数论文没做的事：
1. **逐式演算**：Lynch 式(1)–(46) 每条都给出中间步骤（乘积法则、消元、符号检查），不是抄结果；
2. **主动记录印刷符号不一致**：如"原式(8)：一个必须标出的符号不一致"、"式(39)：扫描原式对 q 写了正平方根…不能直接覆盖正交误差经过 0 的有符号控制"；
3. **把控制环也推了**：式(42) 补充里指出 `T_i = K_p/K_i = 2τ_c`，"漏掉这个 2，就把积分强度加倍"。

这一层的判定：**符合**。它甚至比多数引用 Lynch 的论文更严谨（多数论文只抄四项参数和 4θ 谐波，不讲归一化与符号）。

### 3.3 代码层：**不自洽**——我做了独立反演

**方法**：不依赖任何一篇文献的排版符号，直接积两自由度线性振子

```
M q̈ + C q̇ + K q = 0,   C = 2γI + Δ(1/τ)·A(θ_τ),   K = ω₀²I + 2ω₀·δ·A(θ_ω)
A(θ) = [[cos4θ, sin4θ], [sin4θ, −cos4θ]]
```

把 x(t), y(t) 按恰好一个载波周期做滑动平均解调，得到 `Cx,Sx,Cy,Sy`，再用**代码自己的定义**算 `E, Q, R, S, θ = atan2(S,R)/4`，数值微分后与代码 `local_plant_step` 的右端逐项拟合。参数取 f₀=100 Hz、Q=10⁵（τ=318 s，等效慢动态与 5 kHz/Q=2×10⁶ 一致），Δ(1/τ)=2.5×10⁻⁴、θ_τ=17°、Δω=2π·Δf、θ_ω=41°。

**结果（本机 MATLAB 实跑）**

| 检查 | 代码写的 | ODE 反演得到的 | 判定 |
|---|---|---|---|
| Ė 的阻尼项 | `−2γE − Δ(1/τ)cos4(θ−θ_τ)·E` | 同形，量级一致（比值 0.89，含我的数值偏差未清零） | **符合** |
| θ̇ 的阻尼各向异性项（Case A，Δf=0，Q/E=6.9×10⁻⁷） | `+0.5·Δ(1/τ)·sin4(θ−θ_τ)` | 最佳拟合 **k = +0.2500** | **大了 2 倍** |
| Q̇ 的频裂项（Case B） | `−2·splitRad·E·sin4(θ−θ_ω)`，`splitRad=2πΔf` | 拟合系数 1.05×10⁻⁴ ≈ `splitRad`(1.26×10⁻⁴) 的 0.83 倍，约为代码值的 **1/2.4** | **大了约 2 倍** |
| θ̇ 的频裂项（Case B） | `+0.5·splitRad·(Q/E)·cos4(θ−θ_ω)` | 拟合 **−3.1413×10⁻⁵** = **−0.25·splitRad**（4 位有效数字吻合） | **符号相反，且大 2 倍** |

**结论**：代码的 θ̇ 两个各向异性项与 Q̇ 的频裂项，各差 2 倍；θ̇ 的频裂项还差一个负号。**Ė 是对的**——这正好解释了为什么"能量环看起来正常"却仍然有角度漂移。

**为什么会这样（我的判断）**：`splitRad = 2π·Δf` 是**全裂距**，Lynch 的 `Δω` 是**半裂距**（`ω₀±Δω/2`）；`A(θ)` 矩阵的 cos4/sin4 权重本身带 2；两处约定一混，就出现"整体系数 2×"。而 θ̇ 的负号来自 4θ 旋转方向（被动/主动旋转）与 `R,S` 定义次序（`R=Ecos4θ, S=Esin4θ` 还是反过来）不一致。

**影响面**（必须重算的东西）：
- 所有"阻尼不均匀/频裂导致的角度漂移"仿真数值（量级错 2 倍、方向错）；
- FRP 九参数回归的 `θ̇` 观测方程 → **训练出的 `sin4θ/cos4θ` 系数没有物理含义**，只能当等效拟合；
- 谐波前馈 `p.comp.*Hat` 用的是同一组系数 → 前馈量错 2 倍；
- 论文里任何"补偿了 X% 的 4θ 漂移"都不成立，直到系数改对。

**怎么定性这件事**：不是"项目错了"，而是**"文档对、代码没跟上"**——第五版总书 §9.4 已经写了"同名 L、不同 Q 的逐项对照"，说明作者知道这里有约定差异，但代码没有按对照表实现。

### 3.4 还有一个比系数更根本的问题：模型结构

代码的机械模型是 **(E, Q, θ) 三变量极坐标**，而 Lynch 的是 **(a, q)** 或 **(E, Q, R, S, L) 四变量**。在 Q≪E 时两者等价（`√(R²+S²)=√(E²−Q²)`），但：

- 代码的 **Q̇ 里没有 R、S 的耦合项**。Lynch 的四变量方程在 4θ 上是相互耦合的；极坐标投影在 Q/E 不小（例如频裂 0.008 Hz 时 Q/E 可达 0.5）时不再成立；
- 更严重的是**载波与模态没有耦合**：代码里载波相位是 `resPhase += 2π·f(E,θ,T)·Ts` 积分出来的，`L` 由解调这对"合成载波"得到。真实的 `L` 来自模态自身的相位。**所以 DPLL 现在锁的是自己造的载波，不是模态**——这解释了为什么 `phaseErrorRms=0.005` 很好看，却没有人能证明它在真实谐振子上成立。

### 5.2 但资料里**恰好有**三份把这件事做对的范例

**(a) 张欢博士论文（最重要，同校同院）**——它的链条是：

```
系统级噪声模型（式 4-16，把 S_MEMS/S_CV/S_PGA/S_ΣΔ/S_DAC/S_FB 加权到输出）
 → 判定瓶颈是 C/V 与耦合噪声
 → 定目标 8.36 nV/√Hz + 4.56 fA/√Hz @12 kHz
 → 扫 W3/L3 = 160/320/640/1280 μm：W≥320 后闪烁噪声不再主导但电流噪声上升
 → 定 W3/L3 = 320 μm/3 μm
 → 全差分 C/V，实测 10.91 nV/√Hz、14.87 fA/√Hz
 → 正交校正 4.3 → 0.13 °/h；温补 92.75 → 5.69 °/h
 → 0.18 μm BCD，4.2×4.5 mm²，工程批流片
 → 整机 0.7 °/h、0.03 °/√h
```

这不是"教科书流程"，是**一条从整机指标一路压到晶体管宽长的完整证据链**，而且每一步都有数字。

**(b) 安琦开题（最干净的一条链）**：3.3 V/16 bit → 1 LSB = 50 μV → 需分辨 0.5 LSB = 25 μV → 选动态 LATCH 比较器。

**(c) 折叠共源共栅设计例**：10 mW/3.3 V → 3 mA → 每支路 1.5 mA → 摆幅 1.95 V → 分配 VOD(0.4/0.35/0.3) → 平方律得 W/L → L=1.4 μm → AC 10–300 MHz 得 UGB 164 MHz。

**这三份的共同点：每一级都写成"指标 → 约束 → 器件参数 → 验证量"，而且给出被放弃的分支（16 阵元缩 4 阵元、W3 取 320 不取 640 的理由）。**

**表 1 · 误差预算表（从上到下，每层都要有数字和出处）**

## 6. 如果我是项目负责人

### 6.1 我会先承认一件事

**这个项目现在的瓶颈不是"缺一个新算法"，而是"缺一个能签字的规格"。** 63 个提问里 41 个在问推导，但没有一次问过"我们的目标 ARW 是多少、谁来签"。没有目标，所有仿真都只能得出"看起来还行"。

### 6.2 总体设计：一个 V 模型 + 三张表 + 一条红线

```
L0 任务指标（ARW/BI/SF/量程/带宽/温度/功耗/面积）
      │  ① 误差预算表（每层带数字与出处）
L1 物理与误差源（Lynch 四参数 + 压电换能 + 电极几何）
      │  ② 接口契约表（量纲/Q格式/valid/延迟/饱和）
L2 架构（模拟前端 / 驱动调制 / 数字核 / 时钟 / 校准）
      │
L3 电路与 RTL（OTA/CV/ADC/DAC/PLL/NCO/CIC/CORDIC/PI）
      │  ③ 签核矩阵（指标←选择←证据←签字）
L4 验证与硅（MATLAB→定点→RTL→FPGA→MPW→器件）
```

**一条红线**：**L 与 L+1 之间不许跨层借证据**。用 MATLAB 说"RTL 已实现"、用 FPGA 说"硅已达指标"、用同模型 Oracle 说"物理真值"——这三种是本项目已经出现过、也最容易被审稿人抓住的越级。

### 6.3 我会立刻改的五件事（按顺序）

| 顺序 | 动作 | 理由 | 工时 |
|---|---|---|---|
| 1 | **把 θ̇/Q̇ 的三个系数改对**（0.5→0.25、2→1、符号） | 不改，后面所有漂移/标定/论文数字全部要重算 | 1 天 |
| 2 | **删掉载波里的频裂调频项**，让频裂只通过 Q̇/θ̇ 起作用 | 现在重复计入 | 半天 |
| 3 | **重建载波—模态耦合**：载波相位由模态自身的 `L` 反馈，而不是自由积分 | DPLL 现在锁的是自己造的载波，这是"数字闭环"名不副实的地方 | 1 周 |
| 4 | **角度输出改回直接角** `−unwrap(Φ₄/4)/B`，速率由微分得到 | 全角模式的核心卖点就是直接测角 | 2 天 |
| 5 | **写规格表**（表 1 + 表 2），哪怕一半格子填"待测" | 没有它，S3 阶段"用波形定指标"的原始意图永远落不了地 | 3 天 |

### 6.4 我会怎么定电路指标（把张欢的链条搬到压电全角）

```
ARW 0.03 °/√h
 → 惯性角噪声 8.7×10⁻⁶ rad/√s
 → 模式角噪声 2.4×10⁻⁶ rad/√Hz（×B=0.277）
 → 1 kHz 输出、每样本 7.6×10⁻⁵ rad
 → 相对幅值噪声 δA/A = 1.5×10⁻⁴（A=√E=1）
 → 解调后 I/Q 噪声 σ = 1.5×10⁻⁴ 量级
 → 40 样本匹配滤波白噪声允许 σ_adc = σ·√(N/2) = 6.7×10⁻⁴
 → 折算 ADC：18 bit、FS=2 时 LSB=1.5×10⁻⁵，允许噪声 ≈ 44 LSB
 → 结论：**数字侧完全够，模拟侧只需 SNR≈76 dB/1 kHz**
 → 真正约束：电荷放大输入等效噪声 ≤ (7.6×10⁻⁵)·Θ_s·a，AAF 在 35 kHz ≥40 dB，
   驱动相位误差 ≤ 0.1°（否则正交串扰进角度）
```

这条链里唯一缺的两个数是 **Θ_s（C/m）** 和 **a（m）**——正好是 §7 要测的。**所以"测表头"不是准备工作，它是指标链的唯一缺口。**

### 6.5 十个我认为更好的思路

1. **把"指标"提前到"模型"之前**（现在的顺序是反的）：先写一页 A4 的《设计目标与验收口径》，再建模型。
2. **用"证据分级"代替"版本递进"**：E0 文档 / E1 同模型仿真 / E2 独立模型 / E3 RTL 逐位 / E4 FPGA / E5 器件。任何结论必须标级，**不许跨级引用**。V2→V10 的版本号没有信息量，E 级有。
3. **给每篇论文/专利先写"不可辨识反例"**：审稿人最认负面结论；而且反例一旦成立，正面结论的边界就自动清楚了。
4. **把表头表征做成"可复用的台架资产"**：T0–T7 协议 + 自动出 `identified_profile.json` + 不确定度。这套东西一旦建成，后面每换一只表头都是一天的事。
5. **驱动调制放到数字域，与解调共用同一个 NCO 相位**（相位同源）。这样 DPLL 相位、驱动相位、测角相位在同一个相位坐标系里，才有可能把"相位误差"与"机械正交"分开。
6. **用"双振幅"取代"双方向"做可辨识性激励**：现在靠正反虚拟进动（FRP），但换向落在规范群方向的风险很高（我上一轮已指出）；改变能量 E 是正交方向，秩增益更可靠。
7. **把"故障可观测性"当一等公民**：现在 `passFaultSafety=0`。ASIC 的可靠性不是 ESD 打几分，而是**出错时不给假数据**。先做"故障注入 → 输出置无效"的闭环测试。
8. **每个校准参数带"可辨识状态"三值标签**（identified / bounded / not-identifiable）。没有这个标签，任何"在线自校准"都不能上线。
9. **设一个"红队"角色**（可以是我，也可以是子代理）：每周专门攻击"这个结论是不是真值泄漏/同模型自证/窗口挑选"。本项目有三次这类风险已被识别，但都是事后发现的。
10. **流片前先做一次"纸面硅"**：把每个模拟块的指标、失配、PVT、寄生写成表，用蒙特卡洛在系统模型里跑一遍，看整机 BI/ARW 分布。**如果纸面硅都过不了，就不要流片。**

|---|---|---|---|
