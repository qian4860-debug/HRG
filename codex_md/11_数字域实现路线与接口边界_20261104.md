# 数字域实现：压电全角测控的执行路线

日期：2026-11-04。用户明确选择“在数字域实现”。承接[10号规划](10_读DSH10与11后的下一步路线_20261104.md)，确定数字载波驱动、数字I/Q及数字控制/校准/导航主线；压电驱动、压电检测与WA全角模式固定。

## 1. 当前架构决策

```text
压电检测端口 → 电荷读出/必要模拟滤波 → 双通道同步ADC
    → 数字去嵌与串扰残差校正 → 共享NCO数字I/Q
    ├→ 低延迟幅相观测 → 数字AGC/正交/PLL → 双轴力分配
    │    → 数字载波调制 → 两路快DAC → 重建/驱动 → 压电驱动端口
    ├→ 精细角度估计 → 时间戳/不确定度/全局参考管理 → 角度发布
    └→ 慢速辨识与校准监视 → 更新门控 → 系数与状态切换
```

快反馈和精细输出是拟验证的分工，尚未证明优于同一估计器同时反馈/输出。校准只实现有独立信息支持的部分，不承诺所有表头参数都能无参考恢复。

模拟域承担压电信号转换、必要抗混叠、转换器接口、重建及驱动。必要模拟链的噪声、加载、带宽、串扰和饱和必须留在闭环模型；数字校正不能恢复ADC前削顶丢掉的信息。

模拟I/Q、慢DAC后模拟调制不再作为近期并列实现任务。历史比较文档保留，当前主方案不再等待2×2全组合比较完成。

## 2. 第一项必须补齐：三个慢命令到两路载波

旧RTL输出能量、正交、虚拟进动三路慢码；它们是控制坐标，不能直接当成X/Y两轴载波电压。当前压电MATLAB的`sn_tick.m`已有双轴复相量调制，可作为推导参照，仍需核对力/电压单位和标定边界。

数字核需要实现：

\[
[u_E,u_Q,u_V]\rightarrow[F_x,F_y]\rightarrow[V_x,V_y],\qquad
v_j[k]=\Re\{V_j[k]e^{i\phi[k]}\},\quad j=x,y.
\]

其中F/V为按约定归一化的复载波系数；映射包含驻波方向、驱动矩阵及实际作用相位。公式不指定尚未核定的硬件Q格式。载波NCO与解调共享时基，ADC取样、控制更新及DAC作用的相位差应按真实延迟补偿。

两路快DAC是一般双轴直接驱动接口；物理表头若需差分、多电极或额外偏置，应在端口映射层展开，不能仅凭仿真两输入断言实物一定只需两个引脚。

## 3. 时序与数值合同v0要明确什么

| 对象 | 当前可用依据 | 本轮决定/待验项 |
|---|---|---|
| 载波/ADC采样 | 当前压电合成基线f0=1 kHz、fs=40 kS/s | 先作调试配置，实际表头频率未知；不当成厂家指标 |
| 控制更新 | 当前40点一帧、1 kHz更新 | 先保留基线；窗口支持、发布率和系统时钟分别定义 |
| DAC输出 | 逐载波采样数字合成两轴电压 | 定义请求码、实际码、作用时间、量程、削顶与回读/重建关系 |
| ADC/DAC位宽 | 压电模型与旧RTL默认值不同 | 显式写明转换比例、舍入及饱和；不可无说明截位或直接复用旧golden |
| 相位与角度 | 共享NCO；模态平面角、周向角、机体角不同 | 明确符号、展开周期、Bryan换算及虚拟进动实际作用扣除 |
| 校准与协方差 | A0–A3是条件性浮点研究链 | 先仅输出验证；逐步分配到数字核、低速任务或上位机；未定硬件映射不称完整片上实现 |
| valid/状态 | 采样、可控、校准可更新、全局角可发布含义不同 | 分开定义；复位、缺帧、饱和和重锚定逐状态对拍 |
| 系统时钟/资源 | 需指定目标器件/库和实际约束 | 先B0测基线；不虚构Fmax、功耗、面积或最终位宽 |

## 4. 按此顺序执行

1. **数字接口合同v0**：固定物理基线、原始记录和控制坐标，明确三命令→双轴电压映射及上述时序/数值边界。
2. **A4最小旋转闭环**：Ω进入真实机械科氏项；保留原控制，A2/A3先只输出；验证挂接不改变驱动与机械状态。
3. **数字支路对照**：原链、精细估计仅输出、低延迟估计进反馈。共同检查建幅、能量、Q、PLL、角度、返回比、饱和和缺测恢复。
4. **整数golden与RTL**：先实现双轴力分配、数字调制/快DAC接口，再移植解调与控制改进；复杂辨识/协方差按频率、存储和误差预算逐项映射，不照搬浮点Python。
5. **scoreboard与综合**：逐拍核对码值、valid、源/可用/作用时间、舍入饱和及状态；同时保留独立物理评分。B0旧RTL映射/时序可并行，最后形成同精度/动态约束下的资源比较。

5 Hz仍是待确认的现有设计假设，不因选数字域就保证稳定；提高系统时钟也不会自动缩短固定采样窗口的物理时间支持。先建立返回比与实际时间账本，再确定控制带宽。

本轮完成的是路线决策和接口边界收敛；尚未实施上述新RTL或完成A4闭环验收。下一项具体工程交付是数字接口合同v0及三慢命令到双轴载波的独立scoreboard基线。
