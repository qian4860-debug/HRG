## AD9215 原始码约定

- CSV 保留第 41 号字段。检测接通的采样拍为 `sense_tick=0`。每帧间距 3200 拍，5.44 MS/s。每帧导出 1600 个观测拍及实测输出延迟对应的尾拍。共同延迟为 5 拍时，应导出 `sense_tick=0…1604`。原始 `sample_index` 不重编号。
- 表中 `adc_x_code` 与 `adc_y_code` 为该行在采集接口看到的**输出码**。`adc_clip` 为同一输出拍两轴实际过载位的或。独立驱动参考、门控和时标记录的是该行对应的**采样拍**。转换器用第 (k+d) 行的码和过载位配第 (k) 行的见证参考，保留 1600 个采样拍。现入口要求 X/Y 具有相同整数总延迟，若实测不同先在导出端各自对齐，再按统一口径导出并冻结配置。
- Offset binary 用原始 0…1023 减 512；未扩展二补码字在 512…1023 区间减 1024；已正确符号扩展用 −512…511。名义差分电压为中心码乘以实测或明确记录的 Vpp/1024。2 Vpp 为 1.953125 mV/码，1 Vpp 为 0.9765625 mV/码。10 位码原样记录，保留位对齐、MODE、极性和差分量程测量证据。[AD9215 数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/ad9215.pdf)
- 器件名义延迟为 5 拍，实际需核对包括 FPGA、整拍接口标记在内的总延迟。用同源触发的有标记阶跃或非周期序列同时记录两轴模拟输入、采样时钟、ADC 输出和 OR，按两个轴分别定位输入采样与码跳的拍差，分别复测正负阶跃并核对零输入码。6.8 kHz 正弦用于对齐后的残余相位检查。转换器只核对时标格点并应用给定拍差，板上实物拍差和参考相位由这项校准提供。

## 运行命令

在 `research/drive_reference_blind_20261115` 下运行。以下示例的 2 Vpp、偏移二进制、5 拍应换成该次台架记录的参数。校准与盲测复用同一套已核验的配置，原始仪器文件及实际路由证据随采集包保存。

```powershell
python prepare_blind_capture.py convert calibration.csv calibration_labels.csv calibration.npz --ad9215-coding offset-binary --differential-vpp 2 --observed-delay-cycles 5
python prepare_blind_capture.py convert blind.csv blind_labels.csv blind.npz --ad9215-coding offset-binary --differential-vpp 2 --observed-delay-cycles 5
python blind_drive_reference.py score.json --calibration calibration.npz --blind blind.npz --metadata capture.json
python check_ad9215_capture.py
```

旧入口继续接收已经对齐的 16 位、2 Vpp 协议整数。新增 NPZ 字段记录逐样本过载、码制、码步和应用后的整数延迟参数，供以后做恢复时间归因。

## 已验收与下一步

- 合成对拍覆盖三种码制、1/2 Vpp 和 0/5/7 拍，共 18 组。逐样本比较电压、两轴见证参考和输出过载归属。窗外前导过载剔除，首末两端和最后一个样本的过载按采样拍归属。
- 缺尾拍、帧内缺样、超码域及超 0.1 拍时标偏差全部拒绝。旧 16 位协议仍通过 14 帧校准、28 帧盲测的 CSV → NPZ → 评分流程。
- 实体假负载接通后，先采延迟与零点证据，再按第 41 号采校准和盲测。若两个轴的见证参考不同源、总延迟不同或有效量程无法确认，先解决采集对齐。后续按“当前输入相同、前史不同”成对归因。本轮验收只覆盖合成输入与文件格式。
