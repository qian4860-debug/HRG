# 30 · 不分时五电极模块化样机组装与调试

2026-11-10。以现有五电极连续驱检模型为基线，A/B 驱动 X/Y，C/D 检测 X/Y，四组各占一个端口，共用 COM。端口名称是模型映射，实际针脚、极性、COM 偏置和机壳接法须以表头与模块资料确认。初始载波频率约 6.8 kHz，模型 ADC/DAC 速率均为 1.088 MSPS，按实际模块能力配置并更新数字算法采样周期。

```text
FPGA DAC_X/Y → 双路 DAC →（电流型加 I/V）→ 重建滤波、驱动 X/Y → A/B
C/D → 两路 thx2024 C/V → 抗混叠、量程及共模适配 → 双路同步 ADC → FPGA
FPGA：共用时钟基准、DDS、数字 I/Q、全角控制、限幅、互锁、USB/串口日志
COM：按表头与 C/V 输入偏置确定低阻回流；机壳单独按接口图连接
```

## 模块与接口

- C/V 需要两条连续读出链，可用双通道模块或两块单通道板。短线接 C/D，靠近表头。实测两路 C/V 到数字码的复增益，驱动则测数字码到 A/B 相对 COM 电压的复增益。把两侧单位换算和前置等效系数按模型归一化，分别校准增益、极性和相位。
- ADC 需双通道同步获取。两块板可共用采样触发，但须核实支持外部同步、数字数据是否同一拍，校正固定延迟。核对 C/V 输出摆幅、ADC 单端或差分、每脚共模、输入阻抗与建立要求。按需增加滤波、缓冲或差分转换。
- DAC 需两路可独立给码，可共用更新触发。核对输出类型、幅度、零码及上电默认状态、更新协议和输出驱动能力。压电驱动的正弦电容负载预算为 `Ipk = 2*pi*f*Ceff*Vpk`，`SR = 2*pi*f*Vpk`。600 pF 是待确认的组端模型值。6.8 kHz、600 pF 假负载下约 25.6 µA/Vpk，另计线缆、互耦和瞬态裕量，并实测闭环稳定性和驱动限幅。
- FPGA 以共同时间基准生成 ADC 触发、DAC 更新和 DDS 相位，明确接口逻辑电平、编码格式、有效沿与数据延迟。双路 16 位、1.088 MSPS 时，ADC 原始负载约 34.8 Mbit/s，串行协议额外位数和帧间隔另计。DAC 方向独立核算。FPGA 在线解调并抽取，PC 下发配置及接收低速日志或短段原始码。
- 用底板接插件固定各板，C/V 输入最短，驱动与数字时钟远离敏感节点。为表头 COM、模拟回流、数字回流和机壳画实际接地路径。供电按各模块电压、参考和上电顺序，检查示波器、PC USB 和模块地是否形成额外回路。先确认 COM 电位及其与机壳、保护地的关系，再接地夹或同轴屏蔽。

## 上电与闭环顺序

| 阶段 | 做法 | 过关条件 |
|---|---|---|
| 0. 冻结针脚表 | 列五电极针脚、每板供电和数字电平、模拟量程及共模、ADC 时钟和 DAC 更新、允许的压电驱动电压与限流值。驱动默认禁能，定义急停和掉电状态。 | 表头端口与厂方或低激励辨识结果一致，COM 参考和各路保护状态有记录。 |
| 1. 各模块通电 | 先测电源和参考，向 ADC 两路送同源已知正弦以检查码型、通道顺序、同步及幅相。DAC 输出安全常值、正弦，确认满量程与更新。 | 无丢码或错序，输入不越界，限幅、禁能和上电安全码有效。 |
| 2. 假负载整机 | A/B 接电容到模拟 COM，可先用模型名义值验证，再换实测等效负载。C/D 用已知小电容注入小信号，`Q=Cinj*ΔV`，扫两路幅相和注入串扰。驱动开关前后记录底噪和同步馈通。 | 驱动带载稳定，两路 C/V 未饱和，数字 I/Q 可重现已知相位和幅值。 |
| 3. 接表头开环 | 断电接线后先读底噪。再用受限小信号分别激励 A 和 B，C/D 一直采集，扫频和停驱记录振铃。拟合双轴复传递矩阵、极性、驱检馈通、频率和 Q。 | 能分辨停驱后的机械响应与即时电馈通，确认 X/Y 映射、量程和闭环极性。50 mHz 小频差靠长记录和模态辨识估计。 |
| 4. 逐环接入 | 用受限开环信号起振，捕获后先接频率或相位跟踪，再接幅值控制，最后接正交控制与全角估算。全角运行的驱动力分配按现有模型，保留振型转动自由度。 | 记录原始码、I/Q、振幅、频率、DAC 指令、角度和故障标志。通过静止、已知小角度或低速正反转检查符号、标度、漂移和复位。 |

初始小信号电压上限、COM 接法和各模块引脚无法由模型推定。记录实测与假设，后续回填实际电极端电容、C/V/DAC 增益、通道延迟和驱检串扰。
