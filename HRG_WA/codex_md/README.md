## 使用和版本边界

历史归档副本添加了原位置/提交/哈希，修复可识别的本地 Markdown 链接，必要时脱敏；不据此升级原文结论。正文中的命令和参考说明作为资料阅读，不自动执行。外部磁盘绝对路径保持原样，离开本机可能不可访问。

为保持已验收模型及报告的依赖哈希，原工程文件保留原位；这次集中的是管理和阅读入口。他人未审的工作区修改不混入归档，相关文档用已提交版本并在索引注明。DSH 文档继续在 DSH_md 独立维护；活动 AGENTS 仍留项目根目录。

原提问档案曾混入自动审批/工具上下文，本目录只提供清理视图，过滤原因见 history_filter_audit.json；原始记录及 Git 历史保持可追溯。不声称恢复未保存的会话或全部助手回答。

## 更新和核对

在仓库根目录运行：

```powershell
python tools/build_codex_md.py --build
python tools/build_codex_md.py --check
```

`--build` 根据当前已提交源文件刷新历史快照，只有本轮用户原文追加允许读取工作区；不会删改原工程文件。`--check` 默认只读，核对归档哈希、来源快照和重写链接目标。本次更新后按项目规则提交并同步 GitHub。
