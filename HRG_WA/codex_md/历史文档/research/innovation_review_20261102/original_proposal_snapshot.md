### 0.2 我从代码里读到的、决定创新点的硬事实

这些是可以直接指到文件行号的技术事实，也是我提出下面五个创新点的物理出发点：

1. **本振是全链最大的一块组合逻辑。** `hrg_nco.v` 里 `sine()` 是 **40 级展开的 CORDIC**，数据通路 **x,y 各 56 位、z 50 位**，`atan_turn` 是 40 项 50 位常数表；而 `cos_sample_o=sine(next_phase+90°)`、`sin_sample_o=sine(next_phase)` **把这个 40 级链算了两遍**。两条 40 级 56 位加减链完全组合展开，直接压住 Fmax。
2. **采样率与控制率给了巨大的时序松弛，但没有被利用。** 40 kS/s 采样 + 50 MHz 时钟 ⇒ 每采样 1250 周期；1 kHz 控制 ⇒ 每控制拍 50000 周期。NCO、除法、乘加全都做成了"一个采样内组合完成"。
3. **链上有三个常数除法。** `hrg_dsp_core.v` 的 `mix_round` 做 **`/131071`**（2¹⁷−1）；CIC 归一化做 **`/64000`**（=(RM)³, R=40）；FIR 做 **`/9`**（1:2:3:2:1, 权重和 9）。三者都是常数除法，但写成通用除法语义。
4. **CIC 用了 96 位积分器。** 4 通道 × 3 级 = **12 个 96 位累加器**，另有 12 个 96 位延迟寄存器。
5. **不变量运算是 8 个 28×28 乘法器**（E/Q/R/S/L 各两次平方或乘加），结果截到 Q8.24 并饱和。
6. **导航块用了 128 位中间量，并含一次 128 位÷30 位变除数除法。** `hrg_navigation.v` 用 `128'sd…` 做相位增量乘 90×2¹⁶、除以 `bryan_q30`、再乘控制率除 256；这是全链第二大、且最容易被忽视的资源与关键路径。
7. **测角 CORDIC 是 18 次迭代、32 位、1 拍 1 次**（`hrg_cordic.v`），24 位四倍角相位码；这里的迭代复用已经做对了——这恰好说明"迭代复用"本身可行，问题在于没人把它用到 NCO 与除法上。
8. **专利草案与 RTL 不一致。** 草案权利要求 2 写的是"四分之一周期查找表 + 象限判断 + 符号恢复"，而 RTL 实际是 40 级 CORDIC。这个不一致必须先把文书统一，否则会影响创新点二的新颖性表述与专利稳定性。

### 0.3 三条不能越过的红线

1. **模拟器真值仍在进入算法。** `HRG_WA_v46_simulate.m` 用外部真实角速度给 FRP 零速许可、把 DAC 实际输出传给估计器、温度零偏估计与真实模型共用参数。在修掉之前，任何"在线自校准"主张都不成立。
2. **Oracle 是同模型等效拟合**，不是独立真值；"独立验证"目前是域内温度（训练 15–45 ℃、验证 18–42 ℃）。
3. **三个 advanced 原型当前数值不收敛**：`phaseSelfCal` 误差 1.56°（真值 0.0384 rad）、`nonlinearityCorrection` 估计 ≈0（真值 0.035/0.02）、`physicalFrp` `mechanicalError` 0.309。**五个创新点一个都不能建立在它们上面。**

### 创新点一　全角测控的"角域可辨识性"：规范自由度、不可辨识反例与最小附加激励

**一句话主张（可证伪）**
> 在只有 I/Q、控制命令、温度与状态字可观测的条件下，2×2 等效检测增益矩阵 + 2×2 驱动增益矩阵 + 机械各向异性（阻尼差、频差）+ 相位延时这组参数，在**单一恒能量、单向进动轨迹**下存在维数 ≥3 的等价变换（规范）自由度，其观测分布完全相同；因此"九参数全可辨识"在原理上不成立，只能辨识若干不变组合。给出破除该退化的**最小附加激励条件**及其对导航扰动的上界。

**科学问题**
不是"再加几项误差、再换一个估计器"，而是：哪一组参数组合可以被唯一恢复？哪一组只能得到等效组合？需要多少、何种附加激励（第二振幅 / 检测坐标换向 / 双向虚拟进动 / 双探针）才能把目标参数的 Fisher 信息秩提上去？代价是多少导航误差？

**数学骨架（可直接开算）**
观测方程取离散慢变量形式，参数向量 η = vec(H, G, Δ(1/τ), Δω, τ_p)，灵敏度矩阵与 Fisher 信息

```
J_k = ∂ŷ_k/∂η ,      F = Σ_k J_kᵀ R_k⁻¹ J_k
```

要做三件事：
1. **构造不可辨识反例**：给两组不同 η，使整段 I/Q 序列差 < 1e-12，但 η 差 O(1)。这是全文最有说服力的一张图。
2. **求零空间与规范固定**：给出等价变换群（尺度归一、检测坐标旋转、4θ 相位规范、能量/幅值归一）的维数与显式生成元，说明每个自由度的物理含义（例如"检测增益的整体尺度"与"能量参考"不可分）。
3. **激励的秩增益**：在"驱动/ADC 饱和、机械能量上限、标定时长、导航误差"约束下，用 D-最优/最小奇异值最大化选激励轨迹；给出"换向次数 N_min"的充要条件。

**与 2026 前沿的差别**
FRP（TIM 2026）、多误差分离（TIM 2025）、双向转台检测电极（TIM 2026）、LSTM-PINN 高阶基（MSSP 2026）全部是"给定基函数 + 回归 + 补偿"，都没有回答"可辨识性"。R14 只给开环量化机理。**"给出不可辨识性反例并设计破除它的最小激励"在公开文献里是空位。**

**为什么你的资产能做**
- `HRG_WA_v46_frp_basis.m` 已有九参数基 `[1, sin4θ, cos4θ, sin8θ, cos8θ, ΔT/20, (ΔT/20)sin4θ, (ΔT/20)cos4θ, d]`，条件数 4.80、整周覆盖 1.0，是现成的回归对象；
- RLS 与等价批量 LS 已对齐到 3.25×10⁻¹⁰，说明"递推 ↔ 批量"数值链是干净的，可放心把差异归因到"信息结构"而不是求解器；
- 已有门控/置信度/覆盖率/冻结 A/B 全套流程，改激励只需换输入轨迹。

**最小可交付证据（图表级）**
1. 反例：两组 η 的 I/Q 重合图 + 参数差表；
2. 零空间维数与生成元表；
3. 激励前后 F 的最小奇异值/条件数曲线（等时间预算）；
4. 参数置信椭圆收窄对比；
5. 非零速**全窗口**累计角误差不恶化（防"用平滑掩掉真实运动"）。

**生死判据（先证伪，再投入）**
用 2 周做纯数值实验：若"检测坐标换向"恰好落在规范群方向上（即不增加秩），则换向无用，立刻改用"双振幅"或"双向虚拟进动"；若三种激励都不增加秩，则本点收缩为"等效误差补偿的适用边界"，仍是一篇可发表的负结论，但不再是博士主线。

**期刊落点**：Measurement（附件 §39，二区）主投；理论加强版（一般化到一类轴对称振动陀螺的规范可辨识性）可试 Signal Processing（附件 §51）。
**风险**：若只做出"标准持久激励条件"的重述，则不够。必须有一个**HRG 特有的结构性结论**（例如"4θ 与 8θ 系数在单轨迹下与检测矩阵的尺度和旋转完全混淆，必须靠第二振幅破除"）。

### 创新点二　延迟透明的多速率时间复用数字内核：除法自由、单旋转引擎与闭环等价性

**一句话主张（可证伪）**
> 现有全角数字链把"每采样内可并行铺开"当成前提，导致 2×40 级 56 位 CORDIC、12×96 位 CIC、三个常数除法、8 个 28×28 乘法器和 128 位导航除法同时存在于关键路径。在 40 kS/s / 1 kHz / 50 MHz 合同下每采样有 1250 个时钟周期，存在 1–2 个数量级的时序松弛。提出**延迟透明的多速率时隙调度**：用一个统一旋转/除法/乘加引擎分时服务，并证明"新增 L 拍延迟可用相位预推进 L·FCW 与 DPLL 环路相位折入精确抵消，闭环传递函数不变"。给出资源—延迟—精度的 Pareto 边界。

**科学问题**
在给定角度/速率误差、有效带宽、动态范围、闭环延迟与时钟约束下，**怎样把"时间的富余"换成"面积的节省"，同时不改变闭环动力学**？这是集成电路学科最正统的问题，而不是算法问题。

**三条可证明的技术结论（这是本创新点的骨头）**
1. **除法自由化。** 三个常数除法都能被移位加恒等式精确替代，且误差界可证：
   - `1/(2¹⁷−1) = 2⁻¹⁷·(1 + 2⁻¹⁷ + 2⁻³⁴ + …)`，取 3 项误差 < 2⁻⁵¹，远小于 18 位 LSB；
   - CIC 归一化 `/64000`：改抽取比或把归一化并入 FIR 系数，使除数为 2 的幂（或直接用 `1/64000` 的 2 项级数）；
   - FIR `/9`：把权重 1:2:3:2:1 改写为 `(1,1,1,1,1) + (0,1,2,1,0)` 两级移位加，或直接选 1:2:4:2:1 之类 2 的幂权和（代价是通带略变，需给出频率响应差）。
   - 导航的 128 位除法：Bryan 倒数是慢变量，改成"预先算好的 Q30 倒数常数 × 乘积 + 一次牛顿修正"，把 128 位÷30 位变除数除法整块消掉。**这一条单独就能写进 TCAS-II brief。**
2. **单旋转引擎。** 本振的 sin/cos、四路混频的旋转、测角 CORDIC 本质是同一个"相位 ↔ 向量"旋转。用一个 40 级（或粗 4 级 LUT + 细 3 级残差）迭代管线，按 1250 周期预算分时服务，并让 sin 与 cos 从**同一次旋转**出（而不是算两遍 40 级）。给出 ≤0.5 LSB 的严格误差界与"无杂散"条件（相位截断位数 vs 杂散电平）。
3. **延迟透明（本点最关键的、也最容易被审稿人挑的一点）。**
   - 本振相位是积分器：加 L 拍延迟，只需把相位预推进 L·FCW，**解调参考与载波严格同相**，误差为 0（常数除法/定点下为 1 LSB 级）。
   - 测角/导航的固定延迟可折入 DPLL 环路相位，等价于环路滤波器多一个已知零点，给出稳定性与相位裕度不变的证明。
   - 不满足上述条件的节点（例如 CIC 群延迟随抽取比变化）必须显式建模并纳入调度表，**不能靠"降采样后噪声变小"蒙过去**。

**与 2026 前沿的差别**
ECIE 2024 的全角数字 ASIC 前端只证明"能实现"；陈洋 2023 的 FPGA 定点只证明"能跑"；R14 是开环量化机理。通用 DDS/CORDIC 的时分复用与 Taylor 插值是成熟技术，**不新**。新的是：全角闭环下的**延迟透明等价性定理** + 三个常数除法在 HRG 定点链中的**严格误差界** + 在同一精度/带宽/延迟下的 PPA Pareto。

**为什么你的资产能做**
- 现成 RTL 与逐位黄金向量（前端 350 笔×9 字段零差异，闭环 4000 次更新零错，182889 周期）；

### 创新点三　角度谐波选择性抑制的空间换向读出（HSCR）：把换向图案当作角度陷波器设计

**一句话主张（可证伪）**
> 全角模式的角度相关零偏可按驻波方位展开为 4kθ 族。若把 N 个电极按 π/(2N) 间隔组成虚拟正交对并等权平均，则 4θ…4(N−1)θ 项在**一阶意义上精确抵消**，残差只剩 4Nθ 及以上；由此可以反解出"电极数—可抑制谐波阶数—噪声折叠代价（≈√(N/2)）—换向建立时间—控制带宽"的闭式权衡，并给出换向频率 f_c 的稳定性与混叠条件。换向图案不是"为了省通道"，而是一个**可按谐波阶数定制的空间陷波滤波器**。

**为什么这个抵消是精确的（可当场验证）**
设检测链各向异性造成的角度误差一阶项为 `ε(θ) = Σ_k a_k sin(4kθ + φ_k)`。把电极坐标旋转 α 后同一误差写成 `ε(θ−α)`。取 α = 0 与 α = 45°（8 电极、π/(2N) 且 N=2）等权平均：

```
[sin(4θ) + sin(4θ − 180°)] / 2 = 0
```

4θ 项被精确消掉，剩 8θ 项。取 4 帧（α = 0, 22.5°, 45°, 67.5°，16 电极）则 4θ 与 8θ 同时被消。这个结论可以用你现有的误差注入模型在 10 行代码内先验证，再谈电路。

**关键补充（否则会被误判为"又一个 TDM"）**
1. **参数化层级是新颖性的根**：在 2×2 等效增益矩阵层面，换向只是坐标旋转（落在规范群方向，**不增加信息**，见创新点一）；但在 **N 个电极的物理参数层面**（每极增益 g_i、相位 φ_i、位置偏 δ_i），换向提供 N 个不同的线性组合，使"每极误差"可辨识（只差一个全局尺度）。所以本创新点必须写成"**电极级参数化 + 换向观测 → 可辨识**"，而不是"多测几路再平均"。
2. **代价必须量化**：TDM 读取把 N 路噪声折叠，角度噪声密度上升约 √(N/2)；开关电荷注入与建立时间占用带宽；换向频率必须满足 `f_c ≫ 4·θ̇_max`（否则谐波被运动调制回来）且 `f_c ≪ f_carrier`（否则载波被切碎）。这三条不等式就是设计空间的边界。
3. **电路上要真的省**：DFT 合成系数只有 ±1、±1/√2（后者用 3 项移位加：1.4142 ≈ 1 + 0.5 − 0.0625 − 0.0156…），**不需要乘法器**；与现有 `hrg_dsp_core.v` 的四路混频 + CIC + FIR 结构同构，可直接参数化 N。

**与 2026 前沿的差别**
- 单通道 TDM（Micromachines 2025, 16:273）、八电极分时全角控制 + CORDIC 相位跟踪（CN116929322A）、双频载波全角控制（CN116576841B）：都是**通道复用/硬件节省**动机，没有谐波抵消的设计理论。
- 检测轴旋转 DAR（MSSP 2026, 258:114724）：**物理转动**检测轴，属于器件层；本点是**电域虚拟轴换向**，在环路内实时，且不需要额外机械结构。
- 双向转台检测电极误差辨识（IEEE TIM 2026）：**离线标定**；本点是**在线、无标定**。
（霍尔/磁传感里的 "spinning current" 是同一思想族，但在 HRG 全角读出里没有对应工作——这是可以正面引用的类比，也是查新时要主动排除的风险点。）

**为什么你的资产能做（但有一个硬前置）**
- 结构上：`hrg_dsp_core.v` 的四路对称通道、CIC 抽取、FIR、E/Q/R/S/L 不变量计算全部可参数化到 N 路；
- 模型上：MATLAB 支持逐通道增益/二次非线性/相位延时注入，可直接验证谐波抵消；
- **硬前置：必须先确认表头的电极数、分组与可独立寻址性。** 当前台账（2026-10-29）明确"电极位置/极性/引脚待确认"。若只有 8 个不可分组电极，N≤4 仍可做（4θ 抵消已是最大一项，证据强度略降）；若电极完全不可分组，则本点降级为"驱动侧换向"（驱动增益矩阵误差同样是零偏源，R07），或直接转创新点四。

**最小可交付证据**
1. 谐波抑制表：N = 2 / 4 / 8 对应 4θ / 8θ / 12θ 残差（解析 + 仿真）；
2. 角度噪声密度 vs N（噪声折叠实测曲线，证明代价真实）；
3. 建立时间/带宽预算表；
4. 多初始驻波角的静态零偏（角度相关偏置）改善；
5. 面积与功耗增量（相对四电极基线）；
6. 换向频率扫描的稳定性边界（失稳区必须画出来）。

**生死判据**
先做"谐波抵消"的 10 行数值验证 + 电极可寻址性确认。若电极不可分组，**立刻转创新点四**，不要硬做。

**期刊落点**：Measurement（附件 §39，二区）主投（测量机理 + 实验最匹配）；有明确电路结构可投 TCAS-I；压缩为单一结构可投 TCAS-II。
**风险**：这是五个点里"器件依赖"最强的一个，必须尽早拿到表头电极信息。

### 创新点四　定点闭环的"角度死区—极限环"机理与无死区量化整形

**一句话主张（可证伪）**
> 全角测角是 θ = (1/4)·atan2(S, R)。当方位向量幅值 |V| = √(R²+S²) 较小（低能量、接近正交零点）时，R/S 的定点量化使角度输出出现**周期死区**：θ 变化小于约 LSB/(4|V|) 时输出不响应，形成"粘滞—跳变"极限环。该极限环的等效零偏率与频率可由字长 b、能量 E、环路增益与更新率**解析预测**，并且会在 FRP 回归中被**误识别成 4θ/8θ 机械误差**。提出互补双量化/一阶误差反馈噪声整形结构，在相同字长下把死区宽度降低 1–2 个数量级，并给出"不引入新极限环"的稳定性判据。

**科学问题**
"数字化"本身不保证精度（这是 `00_总览` 的第 3 条结论）。真正的问题是：**量化误差在闭环里被环路增益整形后，落到了哪个频段？它会不会伪装成机械误差被标定吃掉？** 这是一个"实现—机理—标定"三者耦合的问题，比"再加两位位宽"深一层。

**可推导的三条关系**
1. **死区宽度**：δθ_min ≈ (1/4)·(Δ_LSB/|V|)，其中 Δ_LSB 是 R/S 的最低位权重。给定 E 与字长即可算出 δθ_min，并与本底噪声比较——**若 δθ_min 远小于噪声，则机理虽真但工程意义弱，必须改题**（这是本点的第一道生死判据）。
2. **极限环**：把"量化 + PI 环 + 抽取"写成非线性反馈，用描述函数法求极限环的幅值与频率，给出"环路增益 × 字长"的稳定域边界。
3. **与标定的混淆**：在 FRP 回归基上把量化整形开/关，观察 4θ/8θ 系数是否系统性漂移。若漂移显著，则**证明现有文献里一部分"机械谐波系数"其实是实现误差**——这是一个有冲击力、且可以被独立复现的结论。

**与 2026 前沿的差别**
R14（Micromachines 2026, 17:143）给的是**开环、单项**量化影响机理；陈洋 2023 讨论 FPGA 定点与角速率求解；目前没有"闭环死区/极限环解析 + 与标定的混淆 + 结构化消除"。这是本点唯一站得住的差异，必须三件事都做全。

**为什么你的资产能做**
- bit-true MATLAB 链 + RTL 定点链，可逐位注入舍入/饱和/回绕；
- 已有 `overflow`、`controlOutputLimitCount`、`piIntegratorLimitCount` 等诊断计数；
- scoreboard 支持长时运行，可做极限环长测；
- 现有 NCO 40 级、CIC 96 位这些"过度设计"恰好提供了"缩位宽看死区何时出现"的实验台。

**最小可交付证据**
1. 死区宽度 vs 字长/能量曲线（解析 vs 仿真，两条线要重合）；
2. 极限环频谱（能看出离散谱线，而不是白噪声）;
3. 角度 Allan 偏差与零偏不稳定性在整形开/关下的对比；
4. FRP 系数漂移表（证明混淆）；
5. 面积/延迟开销（整形结构的代价必须诚实报）。

**期刊落点**：IEEE TIM（专业最匹配，SCI，可作"任意 SCI"名额）；若测量机理做得足够强，可投 Measurement（二区）。
**风险**：若死区被噪声淹没，本点降级为"量化噪声整形对 ARW 的改善"，仍可发但分量变轻。

### 创新点五　全角/力平衡共用数字内核的双模互校准与片上自检

**一句话主张（可证伪）**
> 同一个 DSP 核通过重配置可同时实现 WA（能量/正交/虚拟进动/测角）与 FTR（驱动 AGC+PLL、检测力反馈、正交反馈）；给出**共享算子集与面积增量上界**（新增只需 2 个 PI + 1 个调制器，复用 NCO/CIC/CORDIC/SPI）、**模式切换的无冲击映射**（(E,Q,R,S) ↔ (A_drive, φ, x_detect) 的守恒映射与瞬态界）、以及双模交替（mode reversal）在**未知角速率**下对零偏与标度因数的可辨识条件与不确定度——从而在无转台条件下实现自标定。

**科学问题**
WA 强在宽动态与直接测角，弱在角度相关零偏；FTR 强在零速/低动态精度，弱在量程。两者互补，但**"交替一下就自校准"是不成立的**：未知的真实运动与零偏在交替中同样不可分。所以真正的问题是：**在什么条件下、用多少次交替、能把这个不可分性打破到何种不确定度？**

**三条必须做出的结论**
1. **可重配置的面积增量界**：给出 WA 与 FTR 的算子集合的并/交，证明增量 ≤ 某个上界（而不是重新做一套 FTR 前端）。
2. **切换瞬态的定量界**：模态状态在两种控制律之间的映射、能量守恒、相位连续性；给出切换时角度跳变与恢复时间的上界，并给出"切换期间不输出导航"的判据。
3. **互校准的可辨识条件**：把"双模交替"写成对零偏与标度因数的观测方程，给出秩条件、所需交替次数与 CRB；明确"必须有一次外部参考（初始零速或已知转角）"这个前提——**诚实写出来，比含糊声称"无参考自校准"更有说服力。**

**与 2026 前沿的差别**
JP2008241706A（双谐振器 WA/FTR 交替比例因子自校准）、EP1722193A2（WA/FTR 切换正交抑制）、CN112595304B（工作模式自适应控制）已有"双模"和"自校准"的专利先例；[R06]/[R24] 是单模前端。**差异必须落在**：(i) 单核重配置的面积增量与延迟合同（电路贡献）；(ii) 切换瞬态的定量界（控制贡献）；(iii) 互校准的可辨识条件与不确定度（估计贡献）。三条缺一条就会被判为"专利复现"。

**为什么你的资产能做（但工作量最大）**
- RTL 的 PI、DPLL、NCO、CIC、SPI 已逐位验证，可复用；
- MATLAB 有 FTR 相关的慢变量与控制器框架（历史版本、`.slxc` 模型文件在库）；
- 专利草案已覆盖多速率接口，可作为权利要求基础；
- **但审计明确指出 "FTR 尚未实现"**，这是五个点里工作量最大的一个。

**定位**：博士论文第 6 章（集成章）+ 可选第 4 篇论文。**不要作为前三篇**。

**期刊落点**：TVLSI（附件 §41/§49，二区）或 TCAS-I（附件 §2/§42）；时间紧时投 IEEE Sensors Journal / TIM 作 SCI。

**必须避免的发文方式**：把同一套方法 + 同一组数据拆成多篇低差异稿件（`03` 文件已明确警告）；用仿真种子数冒充器件数；用平台均值改善 90% 冒充全样本改善 90%。

## 5. 必须先修的四个"证据卫生"问题

这四个不修，五个创新点里的任何"在线/自主/改善"主张都会被审稿人一击命中。

1. **真值泄漏**：`HRG_WA_v46_simulate.m` 第 148/512 行用外部真实角速度给零速许可；第 150/493/1156 行把 DAC 实际输出传给估计器；第 507/1174 行温度零偏估计与真实模型共用参数。→ 把 `calibrationPermit` 变成显式输入，真实角速度只进评分器；比较"真实执行量上限 / 命令+独立标定模型 / 带实测反馈"三种条件。
2. **Oracle 不是独立真值**：`HRG_WA_v46_compute_frp_truth.m` 在同模型里拟合九参数基。→ 建第二个 plant（独立二阶机械方程 + 不同离散化 + 真实电容/压电换能关系），并在第二个 plant 上做冻结验证。
3. **总 PASS 不含非零速**：`run_HRG_WA_v46_ab_validation.m` 第 107 行的 `validation.pass` 只合取 RLS 等价、Oracle 模型、在线估计三项。→ 把"数值一致性 / 零速有效性 / 非零速有效性 / 外域温度泛化 / 硬件一致性"拆成五个独立状态，各自合取。
4. **专利与 RTL 不一致**：草案权利要求 2 写"四分之一周期查找表 + 象限判断 + 符号恢复"，RTL 是 40 级 CORDIC。→ 先统一文书（要么改 RTL 为 LUT+插值并给误差界，要么改权利要求），否则创新点二的新颖性表述与专利稳定性都受影响。

**三个"立即转向"的红线**
- 创新点一：三种激励都不提秩 → 收缩为"等效补偿的适用边界"，改投 TIM。
- 创新点二：B2 打不过 B1 → 收窄为"除法自由化 + 128 位消除"单一结构，投 TCAS-II brief。
- 创新点三：电极不可分组 → 转创新点四或驱动侧换向。

## 8. 一句话总结

> 你的资产不在"再多一个补偿算法"，而在"**全角闭环里的信息结构（什么可辨识）与实现结构（怎么用时间换面积、用换向换精度、用整形换字长）**"。五个创新点按这个顺序排列：先证明边界，再造内核，再造前端，再守住精度，最后集成双模。三篇论文按 P1（TCAS-II）、P2（Measurement）、P3（Measurement/TIM）排产，任意一篇中二区即可达标，其余退路全在 SCI 内。
