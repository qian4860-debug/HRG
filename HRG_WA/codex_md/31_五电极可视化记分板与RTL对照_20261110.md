# 31 · 五电极关键节点记分板与 RTL 对照

适用版本为 6800 Hz 表头、四组对称电极加 COM、thx2024 模拟 C/V 的连续和检测电极分时复用模型。两版采用同一个 MATLAB 评分入口。评分窗和误差阈值用于行为仿真筛查，板级验收指标仍需实测回填。

## MATLAB 与原生 Simulink

从工程根目录在 MATLAB R2025a 运行。

```matlab
d = fullfile(pwd,'HRG_WA_simulink','piezo_v10','five_electrode_20261110');
addpath(d)
[report,data] = five_inspect('continuous','simulink');
five_inspect('continuous','matlab')
five_inspect('tdm_shared','simulink',0.5,struct('dac_divisor',25))
```

- 三个窗口分别显示记分板、载波短窗，以及 I/Q、振幅和角度等逐帧趋势。详细输出也可在 `report.checks` 和 `data.logsout` 中查看。批处理可追加 `Plots=false`。
- 原生观察版保存为 `hrg_5e_continuous_inspect.slx` 和 `hrg_5e_tdm_shared_inspect.slx`。直接打开运行，模型内 `Scoreboard monitor` 显示 ADC 越界拍、DAC 限幅拍、已发布帧、角度有效、跟踪丢失和最近角度。Data Inspector 提供 23 个命名节点。短窗载波可勾选 `dac_output_V`、`terminal_voltage_V`、`cv_output_V`、`adc_input_V`、`adc_output_V`、`adc_clip` 和 `dac_clip`。低速趋势可勾选 `frame_pulse`、`angle_valid`、`tracking_lost` 和 `angle_rad`。
- MATLAB 的数据分析还检查采样窗、ADC 流水对齐、DAC 门控、转换器码格、帧发布、归一化振幅和角误差。评分从同一有效帧锚定真值和测量角增量。短仿真或抽取记录会给出 `INCOMPLETE`，以区别尚未覆盖的判据。故障和越界记为 `FAIL`，评分前 DAC 限幅单列为警告。默认角误差筛查阈值为 0.015 rad，可用 `AngleRmsLimit_rad` 配置。
- 两套原始模型继续保留作为基线。需要重新生成观察版时，使用 `five_build(fullfile(d,'models'),true)`。

R2025a 实跑 0.18 s、0.5 rad/s 的名义工况，评分从 0.06 s 开始。

| 模式 | 评分帧 | 角增量 RMS | 结论 |
|---|---:|---:|---|
| 连续 | 816 | 3.0401959e-05 rad | 评分前 32 拍 DAC 限幅，评分窗内 0，ADC 过载 0。PASS_WITH_WARNING |
| 分时，DAC 217.6 kS/s | 204 | 0.00342488 rad | PASS |

两套原生观察版在 6 ms 逐拍与逐帧核对中，连续和分时的最大数据差分别为 1.97e-14 和 1.32e-12。验证了全部 23 路日志、原生块结构、C/V 和 ADC 图窗。故障注入能检出 ADC 过载和驱动门控错误。

## Verilog 与 SystemVerilog

`hrg_five_digital.v` 是两版共用的定点数字核，包含驱检窗、DDS、DAC 量化和更新、ADC 数据及相位对齐、I/Q、幅值及正交控制和全角累计。两版分别使用 160 或 800 拍每载波周期。电极、驱动、C/V 与抗混叠用 26 状态 SV 行为模型在测试中实现。真实采集板的 ADC/DAC 物理接口和时钟域接入需要适配，器件固有流水延迟也要计入端到端对齐。

- `tb_hrg_five_digital.sv` 回放 MATLAB 在物理采样时刻的 ADC 码与越界标志，逐拍比较时序、DAC 和发布状态，并比较 Q24 I/Q 与角度。误差门限分别为 4 个 DAC 码、约 20 ppm 的归一化 I/Q 和约 25 µrad 的角度差。
- `tb_hrg_five_closed_loop.sv` 用 RTL 实际 DAC 码推进 `hrg_five_analog_plant.sv` 的状态，再由表头模型生成下一拍 ADC。逐拍比较帧状态，报告参考角 RMS 与相对 MATLAB 的最大角差。用于短窗闭环功能验证。
- 使用 Icarus Verilog 和 Python 运行。默认导出并测试连续和分时两套；扩展用例另含 DAC /25 和锁定后 ADC 过载。逐拍数据由 MATLAB 本地生成。

```matlab
vecDir = five_rtl_vectors("C:/Temp/five_vectors",0.012, ...
    ["continuous","tdm_shared","tdm_shared_div25","continuous_overload"]);
```

```powershell
python HRG_WA_simulink/piezo_v10/five_electrode_20261110/rtl/run_five_rtl.py C:/Temp/five_vectors --cases continuous tdm_shared tdm_shared_div25 continuous_overload --vcd-dir C:/Temp/five_vcd
```

MATLAB 导出的角度和 I/Q 参考值使用 Q24，模拟模型系数保留双精度。当前 RTL 用例覆盖约定的采样配置与数字行为。综合资源、时序收敛和板级接口还需按目标 FPGA 验证。

## RTL 实测结果

Icarus Verilog 13.0 完成四组逐拍回放与三组 12 ms 机电闭环。两种数字配置另通过 Verilog-2005 编译。全部回放的时序及导航标志逐拍一致。

| 工况 | 回放拍 / 发布帧 | DAC 最大差 | 回放最大角差 | RTL 驱动机电模型时对 MATLAB 的最大角差 |
|---|---:|---:|---:|---:|
| 连续 | 13057 / 81 | 1 码 | 1.967 µrad | 8.881 µrad |
| 分时 | 65281 / 20 | 1 码 | 0.894 µrad | 0.894 µrad |
| 分时 DAC /25 | 65281 / 20 | 1 码 | 0.954 µrad | 0.954 µrad |
| 连续锁定后 ADC 过载 | 163201 / 157 | 1 码 | 4.292 µrad | 该用例仅执行回放 |

过载用例在成功发布 157 帧后失锁，失锁状态保持至记录结束，共 137920 拍。该压力工况另有 15624 拍 DAC 限幅。闭环三组有效、发布和失锁标志均无逐拍差异。连续版名义机电闭环复现启动时 32 拍 DAC 限幅，其余两组为零。
