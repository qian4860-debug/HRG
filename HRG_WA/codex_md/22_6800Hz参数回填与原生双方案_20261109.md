# 6800 Hz 表头参数回填、采样率下限与原生模型

日期：2026-11-09。基线：完整仓库 `G:/学习资料/HRG/HRG_WA`。本轮新增 `HRG_WA_simulink/piezo_v10/head6800_20261109/`，保留旧的 1 kHz 版本，不覆盖旧证据。

## 1. 本轮能确定什么

三份模型共用同一个物理表头；改变控制方式不会修改其固有频率、频差、Q 或寄生电容。实际接入电路会改变端口负载与闭环响应，不能把闭环响应当成表头固有参数。

| 参数 | 本轮采用值 | 依据与边界 |
|---|---:|---|
| 平均模态频率 | 6800 Hz | 用户指定的仿真表头 |
| 模态频差 | 0.050 Hz | 按小于 50 mHz 的上界作仿真，非所有表头的实际值 |
| 两模态频率 | 6799.975 / 6800.025 Hz | 6800 Hz 定义为中心频率 |
| Q | 30000 | 两轴暂取相同，不假设所有表头都相同 |
| 检测端并联寄生电容 | 600 pF | 两轴暂相同；不等同于驱检互耦电容 |
| 温漂 | 未给统一系数 | 没有伪造温度曲线；偏频试验不是温漂标定 |
| 连续方案转换器 | ADC 16 bit / DAC 16 bit | 具体器件未给，位数是理想码宽；不声称达到 16 bit ENOB |
| 分时方案转换器 | AD9215-65，10 bit ADC；AD9707，14 bit DAC | 两份附件经核对，第二款是 DAC |
| 模拟 C/V | 保留模拟读出与滤波 | 驱动、检测前置归一化增益共用一个参数 |

由表头参数直接得到：

\[
\omega_0=2\pi f_0=42725.66\ \mathrm{rad/s},\quad
\gamma=\frac{\omega_0}{2Q}=0.712094\ \mathrm{s^{-1}},\quad
\tau_A=\frac1\gamma=1.404308\ \mathrm{s},\quad
\Delta f_{3dB}=\frac{f_0}{Q}=0.226667\ \mathrm{Hz}.
\]

0.226667 Hz 是单个机械共振的线宽，不能据此把载波 ADC 采样率降到约 0.45 S/s。当前架构先采集 6.8 kHz 模拟载波，再在数字域解调。

## 2. ADC / DAC 的最低速率分三层判断

**第一层：信号理论界限。** 对理想带限的原始载波直接采样，且只考虑这两个模态：

\[
f_s>2 f_{max}=2(6800+0.050/2)=13600.05\ \mathrm{S/s}.
\]

这是严格大于的下界，不能在等号处选型。若包络/角运动边带需要保留至 \(B_e\)，则 ADC 与重建 DAC 的基带条件变为 \(f_s>2(6800.025+B_e)\)。例如仅作预算假设 \(B_e=100\) Hz，下界为 13800.05 S/s；100 Hz 并非厂家确认的系统带宽。

实际抗混叠还要考虑带外噪声、串扰和开关瞬态。理想矩形驱动窗并不严格带限，不能用一个 13.6 kS/s 数字保证开关边沿复现与建立精度。

**第二层：器件允许的时钟。**

- AD9215 Rev. B 第 5 页给出最低典型转换速率 5 MSPS，第 17 页说明低于此速率动态性能可能下降。因此本板 ADC 的候选下限应按 **5 MSPS** 处理，并留时钟裕量。该下限为典型表征，不是全温性能保证。65 MSPS 是该速度档的上限，不必满速运行。
- AD9215 有 5 拍流水线；模型把数据、有效标记和参考载波同时延迟 5 拍。ADC 时钟持续运行，只屏蔽非检测窗的数据，不在每帧关机。手册所列唤醒约 7 ms、时钟变更后的 DCS 重锁约 100 拍，都不适合当作每帧立即恢复的过程。
- AD9707 是最高 175 MSPS 的电流输出 DAC。ADI 官方支持答复说明：时钟采用直流耦合时无固定的最低时钟频率；实际板上时钟耦合、输出变压器/缓冲和校准过程仍须检查。6.8 kHz 不适合未经核查便套用射频变压器输出路径。
- AD9707 的典型 11 ns 建立时间对应 **0.1%** 误差，不是 14 bit 的半 LSB 建立保证；也不能用其倒数重新定义最大更新率。

**第三层：本模型的工作点和可降速候选。**

| 方案 | ADC | DAC | 有效样本/周期 | 输出帧率 |
|---|---:|---:|---:|---:|
| 连续驱动、连续检测 | 1.088 MSPS / 16 bit | 1.088 MSPS / 16 bit | 160 | 6800 Hz |
| 分时共用检测电极，默认 | 5.44 MSPS / 10 bit | 5.44 MSPS / 14 bit | 800 | 1700 Hz |
| 分时 DAC 降速试验 | 5.44 MSPS / 10 bit | 108.8、217.6、544 kS/s / 14 bit | ADC 仍为 800 | 1700 Hz |

连续方案 1.088 MSPS 位于用户给出的 1–2 MHz 速率建议内。“建立时间 1–2 MHz”存在量纲混用；这里将其作为速率建议，未推定具体器件的 0.5–1 µs 建立精度。连续 ADC 的 1 拍延迟是可修改的仿真假设。

对于正弦 DAC，零阶保持的基波幅度比为

\[
|H_{ZOH}(f_0)|=\frac{\sin(\pi f_0/f_D)}{\pi f_0/f_D}.
\]

108.8 kS/s 对应每周期 16 点，未补偿幅度下降约 0.641%；217.6 kS/s 对应 32 点，约 0.161%。模型重新计算相位/幅度校准，并真实保持 DAC 输出直到下次更新。降速候选通过行为模型闭环并不等于输出镜像、驱动器压摆率与板级建立精度均已验收。**当前可支持的结论是：ADC 保持约 5 MHz 以上；DAC 可以单独降到约 0.1–0.2 MSPS 进行板级验证，不要求 175 MSPS。**

如约束有效样本数 \(N_v\)、有效窗 \(T_v\)、时序分辨率 \(\delta t\)，还应检查

\[
f_A\ge N_v/T_v,\quad f_{timing}\ge1/\delta t,\quad
T_f\ge T_d+T_{bleed}+T_{settle}+T_v+T_{guard}.
\]

时序控制时钟、ADC 采样率、DAC 更新率、I/Q 帧率是四个不同的量。电极开关可由高速时序控制，DAC 的正弦码字不必同速更新。

## 3. 分时窗口与 C/V 复用边界

分时默认一帧为四个载波周期，即 588.235 µs：驱动 147.059 µs、断开泄放 73.529 µs、检测接通/建立 147.059 µs、有效检测 147.059 µs、末尾保护 73.529 µs。驱动占空比 25%。X/Y 同时检测，不共用单个 ADC 扫描。

有效窗覆盖一个完整参考周期，使用原生乘法器和累加器求 I/Q。不能只改窗口长度便继续使用原来的 \(2/N\) 解调系数；短窗要重新建立含直流项的拟合与协方差模型。`sampling.json` 比较了整周期、55 µs、10 µs 窗口的拟合条件数。增加采样点不会消除短相位覆盖造成的病态问题。

原始 thx 文件 `analog_gyro/or/loop_after_dem.slx` 保存了 `Kcvd=1e4`、`Kcvs=1e5`，以及同样不等的 `Kcsd/Kcss`。这不是可直接视为“两路前置增益相等”的参数集。本轮复用其 **模拟 Gain/滤波、原生元件闭环方法**，在压电端口模型中使用同一个 `pre_gain` 控制驱动和检测前置归一化增益。C/V 的物理电荷增益由显式 `Rs/Rf/Cf` 模型定义，不把 thx 的不同量纲系数强行当成 V/C 复制。

因此，本轮不是原 thx 电路数值的逐元件等价复刻。仍须用原理图或实测传递函数确认绝对电荷灵敏度和实际前置增益；已确认的是模拟 C/V 架构保留、前置增益一致的约束被执行。独立功率输出级的 `power_gain` 不属于这个前置匹配条件。

## 4. 完整行为信号链及方程

原生模型链路：双模态机械表头 → 压电检测节点/600 pF 电容 → 模拟电荷放大器及四级抗混叠滤波 → ADC 量化/限幅/流水线 → 数字 I/Q → 幅度与正交控制 → 数字载波调制 → DAC 量化/保持 → 模拟驱动极点与输出放大 → 驱动电极。共用电极版增加互斥连接、残压泄放和 C/V 复位；另有全角解算、无效帧处理及有界起振激励。

\[
\ddot{\mathbf q}+(2\Gamma+4B\Omega J)\dot{\mathbf q}+K\mathbf q
=bG_d\mathbf v_d+\kappa\mathbf v_e,
\]

\[
K=R(\alpha)\operatorname{diag}[(2\pi f_1)^2,(2\pi f_2)^2]R(\alpha)^T,
\quad J=\begin{bmatrix}0&-1\\1&0\end{bmatrix}.
\]

连续检测节点及模拟 C/V 的状态关系为

\[
C_p\dot v_e=-\dot q-(1/R_s+G_0)v_e+C_{ds}\dot v_d,
\quad C_f\dot v_{CV}=v_e/R_s-v_{CV}/R_f.
\]

这里的 \(v_d\) 指对应端口电压；实现中驱动极点的存储状态位于输出放大之前，机械力和共用电极接触电位都乘同一个输出增益。共用电极在驱动窗结束时保留**放大后的实际电极残压**，避免出现受力乘了增益而残压没有乘增益的错误。

模拟 AAF 用四级相同一阶低通：\(H_{AAF}(s)=[a/(s+a)]^4\)，\(a=2\pi\cdot20000\)。这是本轮电路假设，每一级拐点 20 kHz，不是厂家确认的总带宽。其在 6.8 kHz 的幅相影响进入校准矩阵。模型用连续状态方程的精确零阶保持离散化推进，18 个状态按机械、驱动、端口、模拟 C/V 与滤波分组，实际运行是 Gain、Sum、Delay、Switch 等原生块。

全角解算使用

\[
N=I_x^2+Q_x^2-I_y^2-Q_y^2,\quad M=2(I_xI_y+Q_xQ_y),\quad
\theta=-\frac{\operatorname{unwrap}[\operatorname{atan2}(M,N)]}{4B}.
\]

输出相对于首个有效帧；比较角误差时按检测窗中心时间对齐。默认 Bryan 系数沿用旧合成模型，未冒充本次表头实测值。载波为固定 6800 Hz NCO，利用 I/Q 主轴估计相位；未新增宽范围独立 PLL。

## 5. 尚未获得实测依据的数值

| 项目 | 当前假设 | 后续应替换的信息 |
|---|---|---|
| 模拟 C/V | Rs=1 kΩ、Cf=100 pF、Rf=1 GΩ；匹配前置增益=1 | 电荷/电容至输出电压的幅相、噪声、饱和与恢复 |
| 驱动 | 两轴相同 2 µs 极点、功率级增益 20 | 实际输出摆幅、相位、输出阻抗、限流/压摆率 |
| DAC 电压接口 | ±0.5 V 等效差分输出 | 可由 IFS=2 mA、250 Ω 等效差分跨阻实现，仍待核对板上电路 |
| 电极电压 | 上述接口与输出级得到约 ±10 V 仿真上限 | 不是已确认的表头额定电压或实际供电轨 |
| 泄放/复位 | 15 kΩ、2 µs 复位时间常数 | 开关 Ron、开关注入、泄漏、端口残压及 C/V 恢复实测 |
| 表头耦合 | b、κ、Bryan 系数、目标运动电荷沿用旧合成模型 | 同一个确定表头的驱动/检测灵敏度与全角比例因子 |
| 驱检串扰 | 默认 Cds=0，可参数化 | 连续驱动时的实际馈通，不能据默认值宣称串扰已解决 |
| 温漂/非线性 | 无确定温度曲线，机械模型线性 | 每个表头的温度数据、幅频效应、非线性和限幅 |

驱动电压由电路和目标振幅共同决定，不能只由 f、Q、Cp 推出。若驱动负载也近似 600 pF，10 V 峰值正弦需要 \(I_{pk}=2\pi fCV_{pk}\approx0.256\) mA、\(SR\ge2\pi fV_{pk}\approx0.427\) V/µs；这是纯电容负载演算，不含机械补能、其他寄生与电流裕量，也不代表驱动电极电容已确认为 600 pF。

10 bit 与 16 bit 理想满幅量化 SNR 分别约 61.96 / 98.08 dB。实际 AD9215 ENOB 还低于名义 10 bit，且随输入和时钟条件变化。仅在量化误差近似白噪声、正确低通抽取等条件下才有 \(\Delta N\approx\frac12\log_2(OSR)\) 的改善；补足 6 bit 需要约 4096 倍过采样，不能把高速时钟直接等同于 16 bit 精度。默认试验含量化但不含全部器件噪声/失真，另有明确的 ADC 噪声注入工况。

在项目根目录执行：

```matlab
folder=fullfile(pwd,'HRG_WA_simulink','piezo_v10','head6800_20261109');
addpath(folder,fullfile(folder,'models'))
h68_build;             % 重建三份 .slx；参数保存在模型工作区
h68_smoke;             % 原生模型与独立 MATLAB 逐拍核对
h68_physics_checks;    % 频差、Q 衰减、共用电极电压
h68_verify;            % 闭环、参数偏差、噪声、起振与故障
h68_sampling;          % 重算采样与窗口预算
h68_rate_sweep;        % ADC 5.44 MSPS，独立降低 DAC 更新率
h68_report;            % 原生框图和时序图
c=h68_config('tdm_shared',0.5,struct('dac_divisor',50));
[t,trace,frames]=h68_reference(c);
% 使用此配置运行原生模型：
load_system('hrg_6800_tdm_shared');
assignin(get_param('hrg_6800_tdm_shared','ModelWorkspace'),'c',c);
out=sim('hrg_6800_tdm_shared');
```

模型位于该目录的 `models/`；直接打开 `.slx` 即有默认参数。

`trace` 列为：slot、drive、sense、valid、ADC_X/Y、DAC_X/Y、published、Ix/Iy/Qx/Qy、body_angle、angle_valid、motion_X/Y、electrode_X/Y、ADC_clip、lost、DAC_requested_clip。`frames` 的第一列是发布时间，其余列与 trace 相同；它保存每个已接受帧。默认普通 trace 每 200 拍记录，故其中峰值/限幅数是所记录采样的统计；逐拍验证与故障验收显式使用 decimation=1。

本轮验证为带实际采样时钟的行为级闭环；没有建模 AD9707 纳秒级毛刺、完整 INL/DNL、时钟相位噪声、真实运放过载恢复与开关电荷注入，不能替代电路级或实物验收。现有信息足以建立可运行、可回填参数的完整信号链，不足以冻结最终精度和模拟器件指标。
