# 五电极 ADC 量程与分时窗口筛选

日期 2026-11-10。承接 [DSH 24 独立复核](27_DSH24独立复核与五电极执行基线_20261110.md)。本轮验证名义四组对称电极和理想 COM 下的 ADC 利用率、量化、增益及分时恢复。测试保留 6800 Hz、ADC 5.44 MSPS、14 bit DAC、10 bit ADC 与两路同步读出。20 bit ADC 仅作仿真归因。

## 如何测量与比较

MATLAB 参考模型可选返回 ADC 测点。在实际采样拍记录两路 ADC 的干净差分电压、叠加噪声的量化器输入、电压码和四组滤波后的 C/V，采样时间先于数字流水线。只在接通检测期间观测，分开统计建立期和有效期。全程峰值利用率以 ADC 差分半量程为分母。过量程样本按模型的码轨判断。

全部评分固定在零基第 68 帧锚定角度，第 102–305 帧评价 204 个点。参考时刻使用检测窗中心。若锚点缺失、失锁或评分帧不全，标为不可比较。全程同时记录过量程和失锁，覆盖上电或刚起振阶段。

后级增益放在模拟半差合成之后、ADC 之前。MATLAB 中将其并入四组到两路 ADC 的线性映射，数字 I/Q 校准除以同一倍数。thx2024 C/V、四组滤波及驱动前置系数继续采用原基线值。任何放大器噪声、带宽、增益偏差和输出摆幅的变化均需板级实测。

## 多工况增益筛选

用原名义工况加五组独立工况筛选 2 Vpp 档。新增工况覆盖零速、弱 Y 的初始方位、弱 X 的反向输入、对角方位正转和有界起振。全部工况用于检查量程和评分帧完整性。跟踪工况用于按最差角 RMS 排序，起振期角误差单独观察。要求全程无有效区截幅、保留所有评分帧，且检测接通期的峰值占用不超过 80%。80% 是本轮的仿真筛选线。

| 后级增益 | 最大接通峰值占用 | 最差角 RMS mrad | 通过筛选 |
|---:|---:|---:|---|
| 1 | 8.0% | 9.363 | 是 |
| 2 | 16.1% | 3.262 | 是 |
| 4 | 32.2% | 2.009 | 是 |
| 6 | 48.2% | 0.6993 | 是 |
| 8 | 64.3% | 0.6038 | 是 |
| 10 | 80.4% | 0.5728 | 否 |

本轮筛出 **2 Vpp×8**，全组最大占用 64.3%，最差 RMS 由基准 9.36 mrad 降至 0.604 mrad。该档在合成组别上对应输入折算码步 0.2441 mV，可与原档一起进行台架比较。
×6 的最大占用 48.2%，最差 RMS 为 0.699 mrad。若实际恢复或动态信号需要更多余量，可与 ×8 同台比较。

候选从静止起振后约 8.16 ms 发布首个有效帧。在 0.35–0.50 s 评分，角 RMS 为 0.327 mrad，归一化幅度为 0.9997–1.0000。首个有效帧只代表当前算法开始发布。台架还要确认允许出角时刻和起振收敛。

## 参考电压与噪声敏感性

AD9215 的两种内部参考对应差分 1 Vpp 和 2 Vpp。手册在 25 °C 的典型输入折算过渡噪声分别为 0.8 和 0.4 LSB RMS，折成电压均约 0.781 mV RMS。手册给出的 1 Vpp 档满幅 SNR 较 2 Vpp 档低约 3 dB。当前理想模型中 1 Vpp×1 与 2 Vpp×2 的折算码步同为约 0.977 mV，加入同一 ADC 输入端电压噪声后，两者的输入折算噪声不同。[AD9215 数据手册，第 3、14–15 页](https://www.analog.com/media/en/technical-documentation/data-sheets/AD9215.pdf)

噪声敏感性用与上述电压尺度相同的均匀加性噪声，使用两组固定种子。该值用于检验候选的敏感性。真实 ADC 的过渡噪声、杂散、前端噪声谱、非线性和输入共模需另测。

## 分时窗口扫描

固定 4 载波周期/帧（588.24 µs）、1 周期驱动、1 周期有效采样及两轴同步。前四项保持驱动结束到有效采样为 1.5 周期，重新分配泄放和建立。后三项固定泄放并移动整周期检测窗。两类比较分别回答“相同有效窗时该把时间分给哪一步”和“改变检测窗相位或恢复时间后会怎样”。每个窗口均用相同的两个姿态/角速度工况评分。

残压敏感性单独模拟一次切换，四组各以独立极性的 ±10 V 释放残压和检测接通时的 ±1 fC 注入组成线性上界。其他状态从零开始，结果是模型 ADC 输入处的额外误差，不能反映多次切换累积、COM 耦合、保护电路导通或过载恢复。额外扰动与名义波形合并时须按最不利符号留余量。ADC 前滤波也可能掩盖 C/V 前级已经过载的情况。

| 泄放 µs | 建立 µs | +0.5 / −4 rad/s 的角 RMS mrad | 线性附加残压峰值，接通期 / 有效期 mV |
|---:|---:|---|---|
| 36.76 | 183.82 | 0.2486 / 0.5898 | 136.4 / 0.2781 |
| 73.53 | 147.06 | 0.2448 / 0.6038 | 2.305 / 0.2781 |
| 110.29 | 110.29 | 0.2479 / 0.5945 | 0.2781 / 0.2781 |
| 147.06 | 73.53 | 0.09027 / 0.5597 | 0.2812 / 0.2812 |
| 73.53 | 73.53 | 0.1016 / 0.5554 | 2.305 / 0.2781 |
| 73.53 | 110.29 | 0.195 / 0.5692 | 2.305 / 0.2781 |
| 73.53 | 183.82 | 0.2503 / 0.6119 | 2.305 / 0.278 |

即使总等待时间相同，泄放和建立的作用也不同。把泄放从 73.53 µs 缩到 36.76 µs，接通检测后的线性附加残压峰值由 2.3 mV 变为 136 mV。在原泄放下把建立缩到 73.53 µs，有效窗线性附加峰值为 0.278 mV。闭环评分和额外残压上界要一起看。首轮板级仍从原窗口开始。回执也保留了 ×1 的同组窗口对照。

## 台架执行单

| 步骤 | 要做的测量 | 如何判读 |
|---|---|---|
| 1. 接线和参考面 | 确认 A/B/C/D、COM 与机壳/前端模拟参考，记录 600 pF 的测量频率、未激励端终接和组内极性。先用四端假负载做接线和触发校验 | 真实组端 C 值确认后再替换模型。分别记录组端对 COM 电压和 COM 对模拟参考电压 |
| 2. 基准量程和波形 | 先保留 2 Vpp、原后级增益与原窗口。触发同时记录开关门控、组端电压、C/V 输出、ADC 两引脚和溢出码。分别测 X/Y，记录整个驱检周期和起振阶段 | 同时检查 ADC 差分峰值与共模、未使能采样时的过载、C/V 输出是否触轨。强模态的最大峰值决定增益余量，弱模态的最小信号决定分辨力 |
| 3. 增益候选 | 在同一表头和旋转条件下比较原增益与本轮 2 Vpp 候选。若只能切换参考，可加做 1 Vpp。先低电压再逐级到实际允许的最大激励，记录零激励噪声、载波幅相、码分布和逐帧角度 | 20% 预留先作为筛选线。检查通道间复数增益、C/V 余量、ADC 共模、噪声和角误差后定档。必要时按 Vpp、占用率和量程码轨复算 |
| 4. 开关恢复 | 先保持原窗口，分别采驱动关断与检测接通。改变泄放或建立时，每次只比较预定的一组时序，记录整个有效窗的电压残差及同步 I/Q | 放电残压和开关注入分别归因。硬件窗口以 C/V 恢复时间、有效窗 ADC 余量、I/Q 偏差和有效帧率决定 |

台架记录建议至少保存配置 ID、物理引脚、参考/终接、触发时刻、开关状态、两端原始波形、ADC 码及 OR、温度和驱动幅度。若只有输出电压暂未接转台，先交付波形和恢复预算，绝对角误差再由独立角参考验证。本轮没有采集硬件数据。

量程核算以差分半量程为基准。在放大器输入处测得最大载波、恢复残差、偏置和噪声裕量后，分别用 `Vsig`、`Vrec`、`Voffset` 和 `Vnoise_margin` 表示其绝对峰值，保守筛选可用下式。放大器自身的偏置和输出噪声应先等效到该输入参考面，C/V 和差分驱动器的摆幅仍分别检查。

```text
Gmax = 0.8 * (ADC_Vpp / 2) / (Vsig + Vrec + Voffset + Vnoise_margin)
```
