# 汇总结论，以及仍然没想到的

日期：2026-11-05
范围：23 次 DSH 讨论 + codex_md 的 V3/V5/09/16/17 五份交叉复核 + A0–A4、D0 的实际实现
性质：收敛陈述，不是新调研；凡"未验证"处一律标明

---

## 0. 三句话结论

1. **架构已经收敛**：1 kHz 载波 + 40 kS/s 连续双通道 + 数字 I/Q + 分支估计（快反馈/慢输出）+ 40 kS/s 数字载波调制驱动（D0 已实现）。**不需要 65 MSPS，不需要 ARM+FPGA 分工；0.3–1 MSPS 只在分时场景才成立。**
2. **方法已经收敛**：可信角度 = 可辨识几何（W 自校准）+ 因果去嵌 + 协方差门控。A0–A4 把它验证到"合成二阶 / 12 状态"层，**没有一步到实物**。
3. **学位路线已经收敛**：A 链（测量与可信度）+ B 链（接口 ASIC）+ D0（驱动接口），贡献归属清楚；A→Measurement/TIM，B→TCAS-II/TVLSI。

## 1. 重新给出的六条结论（每条一句 + 一条证据）

| # | 结论 | 依据 |
|---|---|---|
| 1 | **Lynch 的骨架是对的，代码的系数是错的** | 两自由度 ODE 反演：θ̇ 应为 `+0.25Δ(1/τ)sin4(θ−θ_τ)`、`−0.25Δω(Q/E)cos4(θ−θ_ω)`，代码写 `+0.5`/`+0.5` |
| 2 | **表头参数是唯一的硬缺口** | 四层证据（A0–A3）全部以端口数据为前提；`bryan_factor/theta_s/theta_d/vmax` 在辨识结果里仍为 `null` |
| 3 | **不需要高速时钟** | 1 kHz 载波下 40 kS/s = 40 点/周期；10 bit 在 1 kHz 带宽内即可达 71 dB（要求 63.5 dB） |
| 4 | **位数由串扰决定，不由"陀螺精度"决定** | A1 实测：AFE/Cs 失配 0.5% → 留出误差 7.95%/12.18%；信号占满量程的比例被串扰压低 |
| 5 | **分时的价值是"空间覆盖"，不是"多采点"** | 时间上每路 T/N、噪声 √N；仅当电极失配 > N×噪声时净赚（本项目成立，但前提是电极可寻址） |
| 6 | **所有结论停在合成层** | 证据等级 A/B 有，C（逐位 RTL）部分有（D0 6055 拍），D（实物）为零 |

## 2. 这次讨论暴露的"元问题"——比任何单条技术结论都重要

**我们反复犯同一类错：一个假设在一个分支成立，被搬到另一个分支，且没人登记。**

| # | 实例 | 谁犯 | 错法 |
|---|---|---|---|
| 1 | `1+1/2−1/16−1/64 ≈ 1/√2` | 我 | 心算近似 |
| 2 | "旧环路 0.094/0.188 Hz ⇒ 延迟不是瓶颈" | 我 | 那是 tune **目标值**，且压电分支是 4–5 Hz |
| 3 | "125 µs 时差占满 0.003 rad 预算" | 我 | **度 vs 弧度**，错 57 倍 |
| 4 | "40 kS/s 每周期 8 点" | 我 | 把 5 kHz 分支的数搬到 1 kHz 分支 |
| 5 | "18 Hz 是带宽上限" | 我 | 那是"分配 45° 给延迟"的假设 |
| 6 | "B₂ 在频裂小时接近奇异" | 我 | `B₂=G⁻¹H⁻¹` 不含频裂 |
| 7 | "AD9215 可以跑 40 kS/s" | 我 | 只算噪声，没查最低转换率 |
| 8 | "40 kS/s 分时不可行" | 我 | 用 15 µs 特例推普遍 |

**注意：八条里七条是我犯的，而且集中在"把 branch A 的数用到 branch B"。**

这不是数学能力问题，是**工程过程缺失**：项目有 129 份文档，却没有一张《假设与适用范围表》。

**解法（我建议立刻建）**：

| 字段 | 说明 |
|---|---|
| 数 | 值 + 单位（rad/°、绝对/相对、峰值/RMS） |
| 分支 | legacy v4.6 / 压电 V10 / A4 / A0–A3 |
| 前提 | 在什么条件下成立（如"单极点阶跃""恒定转速""理想量化"） |
| 来源 | 哪个文件哪一行 |
| 验证状态 | 未验证 / 算过 / 仿过 / 实测 |

**任何跨分支引用，必须先查这张表。** 这一次讨论里 8 个错误，7 个能被它拦住。

## 3. 仍然没想到的（这次讨论之后新暴露的，不是 12 号那份）

### 3.1 理论侧

| # | 问题 | 为什么重要 |
|---|---|---|
| **T1** | **FRP 基函数的完备性从没审计过** | 这次才发现基里没有 Ω² 项。是否还缺 `s·Ω`、`T·Ω`、`Ω²·sin8β`？**该做一次系统审计**：用高保真模型生成数据，看拟合残差是否白、是否随 Ω 增长 |
| **T2** | **W 自校准与"好陀螺"天然矛盾** | W 可辨识要求 D、K 非共轴；而理想陀螺恰恰接近共轴。A0 只做了数值演示，**没有物理上"可控扰动"的实现路径**，也没有"扰动撤除后角度不残留"的证明 |
| **T3** | **时间戳只标得住数字时刻，标不住模拟时刻** | ADC 孔径、AFE 群延迟、电极切换的电荷注入时刻**都没有独立可观测量**。是否要加一路"已知阶跃注入"的校准通道去实测？**没人提过** |

### 3.2 工程侧

| # | 问题 | 为什么重要 |
|---|---|---|
| **T4** | **多器件/批次分布** | 全部结论是单器件。若批量参数散布大，W 校准能否迁移未知 |
| **T5** | **"拒绝输出"没有统计定义** | 现在只有阈值，没有误拒率/漏拒率。审稿人会问"你这个门限凭什么" |
| **T6** | **数据与代码的可复现要求** | 期刊要 data availability；现在 100 MB CSV 在 git 里，是否需要独立数据仓库 + DOI |
| **T7** | **专利与论文的先后** | D0/W 校准若先发论文，专利还来不来得及？现有 `patent/` 草案是 V0.1 |

### 3.3 项目侧（最容易被忽略）

| # | 问题 | 为什么重要 |
|---|---|---|
| **T8** | **人月从来没算过** | 以上全部工作目前是"一个人 + 两个 AI"。哪些能交给本科生/工程师？缺口几个月？ |
| **T9** | **停损点没定义** | 什么条件下承认"A 链走不通"转 B？没有写下来，就会一直加层 |
| **T10** | **答辩叙事没规划** | 若最终只有合成数据，学位论文的"实验验证"章节怎么组织才不被质疑？这是**写作策略**问题，比任何算法都影响毕业 |

## 4. 如果只补三件

| 优先 | 补什么 | 为什么是它 |
|---|---|---|
| **1** | **《假设与适用范围表》** | 一次讨论暴露 8 个错误、7 个同源；这张表能拦住未来 80% 的同类错 |
| **2** | **基函数完备性审计（T1）** | 它决定 FRP 那篇论文能不能成立——如果残差非白，整个"补偿"叙事要重写 |
| **3** | **停损点 + 人月（T8/T9）** | 决定这个项目是"三年做出两条线"还是"三年做一条线的一半" |

## 5. 一句话

> **技术结论已经收敛（架构、指标、路线都清楚），但这次讨论暴露的真正问题是过程性的：我们把一个分支的假设搬到另一个分支却没人登记，八次错误里七次同源。下一件该做的不是再加一层研究，而是建一张假设登记表、做一次基函数完备性审计、写下停损点——这三件都不需要新硬件，也不需要导师批准。**
