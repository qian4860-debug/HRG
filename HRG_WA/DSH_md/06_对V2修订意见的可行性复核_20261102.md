# 对《五个创新点_可行性评估与修订V2》的可行性复核

日期：2026-11-02
复核对象：`research/innovation_review_20261102/五个创新点_可行性评估与修订V2.md`（446 行，含原稿快照与十组代数核验）
复核方式：逐条判断"技术是否成立 / 采纳代价 / 采纳后还剩多少创新"，并对关键三条做了独立复算
结论口径：本文只评"修改意见可不可行"，不评"V2 作者是否读完了文献"

## 0. 总裁决（三句话）

1. **V2 的修改意见在技术上基本成立，应当采纳。** 我抽查了它的四条关键论证（相似变换群、延迟极点、测角几何、量化量级），**四条全对，其中一条证明我原稿写错了**。
2. **采纳之后"更可行"，但"更小"。** 五条里有三条会缩到"不能独立成篇"的程度——这不是 V2 的错，是原稿把话说满了。
3. **真正的风险不是"做不出来"，而是"做出来不够一篇二区"。** 所以可行性评估的落点应该是：**哪三条能撑住论文，哪两条只能当章节**。

## 2. 我独立复算过的四条

### 2.1 相似变换群：V2 对，但结论比它写的更强

V2 的证明：取 `T = s·R(φ)`，令 `r' = Tr`，则

```
D' = RDRᵀ,  K' = RKRᵀ,  G' = sRG,  H' = s⁻¹HRᵀ,  TJT⁻¹ = J
```

输出 `y' = H'r' = s⁻¹HRᵀ·T·r = Hr = y`。**成立。**

我再往下推一步（V2 没做）：因为 `s` 在 `TDT⁻¹` 里**自动抵消**，所以 `D` 和 `K` **只是被旋转，不被缩放**。而

```
D = 2γI + Δγ·A(θ_τ),   K = ω₀²I + 2ω₀Δω·A(θ_ω)
```

旋转不改变 `I` 的系数、也不改变 `A(·)` 的幅度，只改变它的轴角。于是可辨识性可以写得很干净：

| 量 | 是否可辨识 | 原因 |
|---|---|---|
| γ = 1/τ | **可** | 标量，旋转不变 |
| Δγ = Δ(1/τ) | **可** | `A` 的幅度，旋转不变 |
| ω₀ | **可** | 同上 |
| Δω（半裂） | **可** | 同上 |
| 轴角差 θ_τ − θ_ω | **可** | 两轴被同一个 φ 旋转，差值不变 |
| 绝对轴角 θ_τ、θ_ω | **不可** | 与坐标旋转 φ 混在一起 |
| G 与 H 各自 | **不可** | 只有乘积 `H·(动力学)⁻¹·G` 可观测，`s` 与 `1/s` 互补 |
| 乘积 G·H（含动力学） | **可** | 传递函数不变量 |

**这条结论比 V2 的"≥2 维"更有用**，因为它直接告诉你三件事：

1. **机械四参数（γ、Δγ、ω₀、Δω）是真的可以辨识的**——FRP 那类方法不是白做，只要别声称分离 G 和 H；
2. **绝对轴角必须靠外部参考**（已知电极几何，或已知初始方位）；
3. **驱动链和检测链不能靠闭环自己分开**——要分开，只能"独立标定其中一个"：要么已知电荷注入（定 H），要么已知力/位移（定 G）。这正是 V2 §3.4 说的"最小参考"，现在有严格依据了。

**对原创新点一的处置**：原稿承诺"分离检测矩阵、驱动矩阵、机械各向异性"，**第二项在闭环里原理上做不到**。要么改成"分离到 G·H 乘积 + 机械四参数"（诚实但只要一半），要么加一个独立参考（工作量翻倍）。

### 2.2 延迟反例：V2 对

`x[k+1]=0.8x[k]+u[k]`、`u=−0.5x[k]` → 极点 0.3；加一拍延迟 → `λ²−0.8λ+0.5`，`|λ|=0.707`。**极点确实变了。**

所以"延迟透明"不能说成"闭环不变"，只能说"**在不推迟输出时刻的前提下用掉空闲时间**"（V2 §4.1 的说法）。这个收缩是必须的，也是可行的：它把"减少资源"从"改变动力学"变成"改变实现方式"，反而更容易做出干净的对照。

### 2.3 测角几何：我原稿写反了，V2 对

V2 给了恒等式 `R²+S² = E²−4L²`（L 为代码里的 Q/2）。固定 E 时：

- **线振动**（L=0）→ 测角向量模长 = E，**最大**；
- **圆振动**（|L|=E/2）→ 模长 = 0，方向不可测。

我原稿写"近正交零点时 |V| 小"，**把方向搞反了**：正交被控到零，才使方向最可测。这条错误一路会影响"低能量/大正交时才需要冻结"的判断，必须改。

### 2.4 量化量级：V2 对，我也独立算过

- 24 位四倍角码 → 驻波角 LSB = 90°/2²⁴ = **5.36×10⁻⁶°**；折算机体角 ≈ 1.94×10⁻⁵°
- 我用实际字长反推的死区上界：`LSB/(4|V|)`，取门限 |V|=0.08 → **2.9×10⁻⁷ rad**
- 而模拟噪声折算到角度 ≈ **2.8×10⁻⁵ rad**

**死区比噪声低约两个数量级。** 两条独立算法得出同一结论：**当前字长下，量化不是第一矛盾。**

## 3. V2 没做、但必须补的一件事：给出可辨识集合

V2 证明了"不可辨识"，但停在"等价类"三个字上。工程上真正要的是**"那到底能辨识出什么"**。结合 §2.1，我建议把创新点一改写成：

> **在压电全角测控中，给出闭环可观测量的可辨识集合（机械四参数 + 轴角差 + 驱动/检测乘积），证明"驱动链与检测链的分离"必须依赖一项独立参考，并设计最小参考配置与不确定度传播。**

这条的好处：
- 不是"又一次联合标定"，而是**一条结构性结论**；
- 有反例（相似变换）、有正面结论（可辨识集合）、有工程动作（最小参考）；
- 审稿人无法用"这不就是 RLS 吗"打掉。

## 4. 创新点三还能不能救：能，但必须改到"电极级"

V2 §5.3 的反例（`H=diag(1.1,0.9)`，软件旋转再反旋转，偏差不变）**正确**，但它成立的前提是**参数化停在 2×2 矩阵层**。

而在 2×2 层，换向恰好落在 §2.1 的旋转自由度里 → 不增加信息。**这就是为什么"纯数字旋转"没用**。

**救法只有一条**：把参数化下沉到**电极级**（N 个电极各自的增益 g_i、相位 φ_i、位置 δ_i）。此时：

- 2×2 的 H 变成 `H = Σ_i w_i·h_i`（w_i 是换向权重）；
- 不同换向图案给出**不同的线性组合**，N 个方程解 N 个未知（差一个全局尺度）；
- 换向才真正增加秩，而不是落在规范群方向。

**代价**：必须拿到可独立寻址的电极。V2 §5.1 说的前置条件（电极分布、极性、引出线、是否内部合成 X/Y）**不是保守，是硬门槛**。

**结论**：创新点三保留，但题目必须写成"**电极级参数化下的换向可辨识性与谐波选择性抑制**"，并且**先做电极可访问性确认，再投入**。这一条与 V2 的收缩条件一致。

## 5. 创新点四改向：从"死区"改到"延迟—噪声—动态精度"

V2 §6.5 说"若量化不主导，应转向滤波群延迟—测量噪声—闭环动态误差的联合约束"。**这个建议是对的，而且我上一轮已经算出了具体数字**：

| 量 | 数 | 来源 |
|---|---|---|
| CIC（3 级，R=40）群延迟 | 1.46 ms | N(R−1)/2 ÷ 40 kHz |
| FIR（5 抽头，1 kHz） | 2.0 ms | 2 个控制周期 |
| 控制流水线 | 3.0 ms | 项目设置 |
| DAC 零阶保持 | 0.5 ms | 半个控制周期 |
| **合计** | **≈7 ms** | |
| **45° 裕度下的带宽上限** | **18 Hz** | 45/(360×0.007) |
| 若指标要 100 Hz | 延迟须 ≤ **1.25 ms** | 必须砍 FIR 与流水 |

**这就是"量化不主导之后该做什么"的答案**：不是继续抠位数，而是**把延迟预算当成一等公民**，并且它天然属于集成电路学科（调度、流水、滤波器结构）。

## 6. V2 的四处不足（不影响采纳，但会影响排期）

| # | 不足 | 后果 | 建议 |
|---|---|---|---|
| 1 | 没算"当前字长值不值得做"的具体数（只说"要回答"） | G3 的入口判据缺失 | 用 §2.4 的两个数直接判：**不值得**，转延迟 |
| 2 | **完全没提驱动载波调制** | 这是卡住闭环的第一硬件缺口：数字核只出 3 路慢 DAC 码，压电头需要 5 kHz 载波 | 加到 G2 之前，作为"架构决策"单列 |
| 3 | "G0–G3 约 12–16 周"偏乐观 | 表头 T0–T3 需 2 周 + 仪器/工装排队；且驱动调制方案要评估板 | 改为 **16–20 周**，并把表头表征前移到 G0 |
| 4 | 未处理"载波—模态耦合缺失" | 现在 DPLL 锁的是合成载波，不是模态；任何闭环结论都建立在这一点上 | 单列为 G1 的前置：**先让 L 来自模态** |

这四条不是否定 V2，而是**它按"文献+代数"审，我按"硬件+时序"审，两边合起来才完整**。

## 7. 采纳后的五条：还剩多少

| 原 | 采纳 V2 后 | 能独立成篇？ | 落点 |
|---|---|---|---|
| 一 | 可辨识集合 + 最小参考设计 | ✅ **能**（结构结论 + 反例 + 实验设计） | Measurement / TIM |
| 二 | 保持时序合同的共享定点内核 | ✅ **能**（前提是综合/STA 做出来） | TCAS-II / TVLSI |
| 三 | 电极级换向可辨识性 + 谐波抑制 | ⚠️ **有条件**（电极可寻址） | Measurement / TCAS-I |
| 四 | 量化—闭环—标定耦合 → 改向延迟 | ⚠️ **勉强**（建议并入二或三） | TIM |
| 五 | 双模可恢复切换 + 参考受限互校准 | ❌ **不能独立**（降为章节/第 4 篇） | TVLSI（远期） |

**结论**：采纳后是 **"2 篇稳 + 1 篇有条件 + 1 篇并入 + 1 篇远期"**。这正好对上"1 篇二区 + 2 篇任意 SCI"：
- 二 → TCAS-II（二区）或 TVLSI；
- 一 → Measurement（二区）或 TIM（SCI）；
- 三或四 → TIM / Sensors Journal / Micromachines（SCI）。

**风险**：如果三的电极不可寻址、二又打不过强基线，就只剩一篇，达不到要求。**所以必须以"二"为第一优先**——它是唯一不依赖外部硬件的。

## 8. 我的建议（按顺序）

1. **全盘采纳 V2 的 14 条修正**，包括认错的三处（几何、1/√2、延迟透明）。
2. **把 §3 的可辨识集合写进创新点一**，这是把"否证"变成"正结论"的关键一步。
3. **把 §5 的 18 Hz / 7 ms 写进创新点四**，让它从"要不要做死区"变成"延迟预算怎么做"。
4. **把驱动调制单列为架构决策**，排在所有算法之前。
5. **排期按 16–20 周**，表头表征前移。
6. 三的投入以"电极可独立寻址"为闸门，**拿不到就不做**，把资源压到二上。
