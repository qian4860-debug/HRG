# 分时与不分时：从低速基线到高速 TDM 的两套计划

日期：2026-11-09
输入：用户提问 39；`DSH_md/13`–`17`；Wang 2025（库内全文）；CN114396927B（库内全文）；CN116929322A（库内全文）；Xu 2021、Measurement 2026、AIP Advances 2026（仅题录/摘要，见 §1.2）。
适用范围：压电全角 HRG，`f0 = 1 kHz` 的压电分支假设，8 电极“两件套”表头假设。表头电极数、极性、可寻址性尚未确认，所有与电极有关的结论都带条件。

---

## 0. 先给结论

1. **分时本身不产生高速，反而要求前端更快。** N 路共用一个前端，前端采样率必须约提高到 N 倍（还要加建立/保护时间）；每路的有效时间反而降为 1/N。所谓“高速”，是把“多套慢前端”换成了“一套快前端”，总吞吐守恒。
2. **在 1 kHz 载波下，分时的时隙不能无限短。** 直接 I/Q 解调至少需要半个载波周期（500 µs）才能保持正交；8 时隙 × 约 520 µs → 帧率约 240 Hz。若坚持 1 kHz 帧，每隙只有 125 µs，扣掉建立/保护后有效窗口约 55 µs（约 20°），直接解调的噪声和偏差都不可接受，必须改用闭环跟踪（残差读出）。
3. **“复用”要分三层说**：时间上分时（drive/sense 不同时）、空间上复用（同一电极既驱动又检测）、通道上复用（X/Y 共用一套 AFE/ADC，但电极不换角色）。文献里常把第三层也叫 TDM，但它和前两层不是一回事。
4. **推荐路线**：先做**不分时、连续双通道、40 kS/s 的低速基线**，把表头、AFE、电极映射和闭环测通；再做**2 通道分时（通道复用）**验证时隙与相位；最后才做**8 电极分时复用**与空间换向。没有表头电极可寻址性，就停在 2 通道分时。
5. **迁移核查**：`HRG` 仓库原先整仓缺失，已克隆到 `G:\学习资料\HRG`；`ic-reference-library` 已把 28 条目录中的 27 条从 `D:` 改到 `G:` 并提交，但原 `reference_library`（209 条）未随迁移；`数字陀螺教材` 与 `NYCU-Lab3` 的本地提交还没有自己的 GitHub 远端。详见 `DSH_md/18`。

## 1. 术语与文献：先把“复用”说清

### 1.1 四种容易混淆的架构

| 架构 | 驱动与检测在时间上 | 电极角色 | 前端/ADC | 典型来源 | 一句话 |
|---|---|---|---|---|---|
| **E0 连续、不复用** | 同时 | 固定：专用驱动电极 + 专用检测电极 | 两套检测通道，同步采样 | 常规双通道 | 最简单、噪声最好，通道失配是主要误差 |
| **E1 分时、不复用** | 分开 | 固定：驱动组/检测组不变 | 一套前端轮流服务 | CN116929322A | 隔离驱动/检测，省前端，但不平均电极失配 |

| **E3 通道复用** | 可同时，也可分时 | 固定：X/Y 电极不换角色 | X/Y 共用一套检测链（AFE/ADC/DAC） | Wang 2025、Xu 2021 | 消除 X/Y 通道失配；不是“电极复用” |

**关键澄清**：CN114396927B 对“时分/复用”的定义最清楚：

> “时分是在时间域上将激励和检测分开，避免激励和检测的相互干扰，复用是在空间域上将离散电极进行复用，同一离散电极既可以作为激励电极也可以作为检测电极。”——CN114396927B 说明书 [0002]

因此：
- **分时 ≠ 复用**。分时只规定“不同时”，复用规定“同一电极换角色”。
- **Wang 2025 的“single-channel TDM”是 E3（通道复用）**：X/Y 共用同一套检测链，电极仍然是固定的 X/Y 检测电极，不换驱动角色。把它叫“电极复用”会误导。
- 用户说的“分时复用 / 分时不复用”，正好对应 E2 / E1；这正是需要分别做计划的两种电极方案。

## 2. 为什么“分时 ≠ 高速”：一条吞吐守恒

### 2.1 总采样率守恒

设 N 个通道，每通道需要 `f_s,ch`，共用前端占空比 `η = T_valid / T_slot`（扣除建立、保护、blanking），则共用前端至少要有：

```
f_s,shared ≥ N · f_s,ch / η
```

例：N=8，`f_s,ch = 40 kS/s`，η=0.8 → `f_s,shared ≥ 400 kS/s`。若每隙还要过采样，`f_s,shared` 到 0.5–1 MSPS 是合理的。**这就是“高速”的真正来源：不是分时产生了速度，而是共用前端必须快 N 倍。**

反过来，每通道的有效时间只有 `T_slot / T_frame ≈ 1/N`。白噪声下，每通道的方差约升 N 倍（幅度噪声约 √N 倍），这是分时的基本代价。精确的噪声还要看窗口形状和噪声谱，不能无条件写“√N 惩罚/收益”；最终应按 `wᵀΣw` 算。

### 2.2 1 kHz 载波下的“时隙—正交”矛盾

直接 I/Q 解调要求本振与信号在积分窗口内保持正交。设载波周期 `T0 = 1/f0 = 1 ms`，窗口 `T_w = T0/m`，则 Gram 矩阵为：

```
G = [[∫cos², ∫cos·sin],
     [∫cos·sin, ∫sin²]]
```

对白噪声，按锁相积分的归一化 `I = (2/T_w)∫r cos`，I/Q 估计的噪声方差相对全周期（m=1）的比值可写成 `2T0·a/T_w²`（`a=∫cos²`）。解析估算如下（理想积分器、白噪声）：

| 窗口 `T_w` | 载波相位 | 相对全周期的噪声方差 | 幅度噪声 | 能否直接 I/Q |
|---:|---:|---:|---:|---|
| `T0` | 360° | 1× | 1× | 可以（基准） |
| `T0/2` | 180° | 2× | 1.41× | **可以（下限）** |
| `T0/4` | 90° | 4× | 2× | 勉强，需校准 |
| `T0/8` | 45° | 约 13× | 约 3.6× | 不建议直接解调 |
| `T0/16` | 22.5° | 约 30× | 约 5.5× | 不可用 |

> 表为解析估算，前提是白噪声、理想积分、已知窗口；实际还有 1/f、开关注入、AFE 建立，需实测复核。

**直接结论**：
- **2 时隙（X/Y 各一）**：每隙约 520 µs（有效约 450 µs），帧约 1.04 ms → **约 960 Hz**。这是最稳的分时工作点。
- **4 时隙（Xs/Xd/Ys/Yd）**：每隙约 520 µs，帧约 2.08 ms → **约 480 Hz**。
- **8 时隙（8 电极逐个扫）**：每隙约 520 µs，帧约 4.16 ms → **约 240 Hz**。
- **8 时隙 + 1 kHz 帧**：每隙 125 µs，扣建立/保护后有效窗口约 55 µs（约 20°），相对连续全帧的噪声方差约 36×（幅度约 6×）；**不推荐**。

所以“分时高速”的可行定义是：
- **H1**：2 通道通道复用，960 Hz 帧，直接解调；
- **H2**：4/8 电极分时不复用，240–480 Hz 帧，直接解调；
- **H3**：8 电极 + 1 kHz 帧，**必须闭环跟踪**（残差读出），否则不成立。

### 2.3 闭环跟踪为什么能让短时隙成立

Wang 2025 的做法不是“每个时隙从头解调”，而是：
- DAC 持续重建一个跟踪信号 `A_f(t)`；
- 检测期把真实信号 `A_c(t)` 与 `A_f(t)` 相减，ADC 只读残差 `A_e(t)`；
- 残差经 I/Q 解调后，只更新跟踪信号的幅值/相位，不要求每个时隙独立估计全部信息。

这样，时隙只需要“残差建立 + 少量样本”，不需要半个载波周期。代价是：
- 多一个跟踪 DAC/控制环；
- DAC 的增益/相位误差进入环路（但它是共用的，可校准）；
- 环路稳定性、捕获、抗饱和要设计；
- 残差通道的噪声和线性度要求更高。

**这就是“高速分时”的真正技术核心**：不是开关本身，而是“闭环跟踪 + 残差读出 + 数字相位对齐”。如果只做开关轮询、每隙直接解调，1 kHz 帧不成立。

### 2.4 时偏与 FRP：分时最容易被忽略的污染

分时让不同电极在不同时刻采样，时偏 `Δt` 会进入角度/速率。项目 16 号文档已给出速率域的一阶表达式：

```
e_Ψ = ½·Ω·Δt·cos4β
ė_Ψ = ½·Ω̇·Δt·cos4β + 2B·Δt·Ω²·sin4β
```

关键点：**FRP 的九参数基不含 Ω² 项**，所以 `2B·Δt·Ω²·sin4β` 会被吸进 `sin4β` 系数，伪装成阻尼/刚度各向异性。按 `2BΔtΩ² ≤ 1×10⁻³ °/s` 反推：

| 训练速率 Ω | 允许的 `Δt` |
|---:|---:|
| 10 °/s | 59 ms |
| 100 °/s | 0.59 ms |
| 316 °/s | 59 µs |
| 1000 °/s | 5.9 µs |

**对计划的含义**：
- 低速基线（E0）没有时偏，是 FRP 训练和标定的“金标准”。
- TDM 在 240 Hz 帧下，首尾时隙差约 4 ms；100 °/s 时已超过 0.59 ms 的上限。因此：
  - 要么把 FRP 训练限制在低速率；
  - 要么对每个通道做载波相位旋转 `exp(-jωΔt)` + 包络修正，把 `Δt` 压到残余；
  - 要么把 Ω² 项显式加入 FRP 基函数。
- **不能**用“数字时间戳”一句话带过：时间戳只标数字时刻，标不住 AFE 群延迟、孔径、开关注入的真实模拟时刻。必须用已知注入信号实测“数字到模拟”的延迟。

## 3. 方案 A：不分时、低速基线（先做）

### 3.1 目标与边界

**目标**：在真实表头上建立一条“可解释、可复现、可标定”的连续双通道链路，作为后续所有 TDM 方案的对照基准。

**边界**：
- 不做电极复用，不做驱动/检测分时；驱动与检测同时。
- 载波 1 kHz，控制率 1 kHz，采样 40 kS/s（可提高到 100–200 kS/s 做对比）。
- 先用 FPGA + 分立 AFE/ADC/DAC，不上 ASIC；数字部分复用 HRG_WA 的 A4/D0 RTL。
- 表头参数未知时，先做无源/小信号表征，不直接上高压。

### 3.2 架构

```
表头 8 电极（假设）
  ├─ X 检测对（0°/90° 或 0°/180°）→ AFE_X → ADC_X ─┐
  ├─ Y 检测对（45°/135° 或 45°/225°）→ AFE_Y → ADC_Y ─┤→ FPGA：数字 I/Q、PLL、E/Q/角、FRP
  ├─ X 驱动对（180°/270°）← DAC_X ← 重建滤波 ← HV 驱动 ┤
  └─ Y 驱动对（225°/315°）← DAC_Y ← 重建滤波 ← HV 驱动 ┘
```

- **检测**：电荷放大器（CSA）优先，TIA 作为对照；高阻输入、屏蔽/护环、差分对称；抗混叠滤波按 `fs/2` 设计。
- **ADC**：20-bit、40–200 kS/s、双通道同步采样；若用单芯片双通道，确认“同时采样”而非“轮流转换”。
- **DAC**：18-bit、40 kS/s 更新；重建滤波器 + 高压缓冲；驱动电极的直流偏置与交流载波分开。
- **时钟**：50 MHz 系统时钟；采样时钟与 NCO 同源，避免异步。
- **数字**：NCO + 四路混频 + CIC/FIR + 不变量 + CORDIC + PI/DPLL + FRP；先用 MATLAB 位真模型对拍。

| 两通道增益匹配 | ≤ 1% | 不匹配会直接进 4θ |

## 4. 方案 B：分时、高速（后做）

### 4.1 目标与边界

**目标**：用一套共用前端，在 N 个电极/通道之间分时，获得：
- 通道/电极失配的共模化或平均；
- 驱动-检测隔离（避免强驱动淹没弱检测）；
- 8 电极的空间覆盖，为谐波抵消/换向做准备；
- 在可接受噪声代价下，把帧率做到 240–960 Hz。

**边界**：
- 不以“1 kHz 帧 + 8 电极 + 直接解调”为目标；该组合不成立（见 §2.2）。
- 不在表头电极不可寻址时做 E2；最多做 E3（2 通道通道复用）。
- 不在 AFE 建立时间未测前定时隙；35 µs 是 Wang 的 7.3 kHz 表头，不是我们的 1 kHz 表头。
- 高压开关、电荷注入、压电电荷记忆必须先做器件级测试，不能直接上整机。

### 4.2 三种电极方案（B1/B2/B3）

| 方案 | 电极角色 | 开关 | 优点 | 代价/风险 | 适用条件 |
|---|---|---|---|---|---|
| **B1 分时、不复用（E1）** | 驱动组/检测组固定；时间上分开 | 每组一个选通开关，无需双向高压 | 隔离驱动/检测；实现简单；可先用低压 | 不平均电极失配；占空比损失 | 8 电极可分组，但不敢/不需要换角色 |
| **B2 分时、复用（E2）** | 同一对电极在不同时隙既驱动又检测 | 双向高压开关 + 电荷泄放 | 省电极、平均电极失配、硬件共用 | 电荷注入、介质吸收、压电电荷记忆、驱动/检测负载变化 | 电极可独立寻址、能承受双向高压 |
| **B3 分时、复用 + 空间换向（E2+E3）** | 角色在 N 个电极间轮换 | 多路高压开关矩阵 | 可做 4θ/8θ 谐波抵消；空间平均 | 开关矩阵复杂、时序/相位校准难、帧率低 | 8/16 电极、可独立寻址、有转台/激励条件 |

**建议顺序**：B1 → B2 → B3。不要从 B3 开始。

### 4.3 时序与帧预算

统一记号：
- `T0 = 1/f0 = 1 ms`（1 kHz 载波）；
- `T_slot`：一个时隙的总时长；
- `T_settle`：AFE/开关建立到 0.1% 的时间；
- `T_guard`：开关非重叠、保护、blanking；
- `T_valid = T_slot − T_settle − T_guard`；
- `T_frame = N_slot · T_slot`；
- `f_frame = 1/T_frame`。

**工作点表**（假设 `T_settle=50 µs`、`T_guard=20 µs`、`T_slot=520 µs`）：

| 方案 | N_slot | T_slot | T_valid | T_frame | f_frame | 直接 I/Q | 用途 |
|---|---:|---:|---:|---:|---:|---|---|
| B1-a 2 通道 | 2 | 520 µs | 450 µs | 1.04 ms | 962 Hz | 可以（约 162°） | 通道复用验证 |
| B1-b 4 组 | 4 | 520 µs | 450 µs | 2.08 ms | 481 Hz | 可以 | 驱/检分时 |
| B1-c 8 电极 | 8 | 520 µs | 450 µs | 4.16 ms | 240 Hz | 可以 | 空间覆盖 |
| B2-a 4 状态复用 | 4 | 520 µs | 450 µs | 2.08 ms | 481 Hz | 可以 | 电极复用 |
| B3-a 8 状态复用 | 8 | 520 µs | 450 µs | 4.16 ms | 240 Hz | 可以 | 换向/谐波 |
| H3 8 状态 + 1 kHz 帧 | 8 | 125 µs | 55 µs | 1.0 ms | 1 kHz | **不可以（约 20°）** | 必须闭环跟踪 |

> `T_settle=50 µs` 是待测假设；若实测 100 µs，则 520 µs 时隙的有效窗口只剩 400 µs，仍可用；若 200 µs，则要改用 1 ms 时隙或降低 N。有效窗口 450 µs 约为半个载波周期（180°）的 90%，已接近直接 I/Q 的下限，不能再短。

**帧率与环路带宽**：压电分支 AGC 5 Hz、正交 4 Hz；240 Hz 帧仍是环路带宽的 48 倍，足够。**帧率不是瓶颈，噪声和时偏才是。**

### 4.4 相位/时间戳校准

分时有三类“时间”必须分开：

1. **数字调度时间**：FPGA 计数器/时间戳，50 MHz → 20 ns 分辨率。只能标“什么时候发命令”。
2. **模拟采样时刻**：ADC 孔径、AFE 群延迟、开关导通时刻。**数字时间戳标不住它。**
3. **信号相位**：载波在 `Δt` 内转过的 `ωΔt`，以及包络在 `Δt` 内的变化 `α̇Δt`。

校准步骤：
- **S1 电注入**：在 AFE 输入端注入已知正弦/阶跃，测“数字命令→ADC 样本”的群延迟；重复 10 次，取均值/散布。
- **S2 电极注入**：通过校准电极/注入电容，在真实电极节点注入已知小信号，测“DAC 码→电极电压→ADC”的全链延迟。
- **S3 时偏表**：每个时隙记录 `t_k`、`T_settle,k`、`T_valid,k`；解调时用 `exp(-jω(t_k−t_ref))` 旋转到统一参考。
- **S4 残余验证**：用同一机械激励、不同时隙顺序，检查角度/速率是否随时隙顺序变化；若变化，说明时偏未补干净。
- **S5 FRP 混淆实验**：同一机械模型、不同 `Δt`，看 `sin4β` 系数是否漂移；这是判断“时偏是否被误标定成机械误差”的直接实验。

**验收**：残余相位误差 ≤ 0.1°（对应 1 kHz 下 `Δt ≤ 278 ns`）；若做不到，必须在 FRP 基里加 Ω² 项或限制训练速率。

### 4.5 噪声与失配预算

不要用“√N 一定亏/赚”的口号，按下面的账算。对白噪声、锁相积分 `I=(2/T_valid)∫r cos`，相对“连续全帧”的噪声方差比为：

```
κ = 2 · T_frame · a / T_valid²,   a = ∫0^Tvalid cos²(ωt) dt
```

| 方案 | T_valid | T_frame | κ（方差） | 幅度噪声 |
|---|---:|---:|---:|---:|
| 2 时隙 | 450 µs | 1.04 ms | 2.6× | 1.6× |
| 4 时隙 | 450 µs | 2.08 ms | 5.1× | 2.3× |
| 8 时隙 | 450 µs | 4.16 ms | 10.3× | 3.2× |
| 8 时隙 + 1 kHz 帧 | 55 µs | 1.0 ms | 36× | 6.0× |

- 这只是**噪声**账；失配平均的收益另算。
- 若各电极失配独立，平均 N 路可降约 `1/√N`；若失配是共模的，平均无效；
- 最终用 `wᵀΣw` 算，不要用单一 √N。

**净收益判据**：

```
失配引起的误差方差 > 噪声引起的误差方差 时，空间平均才净赚。
```

本项目 A1 的 AFE/Cs 失配（0.5% 量级）远大于噪声，所以“失配主导”可能成立；但必须用实测 `Σ` 验证，不能直接引用旧结论。

### 4.7 门禁（Go/No-Go）

- **G5（收益）**：空间平均/谐波抵消的实测收益 ≥ 2×；否则 TDM 只剩“省硬件”，不如保持基线。

## 6. 风险与停损点

| 风险 | 触发条件 | 应对 | 停损 |
|---|---|---|---|
| 表头电极不可寻址 | 只有 2 个合成端口 | 只做 E3/B1 | 停止 E1/E2 |
| AFE 建立太慢 | `T_settle > 100 µs` | 加时隙/降 N/提高带宽 | 若 >200 µs，放弃 1 kHz 帧 |
| 开关电荷注入大 | `Q_inj > 1 fC` 或漂移 | dummy/差分/自举/泄放 | 若无法压到 1 fC，退回 B1 |
| 压电电荷记忆 | 切换后基线漂移 | 卸荷态、复位、长 blanking | 若漂移 > 角度预算，退回 E0 |
| 时偏污染 FRP | `sin4β` 随时隙顺序漂移 | 相位旋转/Ω² 基/限速 | 若残余 > 0.1°，B 不用于 FRP |
| 噪声代价过大 | TDM 噪声 > 基线 +6 dB | 增加时隙/减少 N/提高 fs | 若 > +6 dB 且无空间收益，停止 |
| 收益不足 | 空间平均 < 2× | 检查失配是否共模 | 若 < 2×，TDM 只省硬件，不做 |

**一句话停损**：如果 B 的噪声代价超过 +6 dB，且空间平均/谐波抵消的实测收益不到 2×，就把 B 降级为“实验室对照”，不进入 ASIC 主线。

## 附录 B：关键公式

**吞吐守恒**

```
f_s,shared ≥ N · f_s,ch / η,    η = T_valid / T_slot
```

**帧率**

```
T_frame = N_slot · T_slot
f_frame = 1 / T_frame
```

**分时通道相对连续全帧的噪声方差比（白噪声、锁相积分）**

```
a = ∫0^Tvalid cos²(ωt) dt
κ = 2 · T_frame · a / T_valid²
```

**时偏对速率的影响（项目 16 号）**

```
ė_Ψ = ½·Ω̇·Δt·cos4β + 2B·Δt·Ω²·sin4β
```

**FRP 误吸条件**

```
2B·Δt·Ω² > 待辨识谐波（约 1×10⁻³ °/s） → Δt 上限随 Ω² 收紧
```
