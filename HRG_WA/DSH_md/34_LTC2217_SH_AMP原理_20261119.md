# 34 · LTC2217 `SH_AMP` 原理详解

2026-11-19。对象是截图中 Virtuoso 打开的 `LTC2217 SH_AMP` 顶层原理图。它是 LTC2217（16 位、105 Msps）的**输入采样保持放大器（Sample-and-Hold Amplifier）子系统**，不是整个 ADC。

读图边界：截图能看清单元名、引脚名、部分器件尺寸和电容值；`sch.oa` 是二进制，不能像网表一样逐线核对。下面按“功能等效”讲原理，凡是按图上标注值做的计算都标“一阶估算”。

---

## 1. 它在 LTC2217 里的位置

LTC2217 的信号链：

```text
AINP/AINN
   │
   ▼
┌──────────────┐
│   SH_AMP     │  采样/保持，隔离第一级流水线的回踢
│  本图        │  输出 VL_P/VL_N 驱动第一级
└──────┬───────┘
       │
       ▼
Stage 1 → Stage 2 → Stage 3 → Stage 4 → Stage 5 → 数字校正 → 16 位输出
```

数据手册给出的关键点：

- 16 位、105 Msps；
- 输入 2.75 Vpp 差分；
- 400 MHz 全功率带宽 S/H；
- 85 fs RMS 抖动；
- 5 级流水线，采样后 7 个时钟出结果；
- 81.2 dBFS SNR、100 dB SFDR。

`SH_AMP` 的任务不是“放大”，而是：

1. 在时钟沿把差分输入**冻结**在电容上；
2. 用低噪声、高线性缓冲器驱动第一级流水线；
3. 隔离第一级开关的**回踢**；
4. 通过校准网络修掉采样开关/电容/放大器的失调和增益误差；
5. 保证 16 位所需的建立精度和孔径一致性。

## 2. 顶层功能框图

按截图，`SH_AMP` 由五块组成：

```text
AINP ──[ESD]──[自举采样开关 M1298]──┬── 采样电容组（2.88/8.49/12.68 pF）──┬── U1 VL_P
                                    │                                      │
AINN ──[ESD]──[自举采样开关 M3263]──┴── 采样电容组 ────────────────────────┴── U1 VL_N
                                    │
                          ┌─────────┴─────────┐
                          │ 补偿注入电容桥     │  4 × 201.63 fF
                          │ M1214/M621/M1211  │  由 FR_CLK 复位到 V_CM2
                          └─────────┬─────────┘
                                    │ COMP_P / COMP_N
                          ┌─────────┴─────────┐
                          │ U4 SH_CALIBRATION2 │  5 位补偿 DAC
                          │ VREF/VH/VL/ADJ1..5 │
                          └─────────┬─────────┘
                                    │ ADJ
                          ┌─────────┴─────────┐
                          │ U18 SH_CALIBRATION │  4 位 SAR/修调控制器
                          │ IN4..1, CP_CLK     │
                          └───────────────────┘

U6 SH_CLK_GEN（BOOTSTRAP CLOCK GENERATOR）
  → S_CLK / H_CLK / EQ_CLK / EN_CLK
  → HCK_BOOTSTRAP / SCK_BOOTSTRAP / EQCK_BOOTSTRAP
  → 用 ADJ*_R 修时钟延迟/非交叠

U2 SH_BIAS
  → VBP1/VBP2（PMOS 偏置）
  → VBN1/VBN2（NMOS 偏置）
  → Y_OUT

U1 S_H_AMP（核心放大器）
  → AMP4 第一级 + AMP5 第二级 + CMFB + SH_CMFB
  → OP/ON 输出到第一级流水线
```

## 3. 采样网络：自举开关 + 底板采样 + 补偿电容

### 3.1 自举采样开关

`AINP/AINN` 先经过 ESD（`ESD1`），再经过 `M1298/M3263` 两个大 NMOS 开关。它们的栅极由 `S_CLK` 和自举时钟驱动：

- `SH_CLK_GEN` 里的 `SCK_BOOTSTRAP` 产生自举时钟；
- 自举电容在采样期间把栅极电压抬到 \(V_{in}+V_{DD}\) 附近；
- 这样 \(V_{GS}\) 近似恒定，\(R_{on}\) 不随输入信号变化。

为什么 16 位必须自举：

- 普通 NMOS 开关的 \(R_{on}\propto 1/(V_{GS}-V_{TH})\)，输入越大 \(R_{on}\) 越大；
- \(R_{on}\) 非线性会与采样电容形成信号相关的建立误差，直接恶化 SFDR；
- 自举后 \(R_{on}\) 近似常数，建立误差与信号无关。

### 3.2 底板采样

图上输入开关在电容的**上极板**，电容的**下极板**通过 `M1214/M621` 接到 `V_CM2`，由 `FR_CLK` 控制。典型时序是：

1. 采样前，下极板开关先把电容下极板复位到 `V_CM2`；
2. `S_CLK` 打开上极板开关，电容跟踪 `AINP/AINN`；
3. 保持时，先断开下极板开关，再断开上极板开关。

这样，上极板开关的电荷注入看到的是一个近似固定的共模节点，注入量与输入信号的相关性被压低；下极板开关的注入则被共模/差分对称结构抵消一部分。16 位系统还要靠 dummy 开关、对称版图和校准来修残余。

### 3.3 采样电容组

图上能看到三组采样电容，实例名 `C270/C274/C275`，尺寸标注约为 `l=2.88u / 8.49u / 12.68u`，`m=1`。注意：这些是 **MIM 电容的尺寸参数（µm）**，不是 pF 值；截图没有给出三组电容的实际电容值，不能把 2.88、8.49、12.68 直接相加当 pF。

16 位、2.75 Vpp 的 LSB 是：

\[
LSB=\frac{2.75}{2^{16}}=41.96\ \mu V
\]

若要求 kT/C 噪声低于 0.5 LSB（约 21 µV）：

\[
C_s>\frac{2kT}{\sigma^2}
=\frac{2\times1.38\times10^{-23}\times300}{(21\times10^{-6})^2}
\approx18.8\ \text{pF}
\]

若要求低于 0.25 LSB（约 10.5 µV），则要约 75 pF。实际 LTC2217 的采样电容应在几十 pF 量级；具体值以 Virtuoso 原图的 `c` 参数为准。**大电容是 16 位 kT/C 的必要条件，代价是输入驱动电流和建立时间。**

### 3.4 补偿注入电容桥

四个 **201.63 fF** 电容组成桥式网络，一端接采样节点，另一端由 `U4 SH_CALIBRATION2` 的 `COMP_P/COMP_N` 驱动；`M1214/M621/M1211` 由 `FR_CLK` 控制，把桥节点复位到 `V_CM2`。

功能：

- `U4` 输出一对差分补偿电压；
- 通过 201.63 fF 电容向采样节点注入少量电荷；
- 因为桥是对称的，共模注入互相抵消，差模注入用于修 **输入失调/增益误差/电荷注入残余**；
- `M1211` 在复位相位把桥节点短接/均衡，清掉上一次的补偿电荷。

补偿范围由 \(C_{cal}/C_s\) 和 `VH/VL` 的摆幅共同决定：

\[
\Delta V_{in,eq}\approx\frac{C_{cal}}{C_s}\Delta V_{comp}
\]

`C_cal=201.63 fF` 是确定的；`C_s` 是几十 pF 量级，所以比值大致在 \(10^{-3}\)–\(10^{-2}\)。具体能修多少 mV、LSB 多细，取决于原图的 `C_s`、`VH/VL` 和补偿 DAC 位数。这里不把长度参数当电容值硬算。

## 4. 核心放大器 U1 `S_H_AMP`

### 4.1 引脚

U1 是差分输入、差分输出的采样保持放大器：

| 引脚 | 作用 |
|---|---|
| `VL_P` / `VL_N` | 采样电容送来的差分输入 |
| `OP` / `ON` | 差分输出，送第一级流水线 |
| `SH_EN` | 采样保持使能 |
| `ENB` | 使能反相/关断 |
| `CLK1/2/3` | 开关电容 CMFB/相位时钟 |
| `YBP1/2` | PMOS cascode 偏置 |
| `YBN1..4` | NMOS cascode/电流源偏置 |
| `Y_EN0` / `Y_EN` | 偏置支路使能 |
| `Y_DN` / `Y_OUT` | 输出共模/参考 |
| `Y_CM2` | 输出共模设定 |
| `CMFB_EN` | 共模反馈使能 |
| `IB` | 偏置电流 |

### 4.2 内部层次

`S_H_AMP` 内部有：

- `AMP4`：第一级放大器；
- `AMP5`：第二级放大器；
- `CMFB`：连续共模反馈；
- `SH_CMFB`：采样保持专用开关电容共模反馈。

这是一套**两级全差分放大器**：

```text
VL_P/VL_N
   │
   ▼
┌──────────────┐
│ AMP4         │  第一级：NMOS 输入对 + cascode 负载
│ 高增益/低噪声 │  决定输入噪声和增益
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ AMP5         │  第二级：输出级，提供摆幅和驱动
│ 大摆幅/驱动   │  内部含 AMP2/AMP3（cascode/输出级）
└──────┬───────┘
       │
       ├──► OP/ON
       │
       └──► CMFB / SH_CMFB  ← 检测输出共模，调偏置
```

为什么用两级：

- 16 位需要很高的直流增益，单级 cascode 可能不够；
- 第一级用 NMOS 输入对，噪声低；第二级提供输出摆幅和驱动能力；
- CMFB 把输出共模稳在 `V_CM`，否则差分摆幅/线性度会随 PVT 漂移；
- `SH_CMFB` 在采样/保持相位切换时维持共模，避免电荷再分配把输出共模拉偏。

### 4.3 建立时间与 400 MHz 带宽

105 Msps 的周期是：

\[
T=\frac{1}{105\text{MHz}}=9.52\ \text{ns}
\]

半周期约 4.76 ns。16 位建立到 0.5 LSB 需要：

\[
n=\ln(2^{17})=11.78\ \tau
\]

若 4.76 ns 内完成：

\[
f_{-3dB}\approx\frac{11.78}{2\pi\times4.76\text{ns}}\approx394\ \text{MHz}
\]

这和数据手册的 **400 MHz 全功率带宽 S/H** 对上了。也就是说，`SH_AMP` 的 400 MHz 不是随便写的，而是 16 位/105 Msps 建立精度的直接结果。

### 4.4 噪声

采样电容在几十 pF 量级时，kT/C 约十几 µV、零点几 LSB。放大器的输入折算噪声必须低于这个量级，否则 16 位噪声会被 OTA 主导。第一级 `AMP4` 的 NMOS 输入对、偏置电流和器件面积就是按这个噪声预算选的；第二级的噪声被第一级增益抑制。

### 4.5 失真

16 位、100 dB SFDR 要求：

- 输入对线性；
- cascode 输出阻抗足够；
- CMFB 不引入信号相关误差；
- 采样开关 \(R_{on}\) 恒定（自举）；
- 底板采样降低电荷注入；
- 校准修静态失配。

`SH_AMP` 的差分结构本身抑制偶次谐波；自举开关和对称版图抑制奇次/信号相关项。

## 5. 校准环路：U18 + U4 + 补偿电容

### 5.1 U18 `SH_CALIBRATION`

从层次看，U18 内部是数字逻辑（反相器、与非门、OAI、传输门），不是模拟放大器。它的引脚：

- `IN4..IN1`：比较/检测输入；
- `DUMMY_IN4..1`： dummy 输入，匹配寄生；
- `CP_CLK`：比较时钟；
- `ADJ3..0`：调整码输出。

功能上，它是一个**逐次逼近/修调控制器**：在校准模式下，根据比较结果逐位确定 `ADJ` 码，使 SH 的失调/增益误差最小。它更像“出厂/上电前台校准”，不是连续后台自适应。

### 5.2 U4 `SH_CALIBRATION2`

U4 是补偿 DAC：

- `VREF`、`VH`、`VL`：参考/高/低电压；
- `ADJ1..5`：5 位调整码；
- `COMP_P/COMP_N`：差分补偿输出；
- 内部有电阻串（`res_poly`/`res_pdiff`）、PMOS/NMOS、pipcap，说明它是电阻分压/缓冲型 DAC。

它把数字 `ADJ` 变成一对差分电压，通过 201.63 fF 电容注入采样节点。校准环的路径：

```text
SH 输出/参考 → 比较 → U18 SAR → ADJ 码
                              │
                              ▼
                         U4 补偿 DAC
                              │
                              ▼
                  COMP_P/COMP_N → 201.63fF → 采样节点
                              │
                              ▼
                     减小失调/增益误差
```

### 5.3 `ADJ*_R` 修时钟

U6 `SH_CLK_GEN` 还接收 `ADJ1_R..ADJ8_R`，内部有 `RC_DELAY`。这说明同一套修调码不仅修模拟失调，还修**采样时钟延迟/非交叠**：

- 采样开关的开启/关断时刻影响电荷注入和孔径；
- 片内 RC 延迟随 PVT 变化；
- 用 `ADJ*_R` 调延迟，让采样沿落在最佳位置。

对 16 位/105 Msps 来说，时钟延迟的皮秒级变化都会影响 SFDR，所以时钟修调和模拟修调要一起做。

## 6. 时钟发生器 U6 `SH_CLK_GEN`

U6 是 “BOOTSTRAP CLOCK GENERATOR”，输入：

- `LVDD1/2`：逻辑/驱动电源；
- `V_IN`、`ADP/ADN`、`VL_P/VL_N`：输入/电平参考；
- `ADJ1_R..ADJ8_R`：延迟修调；
- `CLK1/2`：主时钟。

输出：

- `S_CLK` / `S_CLK_1`：采样时钟；
- `H_CLK` / `H_CLK_1`：保持时钟；
- `EN_CLK`：使能；
- `VCM`：共模参考。

内部：

- `HCK_BOOTSTRAP`：保持开关的自举时钟；
- `SCK_BOOTSTRAP`：采样开关的自举时钟；
- `EQCK_BOOTSTRAP`：均衡/复位开关的自举时钟；
- `RC_DELAY`：非交叠/延迟修调。

关键点：

1. **非交叠**：S_CLK 和 H_CLK 不能同时有效，否则采样电容和保持节点会同时导通，电荷共享，精度崩溃。
2. **先开后合**：保持相位先断开采样开关，再接通保持/反馈开关；采样相位反之。
3. **自举**：采样开关的栅极要高于输入共模 + \(V_{TH}\)，否则大输入时 \(R_{on}\) 变大。
4. **均衡**：`EQ_CLK` 在采样前把差分节点短接/复位，清掉上一次保持的电荷，降低记忆效应。

---

## 7. 偏置 U2 `SH_BIAS`

U2 产生：

- `VBP2/VBP1`：PMOS cascode/电流源偏置；
- `VBN2/VBN1`：NMOS cascode/电流源偏置；
- `Y_OUT`：输出级参考/共模相关偏置。

`BIAS_EN` 控制上电/关断；`IBN1/IBN2` 是偏置电流输入。U1 的 `YBP1/2`、`YBN1..4`、`IB` 都来自这里。

偏置噪声/电源抑制会直接调制放大器的 gm 和输出共模，所以 16 位系统里偏置要单独去耦、软启动、PVT 补偿。

## 8. 一次完整的采样/保持过程

下面按典型 SC-SHA 时序描述（具体相位以 Virtuoso 原图为准）：

### 8.1 复位/均衡相位

- `EQ_CLK` 有效：把采样节点/补偿桥短接或复位到 `V_CM2`；
- `FR_CLK` 有效：`M1214/M621` 把 201.63 fF 补偿电容复位到 `V_CM2`；
- `SH_CMFB` 复位：输出共模回到 `V_CM`；
- 清掉上一次转换的电荷记忆。

### 8.2 采样相位

- `S_CLK` 有效：`M1298/M3263` 导通，采样电容跟踪 `AINP/AINN`；
- 自举电路把开关栅极抬高，\(R_{on}\) 近似恒定；
- 采样电容组充电到输入电压；
- 补偿电容桥也采样/保持补偿电压；
- U1 可能处于 unity-gain/reset 状态，等待保持相位。

### 8.3 保持相位

- `S_CLK` 断开：输入与采样电容分离；
- `H_CLK` 接通保持/反馈开关：采样电容下极板切换到 `V_CM`/反馈节点；
- 电荷再分配，U1 输入节点建立到 held 电压；
- U1 差分输出 `OP/ON` 建立到 16 位精度；
- 第一级流水线在 `H_CLK` 期间采样 `OP/ON`；
- 补偿 DAC 的电荷同时注入，修掉静态误差。

### 8.4 校准相位

- 在 startup/测试模式，U18 逐位调整 `ADJ`；
- U4 输出 `COMP_P/COMP_N`，通过 201.63 fF 注入；
- 比较 SH 输出/参考，直到失调/增益误差最小；
- `ADJ*_R` 同时修时钟延迟；
- 校准完成后锁存码，正常转换不再频繁调整。

## 10. 这个 SH_AMP 的设计取舍

1. **大采样电容换噪声**：几十 pF 的采样电容把 kT/C 压到零点几 LSB，但输入驱动电流大、建立难；所以需要 400 MHz 缓冲器和 1.19 W 总功耗。
2. **自举开关换线性度**：16 位/100 dB SFDR 不能容忍 \(R_{on}\) 随输入变化；自举是必需，不是可选。
3. **底板采样换电荷注入**：下极板先断开，降低信号相关注入；残余靠对称/校准。
4. **两级放大器换增益/摆幅**：第一级低噪声高增益，第二级大摆幅驱动；CMFB 保共模。
5. **校准换 16 位精度**：U18+U4+201.63 fF 补偿桥修静态误差；`ADJ*_R` 修时钟延迟；没有校准，16 位很难达到 100 dB SFDR。
6. **代价**：功耗 1.19 W，面积/驱动/校准测试成本都高。对 5.44 MS/s、12 位的全角 TDM，不需要照搬几十 pF/400 MHz/1.19 W；应把电容、电流、带宽按 12 位/5.44 MS/s 重新缩放。

## 11. 对全角 TDM ADC 的可迁移点

- **采样保持必须独立**：双通道 X/Y 同时采样，SHA 的孔径匹配和回踢隔离直接决定相位/角度误差。
- **自举开关 + 底板采样**：是 12 位以上线性度的基础；不要用简单 TG 开关直接采 2 pF。
- **CMFB 要分相**：采样/保持相位切换时，输出共模会被电荷再分配拉偏；`SH_CMFB` 这类开关电容 CMFB 比连续 CMFB 更适合。
- **校准要分两层**：模拟失调/增益用补偿 DAC；时钟延迟用 `ADJ*_R`；两者不要混为一个“数字校准”。
- **不要照搬功耗**：LTC2217 的几十 pF/400 MHz/1.19 W 是 16 位/105 Msps 的产物；5.44 MS/s、12 位可以用 ~2 pF、~50 MHz、~0.3–0.8 mW 的 SHA。
