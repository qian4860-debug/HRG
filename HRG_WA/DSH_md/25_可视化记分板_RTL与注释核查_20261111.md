## 1. 可视化与 scoreboard 核查

### 1.1 五电极：已做到

| 入口/文件 | 作用 | 证据 |
|---|---|---|
| `five_inspect.m` | 跑 MATLAB 或原生 Simulink，打开三个窗口：记分板表、载波短窗、发布帧趋势 | 179 行；`drawBoard`/`drawWaveforms`/`drawFrames` |
| `five_scoreboard.m` | 共用判据：时间轴、驱动/检测/有效窗、ADC 流水线、DAC 门控、码格/量程、故障、有效帧、角 RMS、振幅 | 175 行；输出 `Node/Result/Detail` 表 |
| `five_instrument_model.m` | 给 inspect 模型加 23 路命名日志、`Scoreboard monitor` 注释和 Data Inspector 入口 | 模型内注释 + 日志 |
| `hrg_5e_continuous_inspect.slx` | 连续版观察模型 | 存在 |
| `hrg_5e_tdm_shared_inspect.slx` | 分时版观察模型 | 存在 |
| `five_build(...,true)` | 重新生成 inspect 模型 | `five_build.m` |

`five_inspect` 的图形内容：
- **记分板表**：节点/判据、PASS/FAIL/WARN/SKIP、测量值与条件；
- **载波时间尺度**：DAC 输出、A–D 组端相对 COM 电压、THX2024 C/V、ADC 输入/量化输出、驱动/检测/有效窗、ADC/DAC 限幅；
- **发布帧时间尺度**：I/Q、归一化振幅、机体角度、角增量误差（mrad）。

`research/five_scoreboard_rtl_20261110/verification.json` 的名义结果：连续 816 帧、角 RMS 3.04e-5 rad，`PASS_WITH_WARNING`（评分前 32 拍 DAC 限幅）；分时 DAC/25 204 帧、3.42e-3 rad，`PASS`。原生/ MATLAB 最大差 1.97e-14 / 1.32e-12。

**注意**：`five_scoreboard` 默认角 RMS 阈值 0.015 rad，3.4e-3 的分时异常仍会“PASS”。可视化图能看到它，但判据没有把它标成风险；下一版应把“0.5 rad/s 相对 0 rad/s 的倍数”单列成检查项，或把阈值按工况收紧。

### 1.2 6800 Hz 三版：部分做到

- `h68_verify.m` 有 3 组 parity、9 组 nominal、8 组灵敏度、9 组故障，写 `verification.json` 和日志；
- `h68_report.m` 只生成 `*_blocks.png` 和 `*_timing.png` 静态图（开关、电极、ADC、DAC 四行），不是交互记分板；
- 没有 `hrg_6800_*_inspect.slx`，没有 23 路命名日志，没有 Scoreboard monitor。

**缺口**：6800 三版（continuous / tdm_shared / tdm_separate）需要一套与 `five_inspect` 同构的 `h68_inspect`/`h68_scoreboard`，至少覆盖：
- 驱动/检测/有效窗、ADC 流水线、DAC 门控；
- ADC/DAC 码格与量程、限幅、失锁；
- I/Q、振幅、角度、角增量 RMS；
- 与 `h68_verify` 的 JSON 结果对拍。

## 2. 等价 RTL 与 SV testbench 核查

### 2.1 五电极：已做到

| 文件 | 作用 |
|---|---|
| `hrg_five_digital.v` | 连续/分时复用数字核：驱检窗、DDS、DAC 量化/整数分频、ADC 流水线/相位对齐、I/Q、幅值/正交控制、全角累计 |
| `tb_hrg_five_digital.sv` | 回放 MATLAB 在物理采样时刻的 ADC 码，逐拍比较时序、DAC、发布、Q24 I/Q/角度 |
| `tb_hrg_five_closed_loop.sv` | RTL 实际 DAC 码推进 `hrg_five_analog_plant.sv`，形成 26 状态机电闭环 |
| `hrg_five_analog_plant.sv` | 五电极机电/驱动/C/V 的 SV 行为模型 |
| `run_five_rtl.py` | Icarus 编译/运行/汇总 |

Icarus Verilog 13.0 结果（`verification.json`）：
- 回放：continuous 13057 拍/81 帧、tdm 65281 拍/20 帧、tdm DAC/25、continuous 过载；
- DAC 最大差 1 码；角度最大差 0.894–4.292 µrad；
- 闭环：continuous/tdm/tdm DAC/25 三组，事件不一致 0；对 MATLAB 最大角差 8.881 µrad / 0.894 µrad / 0.954 µrad。

**边界**：RTL 覆盖五电极 continuous/tdm_shared，不覆盖 6800 的 `tdm_separate`；真实 ADC/DAC 物理接口、时钟域、器件流水延迟仍需板级适配。

### 2.2 6800 Hz 三版：未做

- `tdm_separate` 没有等价 RTL/testbench；
- 6800 三版仍只有旧 `HRG_WA_Digital_ASIC_MATLAB_v4_6_5.../src` 的 v4.6.5 RTL，不是 6800 Hz 参数化核；
- 若要把五电极 RTL 复用到 6800 两通道，需要改 `detect_matrix`/`drive_matrix` 维度、`SAMPLES`（160/800）、`STRIDE`（5/1）和 `tdm_separate` 的驱动/检测组映射。
