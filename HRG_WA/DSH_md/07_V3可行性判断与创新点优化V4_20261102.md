## 2. 我认的三条（含新增证据）

### 2.1 "旋转不变 ≠ 可辨识"：V3 对，我的说法缺条件

V3 的反例（式 1–2）：`G=[1,0]ᵀ, H=[1,0]`，第二模态不可驱不可观 → 把 `d₂` 从 0.3 改到 0.9、`k₂` 从 4.3 改到 7，**输出完全不变**。

所以我在 DSH 06 写的"γ、Δγ、ω₀、Δω 可辨识"**缺了前提**。正确的表述是：

> 可辨识集合 = f(rank G, rank H)。**当且仅当 G、H 都满秩（两对电极都能驱、都能测）时**，D、K 的谱才可恢复；否则只能恢复被激励/被观测子空间上的组合。

**这条不是数学洁癖，是硬件闸门**：`rank G = rank H = 2` 在物理上就是"两对电极都可驱可测"。而这恰好是压电表头最容易不满足的地方（可能只有一对、或内部已合成 X/Y）。**所以 V3 把它写成前置条件是恰当的。**

### 2.2 "18 Hz"：V3 对，而且实际情况比 V3 说的更彻底——延迟根本不是环路瓶颈

V3 说 18 Hz 只是"45° 额度"的示例。我用项目源码查了真实环路频率：

| 环路 | 自然频率 | 7 ms 延迟的相位 | 占预算 |
|---|---:|---:|---:|
| 能量环 | **0.094 Hz** | 0.24° | 2% |
| 正交环 | **0.188 Hz** | 0.47° | 4% |
| DPLL | **2.36 Hz** | 5.9° | 51% |
| 设计预算 `p.tune.delayPhaseBudgetRad` | — | **0.20 rad = 11.5°** | 100% |

**结论：7 ms 延迟对能量/正交环几乎无影响，对 DPLL 只用掉一半预算。** 指标里的"18 Hz"在这个设计里毫无意义——环路比它慢 100 倍。

**真正受影响的是输出路径**：速率低通 45 Hz + Kalman，45 Hz 处 7 ms = **113° 相位**；V2/V3 记录的 32 帧端点估计实测（5 Hz 1.07/−1.55°、10 Hz 1.216/−9.50°、20 Hz 1.345/−41.16°）正好印证。

所以创新点四的题目必须再改一次：**不是"环路延迟预算"，是"输出动态保真度与估计器时间常数的最优选择"。**

### 2.3 "载波调制":V3 对，我的表述按分支错了

源码核对：
- `noise_research/sn_tick.m:23`：`raw = real(phasor*exp(1i*s.phase))` → **逐采样合成 DAC 载波电压**，然后量化；
- `revision_v10_2_cn/pcn_plant.m`：12 状态，含 `driver_tau`、传感端口电压 `x(7:8)`、电荷放大 `x(9:10)`、AFE `x(11:12)`、`detect_matrix`。

**所以压电 V10 分支已经表达了载波调制与模态反馈。** 缺的是旧包络链路（1 kHz 慢 DAC 码）。正确表述是：

> 不是"全系统缺调制"，而是"**两条分支实现层级不同，接口合同必须分别冻结**"——旧链是慢包络 + 外部调制假设，新链是逐采样载波。

## 3. V3 过度收缩的四处，以及怎么把强度找回来

V3 每处收缩都正确，但收缩后"创新性"也被削掉了。优化的原则是：**保留它加的约束，把结论做成"可发表的形式"。**

### 3.1 点一：从"系统辨识"升级为"Lynch 四参数的端口反演定理"

V3 §2.3 给了构造，但没把它接回 Lynch。**这一段可以接得很漂亮**：

由 `B₂⁻¹B₁ = HDH⁻¹`、`B₂⁻¹B₀ = HKH⁻¹`（V3 式 5），取特征值：

```
D 的特征值 → d₁,₂ = 2(γ̄ ∓ δγ)     ⇒  γ̄ = (d₁+d₂)/4,  δγ = (d₂−d₁)/4
K 的特征值 → k₁,₂ = (ω̄ ∓ δω)²      ⇒  ω̄ = (√k₁+√k₂)/2,  δω = (√k₂−√k₁)/2
相对轴角   → tr(D̃K̃)/(2δ_dδ_k) = cos2Δα
```

**这四个数正好是 Lynch 的四参数，加上一个相对轴角。** 于是论文命题可以从"可辨识集合"升级为：

> **仅用端口传递矩阵（不需要厂商给任何内部参数），可反演 Lynch 四参数与阻尼/刚度主轴夹角；反演的可辨识性以 rank(G)=rank(H)=2 为充要条件；反演误差按给定不确定度传播到角度输出。**

这不是通用系统辨识，而是**陀螺专属的、可直接执行的表征算法**，它同时是 T0–T3 台架的计算内核。期刊从"可能只是章节"变成 Measurement 正刊级别。

### 3.2 点二：给"时间戳合同"一个形式定义

V3 §3.1 用散文说了"源窗口、计算可用、执行生效、相位历元"。把它写成三个时间戳和一个约束，就能变成可证的东西：

```
每个数据带 (t_s, t_a, t_e)：采样、算完可用、执行生效
合同 C1（分支内）：t_e − t_s = 常数（与输入无关）
合同 C2（跨分支）：φ(t_e) = φ(t_s) + FCW·(t_e − t_s)   （载波相位按时间戳前推）
合同 C3（调度）：所有任务的 t_a ≤ t_e
```

- C1 + C2 ⇒ "逐周期等价"可证，而不是"我们把流水线改短了"；
- C3 是资源优化的可行性约束；
- 反过来，**违反 C1 的任何优化都必须按"新增延迟"重新评分**（这正是 V3 §3.1 的要点，现在有形式化）。

这让点二的贡献从"组合优化"变成"**合同 + 优化**"，审稿人很难用"这不就是 CORDIC 复用吗"打掉。

### 3.3 点四：从"延迟预算"改成"输出动态保真度 + 最优时间常数"

既然延迟不卡环路（§2.2），点四就要回答一个真问题：**给定 ARW 和最大角加速度，输出带宽能做到多少、代价是什么？**

一阶估计器（时间常数 τ）的经典权衡：

```
噪声：      σ_θ ∝ 1/√τ
动态误差：  e_dyn ∝ τ²·|Ω̈|/ω_n²   （二阶估计器）
最优：      τ* ∝ (σ_θ / |Ω̈|)^{2/5}
```

于是可以把"32 帧端点估计"的实测幅相（5/10/20 Hz）当作基线，给出**一条 Pareto 曲线 + 一个最优 τ***，并回答"45 Hz 低通是否合理"。这是可算、可测、可发表的内容，且天然属于集成电路（估计器要落到硬件）。

### 3.4 点三、点五：把"降级"变成"负结论资产"

V3 已经把点三的判据写成 `rank(W_j)`（式 10），这点很好。建议再加一句：

> 当 `rank(W_j)=1`（所有开关状态只是同一权重的重复）时，换向不增加任何信息——**这是一个可发表的负结论**，而且能用现成的端口矩阵一次测出来。

点五同理：把"仿射不可辨识"（V3 §6 保留的尺度+偏置自由度）写成点一的一个特例，既省一篇，又加强点一。

## 6. 对 V3 的两点保留意见

1. **V3 §2.3 的正结论依赖 `P(s)⁻¹`，而 P(s) 是 2×2 有理矩阵。** 实际带噪数据上做矩阵求逆的数值稳定性 V3 自己承认未证。**建议改成"直接拟合带约束的状态空间模型"并用 `P(s)⁻¹` 只作理论证明**，否则实测时会踩条件数的坑（尤其频裂很小时 `B₂` 接近奇异）。
2. **V3 把"机械四参数"与"相对轴角"并列，但两者精度差一个量级。** 特征值（频率、阻尼）容易测到 1e-3 相对精度；相对轴角靠 `tr(D̃K̃)`，当 `δd` 或 `δk` 很小时信噪比会崩。**建议在验收里分别给两个精度等级**，不要用同一个"可辨识"标签。
