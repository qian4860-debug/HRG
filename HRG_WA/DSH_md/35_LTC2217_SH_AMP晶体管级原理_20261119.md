# 35 · LTC2217 `SH_AMP` 晶体管级原理详解

2026-11-19。对象是 Virtuoso 中的 LTC2217 `SH_AMP` 子系统及其子单元：

- `SH_CALIBRATION2`：补偿 DAC；
- `SH_CALIBRATION`：修调/逐次逼近控制器；
- `S_H_AMP`：采样保持放大器顶层；
- `AMP4`：第一级放大器；
- `AMP5`：第二级放大器（内部含 `AMP3`/`AMP2`）；
- `AMP3`、`AMP2`：增益/推挽输出级；
- `SH_CMFB`、`CMFB`：共模反馈；
- `SH_CLK_GEN`：采样/保持/均衡时钟与自举驱动；
- `SH_BIAS`：偏置产生。

读图边界：截图能看清器件名、部分 W/L、m 因子、电容/电阻值和引脚；`sch.oa` 是二进制，不能像网表一样逐线核对。下面按“从图上看/推断”讲拓扑，具体 W/L、m、偏置电流以 Virtuoso 原图为准。

---

## 1. 总览：SH_AMP 是一个“两级放大器 + 两套 CMFB + 校准 + 时钟/偏置”的系统

`S_H_AMP` 顶层：

```text
VL_P/VL_N
   │
   ▼
┌──────────────┐    VO_N/VO_P    ┌──────────────┐    OP/ON
│ AMP4         │───────────────▶│ AMP5         │──────────────▶
│ 第一级       │                │ 第二级       │
│ 高增益/低噪声 │                │ 大摆幅/驱动   │
└──────────────┘                └──────┬───────┘
                                       │
                    ┌──────────────────┴──────────────────┐
                    │                                     │
              ┌─────┴─────┐                         ┌─────┴─────┐
              │ SH_CMFB   │                         │ CMFB      │
              │ 采样/保持 │                         │ 放大相位  │
              │ 共模反馈  │                         │ 共模反馈  │
              └───────────┘                         └───────────┘

偏置：SH_BIAS → VBP1/VBP2/VBN1/VBN2/Y_OUT
时钟：SH_CLK_GEN → S_CLK/H_CLK/EQ_CLK + 自举时钟
校准：SH_CALIBRATION → ADJ → SH_CALIBRATION2 → COMP_P/N → 201.63fF 注入
```

从 `S_H_AMP` 图看：

- `AMP4` 的输出 `VO_N/VO_P` 接 `AMP5` 的输入；
- `AMP5` 输出 `OP/ON`；
- `SH_CMFB` 输出 `VCMFB`，接 `AMP5` 的共模控制；
- `CMFB` 输出 `VCM_O1`，也参与 `AMP5` 的共模/偏置；
- `SH_BIAS` 给 `AMP4/AMP5/CMFB` 提供 `VBP1/VBP2/VBN1/VBN2/Y_OUT`；
- `SH_CLK_GEN` 提供采样/保持/均衡时钟和自举驱动。

这是一个**两级高增益全差分放大器**，不是简单的单位增益缓冲器。第一级决定噪声和增益，第二级决定摆幅和驱动；两套 CMFB 分别保证采样相位和放大相位的输出共模。

## 2. `AMP4`：第一级高增益、低噪声放大器

### 2.1 从图上看到的器件

- 顶部：`M1097`、`M3311` 两个 PMOS 电流源，栅极 `VBN2`，源接 `VDD`。
- 它们的漏极通过 `RZ19`、`RZ71`（6.05 kΩ）接到输出节点 `VO_N/VO_P`。
- 输入对：`M1362` 和右侧对称的 NMOS，栅极 `VL_P/VL_N`。
- 输入对源极接尾部电流源：`M1395/M1404`（栅极 `VBN1`）以及 `M18/M20` 等。
- 输出节点还有 cascode/电流源器件 `M?`，栅极 `VBN1/VBN2`；`EN` 控制使能开关。
- 右侧有补偿/负载电容（8.8 pF 量级）和 `M1367` 等器件。

### 2.2 拓扑判断

这是一个**全差分 telescopic cascode（或折叠 cascode）第一级**：

```text
VDD
 │
PMOS 电流源 M1097/M3311（VBN2）
 │
RZ19/RZ71（6.05k）
 │
 ├─────────────── VO_N
 │
NMOS cascode（VBN1）
 │
NMOS 输入对 M1362 / 对称管（VL_P/VL_N）
 │
NMOS 尾电流源 M1395/M1404（VBN1）
 │
GND
```

更准确地说：

- PMOS 电流源提供偏置电流；
- 电阻 `RZ19/RZ71` 可能是**源极退化/负载/电压降**，用来改善线性度或设置输出共模；
- NMOS 输入对把差分电压变成差分电流；
- cascode 器件提高输出阻抗，从而提高第一级增益；
- 尾电流源设定总电流和 gm；
- `EN` 控制该级上电/关断。

### 2.3 为什么第一级这样设计

16 位 ADC 需要：

1. **低输入噪声**：输入对是 NMOS，`gm` 大；增大 `W/L` 和电流可以降低热噪声，但会增加寄生电容。
2. **高增益**：cascode 把输出阻抗从 \(r_o\) 提高到 \(g_m r_o^2\)，第一级增益约：

\[
A_{v1}\approx g_{m,in}(R_{out,n}\parallel R_{out,p})
\]

cascode 后 \(R_{out}\) 很大，单级可做到 60–80 dB。

3. **低失真**：全差分抵消偶次谐波；cascode 提高输出阻抗，减小增益压缩。
4. **可控共模**：输出共模由 PMOS 电流源和 NMOS 尾电流的匹配决定，最终由 CMFB 修正。

### 2.4 噪声

输入对的热噪声：

\[
\overline{v_{n,in}^2}\approx \frac{8kT\gamma}{g_{m,in}}
\]

要降低噪声，必须提高 \(g_{m,in}\)（增大电流或 W/L），或用 chopping/自动调零（本图没有明显 chopping，靠大器件和校准）。第一级增益越高，后级的噪声贡献越小。

### 2.5 输出摆幅

Telescopic cascode 的缺点是输出摆幅较小：输出节点被 PMOS cascode 和 NMOS cascode 的过驱动电压限制。`AMP4` 只需要驱动 `AMP5` 的输入，不需要大摆幅，所以这个取舍合理：**第一级换增益，第二级换摆幅**。

## 3. `AMP5`：第二级增益 + 推挽输出

### 3.1 从图上看

- 顶部：PMOS 电流源 `M73`、`M2843`（`VBP2`）。
- 中间：PMOS cascode `M2582`、`M3308`，栅极 `VBP1`。
- 输入：`VL_P/VL_N` 通过左侧 NMOS 差分对（`M3312/M3313` 等）进入。
- 输出节点 `VO_N/VO_P` 在 cascode 漏极。
- 下方：NMOS 电流源/镜像 `M585`、`M3386` 等，栅极 `VBN1/VBN2`。
- 右侧：一个三角形符号，内部标 `S`/`AMP3`/`AMP2`，这是 **推挽/class-AB 输出级**（下一节详述）。
- `VCMFB` 引脚接 `SH_CMFB`/`CMFB`，控制输出共模。

### 3.2 拓扑判断

`AMP5` 不是单管共源级，而是：

```text
VL_P/VL_N
   │
   ▼
NMOS 差分对 + PMOS cascode 负载（第一半）
   │
   ▼
class-AB 推挽输出级（AMP3/AMP2）
   │
   ▼
OP/ON
```

- 前半部分提供增益；
- 后半部分提供大摆幅、大电流驱动；
- `VCMFB` 控制输出共模；
- `VBP1/VBP2/VBN1/VBN2` 给 cascode/电流源偏置；
- `V_IN` 可能是输入共模/偏置参考。

### 3.3 为什么需要 class-AB 输出

采样保持放大器在保持相位要驱动：

- 第一级流水线的采样电容；
- 片内寄生/测试负载；
- 可能的反馈网络。

如果输出级只有甲类电流源，静态功耗会很大；class-AB 推挽可以在大信号时提供大电流，小信号时静态电流较小，兼顾速度和功耗。代价是**交越失真/偏置点敏感**，需要仔细设计偏置和局部反馈。

### 3.4 补偿

`AMP5` 内部 `AMP3`/`AMP2` 的输出节点有 Miller 补偿：

- `C22`（约 3.3 pF）+ `R77`（约 1 kΩ）；
- `C23`（约 3.3 pF）+ `R69`（约 1 kΩ）。

Miller 电容把主极点分裂，R 产生一个左半平面零点：

\[
f_z\approx\frac{1}{2\pi R C}
\]

以 3.3 pF、1 kΩ 估算，零点约 **48 MHz**，用来抵消输出极点、提高相位裕度。具体值以原图为准。

## 4. `AMP3`：折叠 cascode / 增益级

### 4.1 从图上看

- 顶部 PMOS 电流源：`M185`、`M102`、`M2877`，栅极 `VBP2`。
- PMOS cascode：`M206`、`M105`、`M2069`，栅极 `VBP1`。
- 输入对：`M166`、`M2849`（NMOS），栅极 `VL_P/VL_N`。
- 输出 cascode：`M170`、`M2850`，输出 `VO_N/VO_P`。
- 底部 NMOS 电流源/镜像：`M250`、`M236`、`M247`、`M239`、`M223`、`M231`、`M230`、`M246`、`M215` 等，栅极 `VBN1/VBN2`。
- 右侧 Miller 补偿 `C22/R77`、`C23/R69`。
- 右下角 `DUMMY DEVICES`：dummy 管，匹配寄生/工艺。

### 4.2 拓扑判断

这是典型的**折叠 cascode 增益级**：

```text
VDD
 │
PMOS 电流源 M185/M102/M2877
 │
PMOS cascode M206/M105/M2069
 │
 ├────────────── VO_N
 │
NMOS cascode M170/M2850
 │
NMOS 输入对 M166/M2849（VL_P/VL_N）
 │
NMOS 电流源 M250/M236...（VBN1/VBN2）
 │
GND
```

特点：

- 输入对是 NMOS，提供高 gm；
- PMOS cascode 作为负载，提供高输出阻抗；
- 折叠 cascode 允许输入/输出共模独立设计，摆幅比 telescopic 大；
- Miller 补偿保证闭环稳定；
- 多组并联 NMOS/PMOS 用于电流比、匹配和版图对称。

### 4.3 增益

折叠 cascode 的增益：

\[
A_v\approx g_{m,in}\left[(g_{m,p}r_{o,p}^2)\parallel(g_{m,n}r_{o,n}^2)\right]
\]

比单管共源高得多。`AMP3` 与 `AMP4` 级联，总增益可超过 100 dB，满足 16 位有限增益误差要求。

### 4.4 Miller 补偿与稳定性

`C22/R77`、`C23/R69` 跨接在输出和内部高阻节点之间：

- 主极点被 Miller 效应推到低频；
- 输出极点被推到高频；
- R 产生零点，抵消非主极点；
- 保证相位裕度 >60°。

### 4.5 Dummy 器件

`DUMMY DEVICES` 里的 `M23`/`M215` 等与主器件同尺寸、同方向，但不参与信号：

- 匹配扩散/STI 应力；
- 匹配寄生电容；
- 保证差分两边的环境一致；
- 减小系统失调和偶次失真。

## 5. `AMP2`：推挽/class-AB 输出级

### 5.1 从图上看

- 顶部 PMOS 电流源：`M1766`、`M145`，栅极 `VBP2`。
- PMOS cascode：`M466`、`M143`，栅极 `VBP1`。
- 输入对：`M3319`、`M319`（NMOS），栅极 `VL_N/VL_P`。
- 输出：`VO_N/VO_P`，在 cascode 漏极。
- 右侧补偿电容 `C281`（约 11.37 pF?）和 `C?`（约 6.2 pF?）。
- 右下角 `DUMMY DEVICES`。

### 5.2 拓扑判断

`AMP2` 是一个**差分输入、推挽输出的 class-AB 级**：

```text
VL_N/VL_P
   │
   ▼
NMOS 差分对 M3319/M319
   │
   ▼
PMOS cascode 负载 M466/M143
   │
   ▼
VO_N/VO_P
```

- 输入对把差分电压变成差分电流；
- PMOS 电流源/ cascode 作为负载；
- 输出节点直接驱动下一级/负载；
- 补偿电容保证局部/整体稳定；
- `VBP1/VBP2/VBN1/VBN2` 设置静态工作点。

### 5.3 为什么叫 class-AB

从器件排列和 `m` 因子看，输出级有较大的 PMOS/NMOS 并联器件，能够在大信号时提供推挽电流；静态电流由 `VBP/VBN` 偏置决定。这样：

- 小信号时功耗可控；
- 大信号时驱动能力强；
- 但偏置点、交越失真和 PVT 敏感，需要 CMFB/局部反馈。

### 5.4 补偿

`C281`、`C?` 是补偿/负载电容，跨接在输出和内部节点之间；与 `AMP3` 的 Miller 电容一起，保证多级放大器的相位裕度。具体连接以原图为准。

## 6. `SH_CMFB`：采样/保持相位的共模反馈

### 6.1 从图上看

- 输入：`VCM`（参考共模）、`DUMMY_IN`（反馈/匹配输入）。
- 偏置：`VBN1`、`VBN4`。
- 使能：`EN`。
- 输出：`VCMFB`。
- 内部：PMOS 电流源 `M3393/M3394`（dummy 区）、NMOS 差分对 `M3344/M648`、电流镜负载 `M98`/`M?`、使能开关 `M3385/M3380`、电容。
- 右侧 `DUMMY DEVICES` 匹配。

### 6.2 工作原理

`SH_CMFB` 是一个**共模误差放大器**：

```text
VCM ──┐
      ├── 差分对 M3344/M648 ── 电流镜负载 ── VCMFB
DUMMY_IN ──┘
```

- `VCM` 是目标输出共模；
- `DUMMY_IN` 是输出共模的检测/匹配输入（可能来自开关电容检测网络）；
- 差分对比较两者，误差电流经电流镜转成单端电压 `VCMFB`；
- `VCMFB` 送回 `AMP5` 的共模控制端，调整输出共模；
- `EN` 控制该 CMFB 是否工作；`VBN1/VBN4` 设置尾电流/负载。

为什么叫 `SH_CMFB`：它主要在**采样/保持相位**工作。采样/保持时，主放大器可能处于 unity-gain/reset，输出共模容易被电荷再分配拉偏；这套 CMFB 专门稳住这个相位。

### 6.3 与主 CMFB 的区别

- `SH_CMFB`：面向采样/保持相位，可能更快、更简单，输入 `DUMMY_IN` 做匹配；
- `CMFB`：面向放大相位，用开关电容采样输出共模，精度更高但更慢。

两套 CMFB 通过时钟切换，避免互相打架。

## 7. `CMFB`：开关电容共模反馈

### 7.1 从图上看

- 输入：`VL_N`、`VL_P`（放大器输出），`VCM`（参考）。
- 时钟：`CLK3`/`_CLK3`、`CLK1`/`_CLK1`、`OP_CLK`。
- 输出：`VCM_O1`。
- 内部：PMOS 开关 `M718/M729`、电容、差分对 `M?`、电流镜、输出级 `M165/M169/M181/M164/M?`、补偿电容。
- 右下 `DUMMY DEVICES`。

### 7.2 工作原理

这是一个**离散时间/开关电容 CMFB**：

1. 在 `CLK3` 相位，开关把 `VL_P/VL_N` 的共模采样到电容上；
2. 在 `CLK1` 相位，采样值与 `VCM` 比较；
3. 差分对把误差放大，电流镜转成 `VCM_O1`；
4. `VCM_O1` 控制主放大器的偏置/共模；
5. `OP_CLK` 控制输出级/保持。

开关电容的好处：

- 不需要连续电阻分压，避免加载输出；
- 采样保持后比较，降低 offset；
- 可以用时钟精确控制共模检测时刻，避开输出瞬态。

代价：

- 需要非交叠时钟；
- 开关电荷注入/时钟馈通会引入残余 offset；
- 需要 dummy/对称版图。

### 7.3 `VCM_O1` 的作用

`VCM_O1` 是 CMFB 的输出控制电压，送到 `AMP5` 的共模控制端，调节 PMOS/NMOM 电流源的相对强度，使 `(OP+ON)/2` 回到 `VCM`。

## 8. `SH_CLK_GEN`：采样/保持/均衡时钟与自举驱动

### 8.1 从图上看

- `U11 RC_DELAY`：输入 `LVDD1`、`ADJ1_R..ADJ8_R`、`AINP/AINN`、`CLK1/CLK2`；输出 `VCM`、`AP_DELAY/AN_DELAY`、`CLK1_1/CLK2_1`、`S_CLK/S_CLK_1`。
- `U10 SCK_BOOTSTRAP`：输入 `AINP/AINN`、`AP_DELAY/AN_DELAY`、`CLK2_1/CLK1_1`、`S_CLK/S_CLK_1`；输出 `S_CLK/S_CLK_1`。
- `U5 HCK_BOOTSTRAP`：输入 `VL_P/VL_N`、`CLK2/CLK2_1`、`CLK1`；输出 `H_CLK/H_CLK_1`。
- `U9 EQCK_BOOTSTRAP`：输入 `LVDD2`、`V_IN`、`CLK1/CLK2`；输出 `EQ_CLK`。
- 图上标注：**“Sampling clock is opposite with holding clock”**（采样时钟与保持时钟相反）。

### 8.2 工作原理

```text
CLK1/CLK2
   │
   ▼
RC_DELAY（ADJ1_R..8_R 修延迟）
   │
   ├── AP_DELAY/AN_DELAY → SCK_BOOTSTRAP → S_CLK
   ├── CLK1_1/CLK2_1 → HCK_BOOTSTRAP → H_CLK
   └── CLK1/CLK2 → EQCK_BOOTSTRAP → EQ_CLK
```

- `RC_DELAY` 用可调电阻/电容和 `ADJ*_R` 修非交叠/延迟；
- `SCK_BOOTSTRAP` 产生采样开关的自举栅极驱动；
- `HCK_BOOTSTRAP` 产生保持开关的自举驱动；
- `EQCK_BOOTSTRAP` 产生均衡开关驱动；
- `S_CLK` 与 `H_CLK` 反相/非交叠，保证采样和保持不同时导通；
- `VCM` 由 RC_DELAY 产生/缓冲，给采样网络提供共模。

### 8.3 为什么需要自举

采样开关是 NMOS，栅极电压必须高于 `AINP/AINN + VTH` 才能导通。自举电路把栅极抬到 `VIN + VDD` 附近：

\[
V_{GS}\approx V_{DD}
\]

这样 \(R_{on}\) 近似恒定，输入大信号时不会因 \(V_{GS}\) 下降而变慢/失真。`SCK_BOOTSTRAP` 和 `HCK_BOOTSTRAP` 分别服务采样/保持开关。

### 8.4 非交叠

如果 `S_CLK` 和 `H_CLK` 同时有效：

- 采样电容和保持节点同时导通；
- 电荷共享，采样值被破坏；
- 可能产生大贯通电流。

所以图上明确写“sampling clock is opposite with holding clock”，并用 RC_DELAY 保证先开后合。

## 9. `SH_BIAS`：偏置产生

### 9.1 从图上看

- 输入：`BIAS_EN`、`IBN1`。
- 输出：`VBP1`、`VBP2`、`VBN1`、`VBN2`、`Y_OUT`。
- 90 个器件，包含 PMOS/NMOS 电流镜、电阻、电容、dummy、启动电路（`M1444/M1434`）。
- 左侧 `M1448/M1150`、`R?` 产生参考电流；右侧多组镜像输出。

### 9.2 工作原理

典型结构：

```text
IBN1 → 参考电流/电流镜 → 启动电路 → 多组 PMOS/NMOS 镜像
                                   ├── VBP1/VBP2（PMOS cascode 偏置）
                                   ├── VBN1/VBN2（NMOS cascode 偏置）
                                   └── Y_OUT（输出级参考）
```

- `BIAS_EN` 控制上电/关断；
- `IBN1` 是外部/内部参考电流；
- 启动电路防止电流镜停在零电流状态；
- 电阻/电容滤波，降低偏置噪声；
- dummy 器件匹配；
- 多组 m 因子设置电流比。

### 9.3 为什么偏置这么复杂

16 位/105 Msps 对偏置非常敏感：

- 偏置噪声会调制 gm，转化为输出噪声；
- 偏置 PVT 漂移会改变共模/摆幅；
- 启动失败会导致放大器不工作；
- 电流镜失配会引入系统失调。

所以 `SH_BIAS` 用 cascode 镜像、启动电路、滤波、dummy 和多路输出，保证 `AMP4/AMP5/CMFB` 的工作点。

## 10. `SH_CALIBRATION2`：5 位补偿 DAC

### 10.1 从图上看

- 输入：`VREF`、`VH`、`VL`、`ADJ1..5`、`CLK`、`ENB`、`LIN`。
- 输出：`COMP_P/COMP_N`。
- 内部：上下两组电阻串（R?），大量 CMOS 开关（M?），PMOS 电流源，NMOS cascode，dummy 器件，电容。
- 左侧 `CLK` 通过传输门 `M490/M438` 控制采样/更新。

### 10.2 工作原理

这是一个**电阻串 DAC + 缓冲/开关网络**：

```text
VH ── R ── R ── ... ── R ── VL
       │    │          │
      开关阵列（ADJ1..5）
       │
       ▼
   缓冲/电平移位 → COMP_P/COMP_N
```

- `VH/VL` 定义补偿电压范围；
- 电阻串产生 \(2^5=32\) 个 taps；
- `ADJ1..5` 控制开关，选择 tap；
- 上下两组对称，产生差分 `COMP_P/COMP_N`；
- `CLK`/传输门用于采样/保持或更新，避免开关瞬间的 glitch 直接进入采样节点；
- dummy 开关匹配电荷注入；
- `VREF` 给缓冲/偏置。

### 10.3 输出到采样网络

`COMP_P/COMP_N` 驱动四个 **201.63 fF** 补偿电容，向采样节点注入差分电荷。等效输入修正：

\[
\Delta V_{in}\approx\frac{C_{cal}}{C_s}(V_{COMP_P}-V_{COMP_N})
\]

`C_cal=201.63 fF`，`C_s` 是采样电容（几十 pF 量级），所以修正范围是 mV 级，用于修失调/增益/电荷注入残余。

### 10.4 为什么用电阻串 DAC

- 单调性好（电阻串天然单调）；
- 5 位规模小，32 个 tap 容易匹配；
- 差分输出对称；
- 比电流舵 DAC 简单，适合低速静态 trim。

代价是开关导通电阻/寄生会影响建立，需要缓冲和 dummy。

## 11. `SH_CALIBRATION`：修调/逐次逼近控制器

### 11.1 从图上看

- 输入：`IN1..IN4`、`DUMMY_IN1..4`、`CP_CLK`。
- 输出：`ADJ0..ADJ3`（图上 3 个完整 bit slice + 顶部辅助/最高位）。
- 内部：传输门 `M?`、NAND 锁存器（`I50/I51` 等）、反相器 `I47/I48`、输出缓冲。
- 32 个器件，38 个 net，是数字/开关逻辑，不是模拟放大器。

### 11.2 工作原理

每个 bit slice 是一个**动态锁存/比较单元**：

```text
INx ──[传输门]──┐
                ├── NAND 锁存 ── 反相器 ── ADJx
DUMMY_INx ──────┘
       ▲
     CP_CLK
```

- `CP_CLK` 控制传输门采样；
- `INx/DUMMY_INx` 是比较器/检测输入；
- NAND 交叉耦合形成再生锁存；
- 输出 `ADJx` 是当前位的判决；
- 逐位从 MSB 到 LSB 试，形成 SAR 修调码。

### 11.3 校准流程

1. 进入校准模式，SH 输入接参考/零输入；
2. U18 从 MSB 开始，设 `ADJ` 位；
3. U4 输出补偿电压，通过 201.63 fF 注入；
4. 比较 SH 输出与目标，决定该位保留/清除；
5. 逐位到 LSB；
6. 锁存 `ADJ`，正常转换。

这是**前台/出厂修调**，不是连续后台自适应。校准完成后，`ADJ` 码保持，补偿 DAC 输出静态修正电压。

### 11.4 `ADJ*_R` 修时钟

U18 的输出还可能送到 `SH_CLK_GEN` 的 `ADJ1_R..8_R`，修 RC 延迟/非交叠。这样模拟失调和时钟延迟一起修，保证采样沿和电荷注入最优。

## 12. 这些块如何协同工作

### 12.1 上电/偏置

1. `BIAS_EN` 有效；
2. `SH_BIAS` 启动，产生 `VBP1/VBP2/VBN1/VBN2/Y_OUT`；
3. `AMP4/AMP5/CMFB` 获得偏置，输出共模建立；
4. `SH_CLK_GEN` 产生时钟，S/H 进入复位/均衡。

### 12.2 校准

1. 输入接参考；
2. `SH_CALIBRATION` 逐位调整 `ADJ`；
3. `SH_CALIBRATION2` 输出 `COMP_P/COMP_N`；
4. 201.63 fF 注入采样节点；
5. 最小化失调/增益误差；
6. 锁存码。

### 12.3 正常采样/保持

1. `EQ_CLK` 复位/均衡；
2. `S_CLK` 采样，输入开关自举导通；
3. `S_CLK` 断开，`H_CLK` 接通保持/反馈；
4. `AMP4` 放大，`AMP5` 推挽输出；
5. `SH_CMFB`/`CMFB` 稳住共模；
6. `OP/ON` 送第一级流水线。

### 12.4 为什么两套 CMFB

- 采样/保持相位：主放大器可能处于 reset/unity-gain，输出共模容易受电荷再分配影响；`SH_CMFB` 快速稳住。
- 放大相位：输出共模需要高精度；`CMFB` 用开关电容采样，精度更高。
- 两者按时钟切换，避免同时驱动同一节点。

## 13. 关键计算

### 13.1 第一级增益

\[
A_{v1}\approx g_{m,in}(R_{out,n}\parallel R_{out,p})
\]

cascode 输出阻抗：

\[
R_{out}\approx g_m r_o^2
\]

目标：第一级 60–80 dB，第二级再提供 40–60 dB，总 >100 dB。

### 13.2 两级 GBW

\[
GBW\approx\frac{g_{m1}}{C_c}
\]

`C22/C23` 约 3.3 pF；若 `gm1` 约 1 mS，GBW 约 48 MHz。实际 400 MHz S/H 需要更高的 gm/更复杂的补偿，具体以仿真为准。

### 13.3 Miller 零点

\[
f_z\approx\frac{1}{2\pi R_z C_c}
\]

3.3 pF、1 kΩ → 约 48 MHz，用于抵消非主极点。

### 13.4 噪声

输入对热噪声：

\[
\overline{v_{n,in}^2}\approx\frac{8kT\gamma}{g_{m,in}}
\]

16 位、2.75 Vpp、LSB 41.96 µV；采样电容 kT/C 要低于 0.5 LSB，需要 \(C_s>18.8\) pF（0.5 LSB 口径）。第一级 gm 要足够大，使 OTA 噪声低于 kT/C。

### 13.5 CMFB 环路

CMFB 的环路增益/相位裕度要单独仿真：

- `SH_CMFB` 在采样/保持相位；
- `CMFB` 在放大相位；
- 切换时不能有大的共模跳变；
- 开关电荷注入要对称。

## 14. 设计启示与常见坑

1. **第一级换增益，第二级换摆幅**：不要指望一级同时做到低噪声、高增益、大摆幅。
2. **cascode 提高增益但吃摆幅**：`AMP4` 输出摆幅小没关系，`AMP5` 要负责大摆幅。
3. **class-AB 输出要防交越失真**：偏置点、局部反馈、dummy 匹配都很关键。
4. **两套 CMFB 要分时**：同时工作会互相拉扯；时钟非交叠是必须的。
5. **校准 DAC 要防 glitch**：`CLK`/传输门/缓冲/ dummy 都是为了更新时不影响采样节点。
6. **自举时钟要非交叠**：S_CLK/H_CLK 同时有效会电荷共享；图上明确写“sampling clock is opposite with holding clock”。
7. **偏置要防零电流**：`SH_BIAS` 的启动电路不是装饰；没有它，电流镜可能停在零。
8. **dummy 不是可有可无**：16 位系统里，dummy 管/电容决定差分对称和系统失调。
