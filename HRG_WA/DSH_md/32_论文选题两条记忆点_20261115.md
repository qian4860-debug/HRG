# 32 · 论文选题的两条记忆点（长期写作卡）

2026-11-15。给全角陀螺、接口 ASIC、ADC/DAC/DPLL 以及后续所有论文共用。与 [39 号双路线记忆](../codex_md/39_全角陀螺论文双路线与长期写作记忆_20261114.md) 配套；39 号管“三条路线与证据阶梯”，本卡只管**审稿人合上论文后还能记住什么**。

---

## 1. 两条记忆点

### 记忆点 A｜“新能力”

> **审稿人记住的是：这个芯片/方法能做到以前做不到的事。**

可以是四类之一，但只能选一个主类：

| 类型 | 记忆句式 | 最小证据 |
|---|---|---|
| 新观测 | “以前看不见的误差，现在能看见/分离” | 新观测 + 秩/CRB/条件数 + 独立验证 |
| 新机制 | “以前不能解释的失效，现在有机制并能被关掉” | 机制 + 消融 + 两条基线 |
| 新性能 | “同一误差下，功耗/面积/时延/速度明显更好” | 同口径对比 + 代价 + PVT |
| 新代价 | “以前做不到的低功耗/小面积，现在能付得起” | 功耗/面积分项 + 校准成本 |

**不是记忆点：** “我们用了 Pipeline+SAR+ΣΔ+AI”“我们加了校准”“我们指标比某篇好 2 dB”。这些是手段，不是能力。

### 记忆点 B｜“新适配”

> **审稿人记住的是：在这个特定工况下，旧架构为什么会失效；这个设计为什么刚好适合。**

必须同时具备：

1. **一个真实工况**：不是“高温/航天”这种标签，而是可重复施加的应力/任务（TDM 切换、短窗、强驱动瞬态、冷启动、零净角往复、温变）。
2. **一个量化失效**：基线在该工况下错多少、丢多少帧、恢复多慢；不能只说“性能不足”。
3. **一个设计改动**：场景改变了哪个决策（量程、时序、复位、校准、封装、功耗）。
4. **一条应力曲线**：窗长/温度/驱动幅度/强弱轴，至少扫一个。
5. **一次复现**：不同表头/批次/天，至少一个外推方向。

**不是记忆点：** “我们的 ADC 更适合陀螺，因为陀螺需要高精度。”这是应用包装，不是适配。

### 记忆点 A×B｜“同一机制在特定工况下被放大”

> **审稿人记住的是：不是两张皮，而是一个机制同时解释了‘为什么旧方法在这里失效’和‘为什么新方法在这里有效’。**

成立条件：

- A 的机制和 B 的工况由**同一个误差量**连接（例如“首级记忆电荷”同时导致恢复慢和角误差大）。
- 常温消融证明增量；应力曲线证明外推。
- 标题/摘要只宣称已到达的证据级别（L0–L4）。
- 只立**一个**核心主张；其他改动都是消融或工程实现。

## 2. 本项目怎么套

### 2.1 Pipeline ADC 不是记忆点

- “12 位 5.44 MS/s Pipeline-SAR”本身不是记忆点：同节点有 10–12 mW 的硅测，同速率有 1.15 mW/88.8 dB 的 14 位基线；FOM 打不过。
- “Pipeline+SAR+校准+AI”是拼装，不是能力。
- “Pipeline 更适合陀螺”是应用包装，除非基线在 TDM 窗内量化失效。

### 2.2 本项目的 A×B 候选

**主张（可替换数字，不可替换结构）：**

> 在共用电极全角陀螺的驱检切换窗内，首级采样/残差节点的跨窗记忆是“首个可信样本”和“同窗角误差”的共同限制；用窗同步复位/共模预充 + 按采样时刻打标的有效位，可以在不增加窗长的条件下降低角误差，或在不增加角误差的条件下缩短无效等待。关闭该机制，收益消失。

- **A 的机制**：跨窗记忆电荷/共模状态；复位/预充改变首级状态；时间戳改变观测对齐。
- **B 的工况**：五电极 TDM、147 µs 窗、6.8 kHz 载波、双通道同步、驱动瞬态。
- **共同误差量**：首级记忆导致的 I/Q 偏差/协方差，而不是“ADC 位数不够”。
- **消融**：复位开/关、时间戳开/关、SAR/Pipeline、校准开/关。
- **系统指标**：首个可信样本、可用窗、角 RMS、斜率误差、覆盖率、每有效帧能量。

### 2.3 如果非要写 Pipeline

把 Pipeline 放在**实现**层，不放在**主张**层：

- 题目可以出现“TDM-aware”“window-synchronous”“timestamped”，不一定要出现“Pipeline”。
- 摘要第一句写系统失效和机制，第二句写实现载体；不要第一句写“本文提出一款 12 位 Pipeline-SAR”。
- 如果 SAR 也能做到，Pipeline 就只是“可选实现”，不要硬写成创新。

## 3. 一页模板（每篇论文开工前填）

1. **一句可被反例推翻的主张：** 在____条件下，____比____好/可辨/失效，因为____。
2. **基线是谁，在该工况为什么失败：** 基线____，失效量____，来源____。
3. **新增的是哪一类：** 新观测 / 新机制 / 新性能 / 新适配（只选一个主类）。
4. **证据在哪一级：** L0 / L1 / L2 / L3 / L4；标题只能宣称已到达的级别。
5. **代价是什么：** 功耗 / 面积 / 时延 / 校准时间 / 测试时间，至少一项。
6. **消融/盲测/阴性对照：** 关掉什么，收益消失？留出集是什么？只换标签不换硬件是什么？
7. **换表头/温度/批次还成立吗：** 至少一个外推方向。
8. **什么结果会让我们放弃：** 预先写停损点。

> 第 2、6、8 条答不出来，说明这篇论文还没有记忆点，只有工作量。

---

## 4. 三不要

1. **不要拼装。** 每加一个模块，先问“它解决了哪个主导误差？关掉它基线差多少？”答不出就不加。
2. **不要应用包装。** 场景必须改变设计决策，基线必须在该场景量化失效；否则只是换一段 introduction。
3. **不要用 AI 补观测。** AI 只拟合物理补偿后的残差；如果输入只有输出码，真实信号和污染同形，模型容量补不回缺失的观测。AI 必须与固定物理模型/查表/RLS 同预算比较，盲测不赢就不算贡献。

## 5. 本项目的记忆句（可直接背）

- **路线 A：** “别人看不见的误差，我们让它可见，并且能关掉验证。”
- **路线 B：** “在这个工况下，旧架构不是精度不够，而是根本来不及/恢复不了；我们的设计刚好改了这个决策。”
- **A×B：** “不是把两种手段拼在一起，而是同一个机制在同一个工况下被放大。”
- **Pipeline ADC：** “Pipeline 是载体，不是主张；先证明 SAR 不够，再证明两级残差能解决同一个误差。”
