# 6800 Hz 三版建模核查与采样率下限

日期：2026-11-10
输入：用户提问 51；`h68_config.m`、`h68_build.m`、`h68_verify.m`、`h68_sampling.m`；三份 `.slx`；`verification.json`、`sampling.json`、`parameter_summary.json`；本轮新增 `research/h68_audit_20261110/`。

结论先说：
1. **三份原生 Simulink 模型已经包含 thx2024 静态 C/V 增益、相同前置增益、6800 Hz/50 mHz/Q=30000/Cp=600 pF、连续 16/16 bit、TDM 10/14 bit。** 不是“待接入”，是已实现并有逐拍/闭环验证。
2. **理论 Nyquist 下限 13.60005 kS/s；带 100 Hz 包络 13.80005 kS/s。** AD9215 器件下限 5 MSPS；TDM 在整数采样约束下最小 **5.0048 MSPS（736 点/周期）**，当前 5.44 MSPS（800 点）不是必须。
3. **DAC 不需要 175 MSPS。** 8/16/32 点每周期分别 54.4/108.8/217.6 kS/s，ZOH 载波幅度下降约 2.5%/0.64%/0.16%；AD9707 在直流耦合时钟下没有固定最低时钟，板级耦合与重建滤波器才是约束。
4. **连续版当前 1.088 MSPS 对应 0.919 µs/样本。** 若“1–2 MHz 建立时间”实际指 1–2 µs 建立，则 1.088 MSPS 偏快；0.544 MSPS（80 点/周期，1.84 µs）参考模型已跑通，角度 RMS 从 3.19e-5 升到 4.30e-5 rad，仍很小。最终档位应由实测 AFE 建立时间决定。
5. **仍缺**：前置增益失配、Cds 馈通、驱动电压、温漂的 parameter sweep；TDM 5.0048 MSPS 的原生 `.slx` 重建；16 bit 的 ENOB/INL/DNL；8 电极分时扫描。详见 §5。

### 2.1 thx2024 C/V 的具体接入方式

`h68_config.m` 第 102–115 行：
- `chargeMap=[-I,0,Cds*drive_matrix,-Cs*I,0]/thx_charge_per_input`；
- 用 `useThxReadout` 把 C/V 从“电荷放大器积分器”替换为 thx 的**静态 Gain**；
- `c.cvOutputGain=p.pre_gain*p.thx_cv_gain`；
- `S(11:18,11:18)=I*charge_target/thx_charge_per_input`；
- `pickoff` 末两列乘 `cvOutputGain`；
- AAF 仍在 C/V 之后独立保留（`afe_bw=20 kHz`，4 阶）。

`tdm_shared` 时驱动/泄放窗的 C/V 输入置零，检测窗接 `chargeMap`；`tdm_separate` 时驱动/泄放窗也接 `chargeMap`。这与“同一物理电极在驱动窗接入驱动器、检测窗接检测”的两阶段方案一致。

**边界**：这不是 thx 原电路逐元件复刻。原文件 `loop_after_dem.slx` 的 `Kcvd=1e4`、`Kcvs=1e5`、`Kcsd=1e4`、`Kcss=1e5` 本身不相等；本模型只复用其**静态 C/V 增益形式**，并用同一个 `pre_gain=1` 保证驱动/检测前置归一化一致。绝对电荷灵敏度和实际前置增益仍需原理图/实测确认（见 §5）。

## 3. 采样率下限

### 3.1 理论 Nyquist

`f0=6800 Hz`，`split=0.05 Hz`，最高模态 `f_hi=6800.025 Hz`：

```
f_s > 2·f_hi = 13600.05 S/s
```

若包络/角运动边带保留到 `B_e=100 Hz`（预算假设，不是厂家指标）：

```
f_s > 2·(6800.025+100) = 13800.05 S/s
```

严格大于，不能在等号处选型。理想矩形驱动窗不严格带限，13.6 kS/s 不能保证开关边沿/建立，实际要留抗混叠与建立余量。

### 3.2 连续 16 bit 方案

当前模型 1.088 MSPS = 160 点/周期。若“1–2 MHz 建立时间”指**建立时间 1–2 µs**，则单样本周期必须 ≥ 建立时间：

| 建立时间 | 允许最高 fs | 可选整数点/周期 | 备注 |
|---:|---:|---:|---|
| 1 µs | 1.0 MSPS | 140 点/周期 = 0.952 MSPS（1.05 µs） | 1.088 MSPS 略快 |
| 2 µs | 0.5 MSPS | 72 点/周期 = 0.4896 MSPS（2.04 µs） | 80 点 = 0.544 MSPS（1.84 µs）也可 |

若“1–2 MHz”指**小信号带宽**而不是建立时间，则 1.088 MSPS 在 1–2 MHz 带宽内没有问题；此时 0.919 µs 周期对应的建立误差要由 AFE 的 16 bit 建立实测决定。**这是一个必须先确认的量纲/指标歧义**，不能同时把 1–2 MHz 和 1–2 µs 当成同一件事。

本轮 MATLAB 参考模型（`h68_rate_variants.m`，0.08 s，0.5 rad/s，16 bit）：

| 模式 | fs | 点/周期 | 角度 RMS rad | 幅度范围 |
|---|---:|---:|---:|---|
| continuous | 1.088 MSPS | 160 | 3.19e-5 | 0.999978–1.000168 |
| continuous | 0.544 MSPS | 80 | 4.30e-5 | 0.999942–1.000177 |

0.544 MSPS 仍可用；角度 RMS 增加约 35%，但绝对量很小。最终档位应由 AFE 建立实测与 16 bit 精度共同决定，而不是只看 Nyquist。

### 3.3 分时 10 bit ADC

AD9215 手册最低典型转换率 5 MSPS（低于此速率动态性能可能下降），因此候选下限不是 13.6 kS/s，而是 **5 MSPS**。模型要求每周期整数点且为 4 的倍数：

```
n_min = ceil(5e6/6800/4)*4 = 736
f_s,min = 736*6800 = 5.0048 MSPS
```

当前 5.44 MSPS = 800 点/周期，比最小值高 8.7%。MATLAB 参考模型（`h68_rate_variants.m`）：

| 模式 | fs | 点/周期 | 角度 RMS rad | 幅度范围 |
|---|---:|---:|---:|---|
| tdm_shared | 5.44 MSPS | 800 | 2.02e-3 | 0.998823–1.000107 |
| tdm_shared | 5.0048 MSPS | 736 | 2.00e-3 | 0.998655–1.000126 |
| tdm_separate | 5.44 MSPS | 800 | 2.09e-3 | 0.998879–1.000107 |
| tdm_separate | 5.0048 MSPS | 736 | 1.98e-3 | 0.998655–1.000126 |

在这个模型里，5.0048 与 5.44 的角度 RMS 基本相同；TDM 误差主要来自四段窗口/相位，不是采样率。**结论：ADC 可以按 5.0048 MSPS 选板级时钟；不必 65 MSPS。**

### 3.4 DAC 下限

DAC 只要重建 6800 Hz 载波与慢控制包络。按每周期点数和零阶保持（ZOH）基波幅度比：

```
|H_ZOH(f0)| = sin(π f0/f_D)/(π f0/f_D)
```

| 点/周期 | DAC 更新率 | ZOH 载波幅度下降 | 用途 |
|---:|---:|---:|---|
| 8 | 54.4 kS/s | 2.50% | 最低可用，需校准/滤波 |
| 16 | 108.8 kS/s | 0.64% | 推荐下限 |
| 32 | 217.6 kS/s | 0.16% | 保守 |
| 800 | 5.44 MSPS | ~0 | 当前模型，过设计 |

AD9707 是 14 bit、最高 175 MSPS 的**电流输出 DAC**（不是 ADC）；ADI 支持答复说明直流耦合时钟下没有固定最低时钟。板级要核查时钟耦合、输出变压器/缓冲、重建滤波和校准；6.8 kHz 不适合未经核查就套射频变压器输出路径。

### 3.5 结论表

| 项 | 理论下限 | 器件/模型下限 | 建议工作点 |
|---|---:|---:|---:|
| 连续 ADC 16 bit | 13.60005 kS/s | 16 bit、整数点/周期 | 0.544–1.088 MSPS，待建立实测 |
| 连续 DAC 16 bit | 13.60005 kS/s | 16 点/周期 = 108.8 kS/s | 108.8–217.6 kS/s |
| TDM ADC 10 bit | 13.60005 kS/s | AD9215 5 MSPS；整数约束 5.0048 MSPS | 5.0048–5.44 MSPS |
| TDM DAC 14 bit | 13.60005 kS/s | 16 点/周期 = 108.8 kS/s | 108.8–217.6 kS/s |

**65 MSPS / 175 MSPS 是器件上限，不是需求。** 65 MSPS 是 AD9215 的速度档上限；175 MSPS 是 AD9707 的上限。按 Nyquist 与建立/窗口预算，TDM ADC 5.0048 MSPS、DAC 108.8–217.6 kS/s 就够。

## 6. 下一步计划

### P0（1–2 天）：把“1–2 MHz / 1–2 µs”变成可执行指标

1. 在 `h68_config` 增加 `t_settle_s` 参数（默认空），并加断言 `1/fs >= t_settle_s`；不改变现有默认模型。
2. 生成连续版 0.4896/0.544/0.952/1.088 MSPS 四个变体，跑 `h68_reference` + 原生 `.slx` parity（0.02 s）。
3. 台架测 AFE 阶跃到 0.1%/16 bit 的时间；把实测值回填，选一个档位。
4. 输出：`rate_decision.json` + 一页对比表；明确“16 bit 建立”与“1–2 MHz 带宽”是两件事。

**门禁**：若实测建立 >2 µs，连续版必须 ≤0.5 MSPS；若 1 µs，≤1 MSPS；1.088 MSPS 只有在建立 ≤0.9 µs 时成立。

### P1（3–5 天）：TDM 5.0048 MSPS 原生化

1. 用 `h68_build` 生成 `hrg_6800_tdm_shared_5005` 与 `..._separate_5005`（fs=5.0048 MSPS，n=736）。
2. 跑 `h68_verify` 的 parity（0.006 s）与 nominal（0.3 s），对比 5.44 版。
3. DAC 扫 54.4/108.8/217.6 kS/s，保持 ADC 5.0048；比较角度 RMS、DAC 限幅、ZOH  Droop。
4. 输出：`tdm_rate_sweep.json`；决定板级时钟。

**门禁**：5.0048 版 parity 最大差 <1e-4；nominal RMS 不高于 5.44 版 +20%；DAC 108.8 kS/s 时 ZOH 下降 <1% 且角度 RMS 不恶化 >20%。

### P2（1 周）：增益匹配与馈通

1. 从原理图/实测取得驱动链与检测链的 C/V 增益；确认 `pre_gain` 一致，失配 ≤0.1%。
2. 在 `h68_config` 增加 `pre_gain_drive`/`pre_gain_sense`（或 `gain_mismatch`），加 0.1/0.5/1% 扫描。
3. 加 `Cds` 0.1/0.5/1 pF 扫描；连续版跑复数馈通，TDM 版跑驱动窗残压/检测窗串扰。
4. 输出：`gain_feedthrough_sweep.json`；给出补偿前/后 4θ 与零偏。

**门禁**：1% 失配下角度 RMS 不超过名义 2×；Cds=0.5 pF 时馈通解调偏量不超过 10 bit 半 LSB（或给出明确预算）。

### P3（1 周）：单表头温漂与批量散布

1. 选一个确定表头，测 f0/Q/split/Cp 随温度（至少 −20/25/60/85 °C，或实际工况）。
2. 在模型中加一维温度查表；不伪造“所有表头通用曲线”。
3. Monte Carlo：f0 ±0.5 Hz、split 0–50 mHz、Q 20k–40k、Cp 480–720 pF、pre_gain 0.5–1%、Cds 0–1 pF、驱动 5–20 V；每组合跑 0.1 s，统计角度 RMS/幅度/失锁。
4. 输出：`monte_carlo.json` + 最坏组合。

**门禁**：90% 组合不失锁、幅度 0.8–1.2；给出“合格表头”的参数窗口。

### P4（2 周）：8 电极分时与 FRP

1. 在 4 周期共用电极版基础上加 8 时隙扫描（每电极一槽），帧率 240 Hz；与 4 周期 1700 Hz 对照。
2. 时偏/相位：每槽记录 `t_k`，用 `exp(-jωΔt)` 旋转；验证 `sin4β` 不随时隙顺序漂移。
3. FRP：连续 6800 Hz 版作为金标准；TDM 版只做低速率 FRP 或加 Ω² 基。
4. 输出：`tdm8_compare.json` + FRP 混淆实验。

**门禁**：8 时隙角度 RMS 不超过 4 周期版 2×；时偏残余 ≤0.1°；FRP `sin4β` 漂移 <10%。

### P5（持续）：台架回填与 Git

- 按 `codex_md/23` 的 T0 台架顺序测 AFE 建立、C/V 增益、馈通、开关注入。
- 每次实测回填后重跑 P0–P4 的相关门禁。
