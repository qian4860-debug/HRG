## 0. 结论

1. **结构实现正确。** 默认组角 0°/45°/90°/135° 下，`H`、`H'·driveMap`、`senseMap·H` 都是秩 2，条件数 1；连续 A/B 驱、C/D 检，分时 A/C 与 B/D 反相驱、四组读、模拟半差，和 `five_verify` 的断言一致。
2. **原生模型正确。** continuous 326 块、tdm_shared 328 块；无 MATLAB Function/S-Function；逐拍最大差 1.97e-14 / 1.32e-12；6 组 nominal、2 组起振、4 组故障通过，`verification.json` 状态 `passed`。
3. **但“物理正确”还没证明。** 当前正确性依赖五个前提：组角、600 pF 口径、COM 理想参考、C 矩阵只有 A–C/B–D 互耦、驱动/检测组分配与极性。任一不成立，结论要改。
4. **TDM 0.5 rad/s 有一个未解释的异常。** RMS 3.41e-3 rad，且随评分起点在 1.9e-3–3.4e-3 间非单调振荡；不是简单启动瞬态。在把“分时版正确”写死之前，必须先做帧相位/检测窗中心对齐审计。

## 1. 结构核查

`five_config.m` 的默认端口：

```
angles = [0;45;90;135] deg
gains  = [1;1;1;1]
H      = [ 1  0
           0  1
          -1  0
           0 -1 ]          % 4 groups x 2 modes
```

### 1.1 连续驱检

```
driveMap = [1 0; 0 1; 0 0; 0 0]     % A/B 驱 X/Y
senseMap = [0 0 -1 0; 0 0 0 -1]     % C/D 检 -X/-Y
```

- `H'·driveMap = I₂`，秩 2；
- `senseMap·H = I₂`，秩 2；
- 条件数 1（默认对称参数）。

### 1.2 同端分时

```
driveMap = [ 1 0; 0 1; -1 0; 0 -1]   % A/C 反相、B/D 反相
senseMap = 0.5*[1 0 -1 0; 0 1 0 -1]  % (A-C)/2, (B-D)/2
driveMask = all four groups
senseMask = all four groups
```

- `H'·driveMap = I₂`，秩 2；
- `senseMap·H = 0.5 I₂`，秩 2；
- 条件数 1。

### 1.3 电容

```
C = diag([600 600 600 600] pF) + Cds * [[I,-I],[-I,I]]
Cds default = 0
cond(C) = 1
```

四个组端各 600 pF 对 COM，A–C、B–D 两支可调互耦；默认无互耦。

### 1.4 原生模型

| 模式 | 原生块数 | 逐拍最大差 | ADC/DAC | fs | 帧率 |
|---|---:|---:|---|---:|---:|
| continuous | 326 | 1.97e-14 | 16/16 bit | 1.088 MSPS | 6800 Hz |
| tdm_shared | 328 | 1.32e-12 | 10/14 bit | 5.44 MSPS | 1700 Hz |

`five_verify.m` 检查了：
- 无 `S-Function`、`MATLABFcn`、`MATLABSystem`、`FromWorkspace`、`MATLAB Function`；
- 4 组端口电容正定、驱动/检测秩 2、组电压可观测秩 4；
- 连续 A/B 驱、C/D 检；分时四组驱/检互锁；
- 分时泄放后残压 < 5% 驱动电压（实际 0.568 mV vs 2 V）；
- ADC 过载前后不发布角度/不使能反馈。

## 2. 五个“正确性前提”

### 2.1 组角必须是 0/45/90/135 的等价布置

默认 `H` 的秩 2 依赖 A/C、B/D 是正交差分对。若实物四组中心是 0°/90°/180°/270°，则

```
H = [1 0; -1 0; 1 0; -1 0]
```

秩退化为 1，当前 `driveMap/senseMap` 不能同时驱动/读出 X/Y。**这是第一硬门禁。** 必须用接线图/探针确认四组中心角，或把实际组角回填 `group_angles_deg` 后重算秩。

### 2.2 600 pF 是“每组对 COM”还是“四组总电容”

当前 `group_capacitance_F = repmat(600 pF,4,1)`，即每组 600 pF；四组同时接前端时总负载 2400 pF。

- 若 600 pF 是**单组对 COM**：当前正确。
- 若 600 pF 是**四组对 COM 的总电容**：每组应按 150 pF 左右，当前模型把负载/驱动电流/噪声放大了约 4 倍，连续与分时结果都会偏乐观或偏保守（取决于指标）。
- 若 600 pF 是“单端到壳体”的测量值，还要先换算到对 COM 的组端电容。

**这是第二硬门禁。** 在实测 4×4 电容矩阵前，所有绝对幅度/噪声/建立时间只能当相对趋势。

### 2.3 COM 是理想参考

模型把 COM 定义为理想电位参考，没有 COM 节点状态、回流阻抗、对壳电容。实际五端器件的 COM 要回流四组电流，COM 阻抗会把共模/差模耦合进来，尤其分时四组同时充放电时。

需要补：
- COM 对壳电容、COM 到前端参考的阻抗；
- 四组同时驱动时的 COM 回流；
- COM 阻抗引起的 A/B/C/D 共模偏移与驱检串扰。

### 2.4 C 矩阵只有 A–C/B–D 互耦

当前 `C = diag(cap) + Cds*[[I,-I],[-I,I]]`，只允许 A–C、B–D 两支互耦；默认 `Cds=0`。真实四组之间还有 A–B、B–C、C–D、A–D 以及各组对 COM/壳的耦合。

需要实测 4×4 `C_group`（或从物理片 `C_phys` 与接线矩阵 `W` 合成），替换当前对角+两支互耦。特别是 `Cds=0` 时，连续驱动的同频馈通没有被建模，分时“泄放后残压”只反映了驱动电压衰减，不是真实串扰。

### 2.5 驱动/检测组分配与极性是名义值

- 连续：A/B 驱、C/D 检；
- 分时：A/C、B/D 反相驱；四组读，`(A-C)/2`、`(B-D)/2`；
- 组增益全为 +1。

若实物接线是 A/B 检、C/D 驱，或某组压电极化反相，`H` 的符号/行顺序要改。模型可用 `group_charge_gain` 回填极性，但必须先用低电压扫频确认，不能靠“默认 +1”。

## 3. TDM 0.5 rad/s 异常

`verification.json` 的 nominal：

| 模式 | 0 rad/s | 0.5 rad/s | −4 rad/s |
|---|---:|---:|---:|
| continuous RMS rad | 4.22e-5 | 3.04e-5 | 9.68e-5 |
| tdm_shared RMS rad | 3.09e-4 | **3.41e-3** | 2.53e-3 |

连续版稳定在 3–10e-5；分时版 0.5 rad/s 比 0 rad/s 大一个数量级，也比 −4 rad/s 大。用 `five_error_vs_settle.m` 扫评分起点（0.5 rad/s）：

| 评分起点 s | 0.04 | 0.06 | 0.08 | 0.10 | 0.15 |
|---|---:|---:|---:|---:|---:|
| RMS rad | 1.95e-3 | 3.29e-3 | 1.92e-3 | 2.62e-3 | 3.38e-3 |

**非单调、随帧相位振荡**，不是简单启动瞬态。可能原因（尚未证实）：
1. 角度输出与检测窗中心的时间对齐；`checkNominal` 用发布时刻，不是检测窗中心；
2. 四段窗口的驱动/泄放/建立相位与 1700 Hz 帧的拍频；
3. 分时四组同时切换时 COM 回流/残压的帧相位依赖；
4. 10 bit 量化 + 半差组合在特定角度下的偏置。

**在解释清楚前，不应把“分时五电极闭环 RMS 3.4e-3”当作方案精度结论。** 连续版可以作为当前金标准；分时版先做相位对齐审计。

## 4. 下一步计划

### P0（立即，1 天）：确认三个硬前提

| 项 | 要确认 | 若不成立 |
|---|---|---|
| 组角 | 四组中心是 0/45/90/135 还是 0/90/180/270 | 后者 H 秩 1，当前接法不成立，需重新配对/接线 |
| 600 pF | 每组对 COM，还是四组总电容 | 总电容则每组 150 pF，重跑全部绝对指标 |
| 极性/组分配 | A/B 驱、C/D 检；A/C、B/D 反相；组增益符号 | 用 `group_charge_gain`/`group_angles_deg` 回填，重算秩/条件数 |

**门禁 G0**：`rank(H)=2`、`rank(H'·driveMap)=2`、`rank(senseMap·H)=2`；否则停止 TDM 结论，先改接线/分组。

### P1（2–3 天）：4×4 电容矩阵与 COM 回流

1. 测四组对 COM 的自电容、组间互电容、COM 对壳/对前端参考的阻抗。
2. 用 `C_group = Wᵀ C_phys W`（若拆到物理片）或直接实测 4×4 替换 `diag(cap)+Cds`。
3. 在 `five_config` 加 COM 节点状态/回流阻抗（至少一个 `R_com`、`C_com`），跑共模/差模馈通。
4. 输出 `port_matrix.json` 与 `com_return.json`。

**门禁 G1**：4×4 C 正定；COM 回流在 nominal 驱动下不导致组端电压偏移 >1%；连续馈通可复现。

### P2（3–5 天）：TDM 帧相位/角度时间对齐

1. 把角度输出对齐到检测窗中心（而不是发布时刻）；在 `checkNominal` 加 `center_to_publication` 修正。
2. 扫帧相位（0–1 帧）、4/8 周期帧、不同泄放/建立窗；看 0.5 rad/s RMS 是否收敛到 0 rad/s 量级。
3. 若仍振荡，分离 COM 回流、开关残压、10 bit 量化三个来源。
4. 输出 `tdm_phase_audit.json`。

**门禁 G2**：0.5 rad/s RMS 相对 0 rad/s 不超过 3×；否则 TDM 闭环精度不能作为结论。

### P3（1 周）：组增益/极性/Cds 扫描

1. `group_charge_gain` 取 1±0.5%/±1%，极性组合 ±1；`Cds` 取 0/0.1/0.5/1 pF。
2. 对每种组合算 `rank`、`cond(H)`、`cond(H'·driveMap)`、`cond(senseMap·H)`。
3. 连续 vs 分时同一表头、同一参数，比较角度 RMS/幅度/馈通。
4. 输出 `group_mismatch_sweep.json`。

**门禁 G3**：1% 失配下闭环不失锁；条件数 <10；连续/分时差异可解释。

### P4（3–5 天）：原生模型变体

1. 生成“600 pF 总电容（每组 150 pF）”变体，重跑 parity/nominal，确认不是只在“每组 600 pF”下成立。
2. 生成“实测 4×4 C + COM 阻抗”变体（若 P1 完成）。
3. 保持无 MATLAB Function/S-Function；更新 `verification.json`。

**门禁 G4**：parity 最大差 <1e-4；nominal 不失锁；关键 RMS 变化有解释。

### P5（台架，1–2 周）：五端 T0

1. 逐组低电压扫频（6800 Hz 附近），记录其余组和 COM 的复数响应；确认组角/极性。
2. 测每组对 COM 电容、组间互容、COM 对壳/前端阻抗。
3. 测连续四路驱检复数馈通、COM 回流、开关注入、C/V 恢复。
4. 回填 `five_config` 的 `group_angles_deg`、`group_charge_gain`、`group_capacitance_F`、`Cds`、`drive_on_resistance_ohm`。

**门禁 G5**：实测矩阵替换假设后，连续版 RMS 与当前同量级；分时版 0.5 rad/s 异常消失或可解释。

### P6（持续）：文档与 Git

- 若 P0 发现组角/电容口径不符，先改 `codex_md/26` 的结论措辞，再改模型。
- 每次实测回填单独提交；代码与文档分开；推送 GitHub。
- 五电极结论只写“行为级 + 名义对称 + 假设电路”，不写“硬件验收”。
