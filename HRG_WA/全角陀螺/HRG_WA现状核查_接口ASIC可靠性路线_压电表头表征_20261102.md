## 0. 三句话结论

1. **MATLAB 模型是对的，但它是"平均慢变量 + 行为级接口"模型，不是物理场模型。** 我独立重跑 12 s 基线，**22.8 s 完成，全部关键指标与归档 `current_validation_summary.json` 逐位一致**（lockTime 1.619 s、rmsRateError 0.780544 °/s、energyMean 0.999886、quadRms 0.0129549、kalmanUpdate 12001…）。可复现性没有问题；**问题在默认配置里嵌了表头真值参数**（见 §1.4-C）。
2. **Simulink 已经把物理层补齐了，但版本之间物理域不一致。** v2–v9 是**电容式**（`Capacitive_CV_PGA_AA`），v10 才迁到**压电**（12 状态双向机电 + 驱动器 + 电荷放大器 + AFE，含负载反作用）。最新 `v10_2_cn_modular.slx` **因依赖库 `hrg_wa_v10_2_cn_modules` 不在路径上，干净会话打不开**。
3. **要成为可靠的接口 ASIC，当前最缺的不是算法，是三个硬件缺口**：①数字核只输出 3 路**慢速** DAC 码，**没有把 5 kHz 载波调制到驱动电极上**；②没有模拟前端（电荷放大/抗混叠/驱动级）；③没有时序约束、PPA、DFT/BIST 入 RTL、ESD/可靠性。详见 §2。

### 1.4 正确性判定：三级

#### A 级——可以下结论（已核对/已复现）

| 项 | 判据 | 结论 |
|---|---|---|
| 不变量代数 | 代入 `Cx=A cos2θ, Cy=A sin2θ, Sx=−q sin2θ, Sy=q cos2θ` 得 `R=(A²−q²)cos4θ, S=(A²−q²)sin4θ`，故 `atan2(S,R)/4 = θ` 精确成立；`Q=2Aq` 为正交量，`L` 与载波相位差成正比 | **正确** |
| Bryan 符号链 | 机械 `θ̇=−B(Ω+bias)+v+drift`，导航 `rawRate=−(θ̇−v)/B` → 两处负号抵消，符号自洽 | **正确**（V4.6.3 的符号修复有效） |
| 前端位真 | RTL vs MATLAB：350 笔×9 字段零差异；负向对照能被 `$fatal` 捕获 | **在给定输入集内成立** |
| 控制/导航 RTL | PI 5000 / DPLL 6000 / 导航 6000 / 控制器 3200 组，0 错；PI 与 MATLAB 最大差 1 LSB(Q30) | **成立，但"逐位"只到 1 LSB** |
| 闭环功能 | 锁定 1.619 s；能量相对误差 −1.1×10⁻⁴；正交 RMS 0.013；相位 RMS 0.005；无 ADC/DAC/定点溢出 | **成立** |
| 可复现性 | 本机 12 s 基线复现归档全部数字 | **成立** |

#### B 级——结构正确但有简化（做定量结论前必须改）

1. **频裂被两处同时表示。** `resonanceHz += 0.5·Δf·cos4(θ−axis)`（载波调频，L231）与 `quadDot` 里的 `−2Δω·E·sin4(θ−axis)`（L1174）是同一个物理量的两种注入；真实情况是**两模态频率不同 → 检测到的信号是两模态拍频/正交增长**，不是共同载波被调频。**风险：重复计入或互相抵消，导致频裂-正交-角度漂移的定量关系不可信。** 建议只保留 Q̇/R,S 方程，载波由两模态方程推出。
2. **θ 在一个控制周期内零阶保持。** 40 个 ADC 样本用同一个 `x.theta`（L235-236），等效于角度通道多了一个 0~1 ms 的阶梯滞后。做 ORE/动态研究前必须把 θ 按样本内插。
3. **抖动模型不是物理抖动。** `analog += jitterGain·|analog|·randn`（L263）是幅度比例噪声；真实时钟抖动的误差项正比于**载波导数**（即 90° 相移分量），应在 I/Q 上表现为正交方向的噪声。
4. **通道几何是隐含假设。** `idealI=[cos2θ; sin2θ]` 等价于**两对检测电极在电极角上相差 45°**（n=2 波型在空间上相差 90°）。若实际表头电极对是 0°/90°，模型必须重映射。
5. **反混叠不足。** AFE 一阶 12 kHz，在 `fs−f0 = 35 kHz` 处衰减只有 **−9.8 dB**。真实前端需要 ≥4 阶或带通，或提高采样率；否则带外模态/干扰会直接折回 5 kHz。
6. **CIC 下垂与群延迟没进环路预算。** 3 级 CIC(R=40) 在 500 Hz 处 **−11.8 dB**，群延迟 `3×39/2 = 58.5` 个 ADC 样本 = **1.46 ms**；加 FIR（2 ms）+ 控制流水（3 ms）+ DAC ZOH（0.5 ms）≈ **7 ms**。10 Hz 处相位滞后 25°，45 Hz 处 113°。**当前环路真正的延迟大头是 FIR 与控制流水，不是 CORDIC。**

### 1.5 一个重要的自我修正（我上一轮的创新点四要改）

上一轮我把"定点闭环的角度死区/极限环"列为创新点四。这次按实际字长算了一遍：

- 4θ 相位码 24 位 → `2π/2²⁴ = 3.75×10⁻⁷ rad`；折成角度 `÷4` → **θ 量化 LSB = 9.4×10⁻⁸ rad = 5.4×10⁻⁶ °**
- 不变量 32 位 Q8.24 → R/S 的 LSB ≈ 6×10⁻⁸，角度影响 ≈ 1.5×10⁻⁸ rad
- 死区 `δθ_min ≈ LSB/(4|V|)`，取有效门限 |V|=0.08 → **≈ 2.9×10⁻⁷ rad**
- 而模拟前端噪声折算到角度 ≈ **2.8×10⁻⁵ rad/样本**（见 §2.1 推导）

**死区比噪声底低约两个数量级。在当前字长下它不是真问题。** 只有把字长砍到 16 位、或能量掉到 |V|<10⁻³ 时才成立。所以创新点四应改向：**"闭环延迟与 CIC 下垂/群延迟"才是真正的实现级瓶颈**（≈7 ms，见 B6），这正好是创新点二（延迟透明）的入口。

同理，**"加大位宽"也不是当前该做的事**：18 位 ADC 的输入噪声约 16 LSB，有效位数只有 ~14 位；24 位相位码相对噪声有 300 倍余量。**当前瓶颈是系统误差与动力学，不是量化。**

## 2. 第二部分：要成为可靠的接口 ASIC，必须做到什么

### 2.1 第一步：把指标从"目标"变成"电路预算"

不要从"ARW 0.01 °/√h"直接跳到"ADC 要 20 位"。要走一遍数量级：

```
ARW = 0.01 °/√h
 → 1.67×10⁻⁴ °/√s = 2.9×10⁻⁶ rad/√s
 → 模式角噪声 = B × 2.9×10⁻⁶ = 0.277 × 2.9×10⁻⁶ = 8.1×10⁻⁷ rad/√Hz
 → 1 kHz 输出，每样本模式角噪声 = 8.1×10⁻⁷ × √1000 = 2.6×10⁻⁵ rad
```

反过来验证现有设置：ADC 输入白噪声 2.5×10⁻⁴（满量程 2），解调（40 样本匹配）后 ≈ `2.5×10⁻⁴×√(2/40) = 5.6×10⁻⁵`，`δθ≈δA/(2A)=2.8×10⁻⁵ rad` → 折算 **ARW ≈ 0.011 °/√h**。
**结论：模型当前的噪声设置本身就落在 0.01 °/√h 量级；而仿真速率 RMS 0.78 °/s 是含动态与系统误差的时域量，两者不能直接比。** 也就是说：**你的噪声预算已经够用，系统性误差比噪声底高约 40 dB。** 这句话应该写进所有论文的问题陈述里。

必须冻结的合同（缺一项都可能返工）：

| 项 | 建议值/来源 | 为什么必须先定 |
|---|---|---|
| 谐振频率 f₀、Q、频裂 Δf | **待测**（见 §3） | 决定 DPLL 捕获范围、CIC 抽取比、环路增益、噪声带宽 |
| 采样率 fs / 控制率 fc | 40 kS/s / 1 kHz（现有）；建议 fc 提到 2 kHz 或把流水降为 1 拍 | 决定延迟预算与 CIC 参数 |
| 系统时钟 | 实测约束，不是假设（现有研究用 50 MHz 举例） | 决定分时复用余量（每采样 1250 周期） |
| 角速率量程 / 带宽 | ±500 °/s、≥100 Hz，需与 B 和延迟一起核算 | 延迟 7 ms 时 100 Hz 已不可行 |
| ADC/DAC | 18 bit / 16 bit（现有） | 需要 AAF 阶数、满量程、电荷量程配合 |
| 电源/工艺 | 未定（0.18 μm BCD 是开题设想） | 高压驱动、电荷放大、ESD 都依赖它 |
| 工作温度 | 未定（−40~150 ℃ 是开题目标） | 决定 trim 范围与温补策略 |

### 2.2 三个必须补的硬件缺口（按优先级）

**缺口 1（最关键）：驱动载波调制不存在。**
现在数字核只输出三路**慢变** DAC 码（能量/正交/虚拟进动），而压电表头必须被 **5 kHz 载波**驱动。也就是说 `u_E(t) = u_E·cos(ω̂t) + u_Q·sin(ω̂t)` 这一步在系统里**没有归属**。两条实现路线：

| 方案 | 做法 | 代价 | 风险 |
|---|---|---|---|
| A. 数字域调制 | 用现成 NCO 的 cos/sin 乘慢命令，DAC 直接在 40 kS/s 输出调制波（2 路或 4 路） | 2–4 个乘法器 + DAC 速率×8 | DAC 需要 40 kS/s（现有 1 kHz 合同要改）；载波量化噪声进驱动 |
| B. 模拟域调制 | DAC 输出慢命令，模拟乘法器/开关解调器与外部载波相乘 | 模拟乘法器相位误差、增益非线性 | 相位误差直接变成正交/能量串扰 |

**这是全系统第一优先级的架构决策**，而且它决定了虚拟进动能不能物理实现（见缺口 1b）。

**缺口 1b：虚拟进动怎么加？** 模型里它是第三路独立输入。物理上只能用同样两对驱动电极、按驻波角分配力与相位合成。所以需要一张 **(u_E, u_Q, u_V) → 各电极电压/相位** 的映射矩阵，并证明它与 `drive.crossMatrix` 的 2×2 抽象一致。现有 RTL/模型都没有这张表。

**缺口 2：模拟前端完全缺失。** 需要：电荷放大（压电是电荷源，不是电容变化）→ 直流伺服/交流耦合 → 抗混叠（按 §1.4-B5 至少 4 阶）→ 18 位 ADC；驱动侧需要高压/大摆幅放大 + 电流能力 + 负载反作用核算。

**缺口 3：工程签核全部缺失。** 时序约束、完整映射与布局布线、功耗活动率、CDC/RDC 签核、DFT（scan/MBIST）、ESD/latch-up、封装模型。

## 3. 第三部分：厂商保密时，压电表头怎么测、能测出什么

### 3.1 核心立场（先说清楚边界）

**把表头当成"一个 N 端口电网络 + 一个双模态机械系统"。** 端子上能测的是**输入输出关系**；不能测的是**内部几何/材料**和**极限值**。这不是妥协——设计闭环只需要前者。

工程根目录已有 `V10压电表头_无厂家参数的测试辨识与回填方案.md`（2026-10-29），理论部分（BVD 等效、尺度不可辨识反例、ring-down 的 IQ 回归、导纳回归、负载反作用、位移标尺、Bryan 与死区）**是对的，可以直接用**。本节把它变成**可执行的台架协议**，并补上它自己承认缺的四项：不确定度、全端口矩阵、温度模型、端口极性验证。

一个必须先讲清的数学事实（文件里已有，这里复述以便你向导师解释）：

```
Y(s) = G0 + sC0 + sΘ²/(ms²+cs+k)
```
令 `m'=λ²m, c'=λ²c, k'=λ²k, Θ'=λΘ`，则 `Y(s)` **完全不变**。所以**扫频拟合再完美也不能唯一确定 m、Θ、c、k**。能唯一确定的是 `κ=Θ²/m`、`γ=c/(2m)`、`ω0`、`C0`、`G0`，以及 BVD 的 `Lm=1/κ`、`Rm=2γ/κ`、`Cm=κ/ω0²`。**任何声称"从阻抗扫频得到模态质量和压电常数"的说法都是错的**，除非加一个独立位移标尺。

### 3.2 能测出来的 12 类参数（表）

| # | 参数 | 符号/单位 | 测法 | 关键公式 | 用途 | 典型精度 |
|---:|---|---|---|---|---|---|
| 1 | 静态电容 | C₀ [F] | LCR/阻抗分析仪，频率 ≪ f₀/10 | 由 `Im(Y)/ω` 取平台值 | 电荷放大增益、量程 | 1% |
| 2 | 漏电/介损 | G₀ [S]、tanδ | 同上，低频段 | `G₀=Re(Y)`；`tanδ=G₀/(ωC₀)` | 直流伺服、噪声 | 10% |
| 3 | 两模态频率 | f₁, f₂ [Hz] | 细扫频 + 相位过零 | 导纳实部峰 / 相位过零 | DPLL 捕获、CIC 抽取比 | 0.1 Hz |

### 3.3 测不出来、必须向厂商确认的东西（不能猜）

| 项 | 为什么不能测 | 如果厂商不给怎么办 |
|---|---|---|
| **引脚定义/极性/是否内置前置** | 接错可能烧表头或去极化 | **必须拿到**。拿不到就先做 §3.4 的无源判别（不激励大信号） |
| 最大驱动电压/耐压 | 小信号测试推不出击穿 | 只用"经确认的安全电压"做小信号；把结论限定在该电压内 |
| 最大振幅/应变/疲劳寿命 | 破坏性 | 不用"寿命"下任何结论；只报"在已测幅度内" |
| 真空/封装/安装预紧要求 | 需要工艺信息 | 按厂商要求的封装条件测；不满足就说明测的是"该条件下的"参数 |
| 工作温度范围 | 需要材料/胶层信息 | 只在温箱实际覆盖的区间内给结论，不外推 |
| 是否需要 DC 偏置 | 压电通常不需要，但极化状态未知 | 先做小信号 DC 扫描（±1 V）看是否有迟滞/回滞，再决定 |

**红线：正常小信号响应不能证明最大耐压、疲劳寿命或极限振幅。** 任何"全工作区安全"的结论都必须有厂商边界或你自己的破坏性试验，不能从拟合参数推出。

### 3.4 无源判别：只用电表/阻抗分析仪就能确定的事（T0）

这一步不加大信号，最安全，先做：

1. **判断是否内置前置**：测 |Z| 与相位 @1 kHz。
   - 裸压电：`|Z| ≈ 1/(ωC₀)`，相位 ≈ −90°，C₀ 在 0.1–10 nF 量级。
   - 内置前置：|Z| 明显偏低且相位接近 0，或存在直流偏置/供电脚。
2. **判断端口数/分组**：两两测电容矩阵 `C_ij`。
   - 对角元是各电极对壳地的电容；非对角元反映共地/共用电极。
   - 若 `C_ij/C_ii > 0.5`，很可能是**同一电极的不同分段**或共地结构。
3. **判断驱动/检测归属**：通常压电表头两种电极在几何上不可区分，只能靠**谐振响应相位**（同相/反相 0°/180°）和**互易性**判断；不要靠颜色或位置猜。
4. **互易性检查**：`Y_jk ≈ Y_kj`。偏差大 → 接线/极性错，或存在内置有源电路。

判据：若 C 矩阵对称且互易性误差 <5%，可以认为是被动压电网络，进入 T1。

### 3.5 分步台架协议（T1–T7）

| 步 | 做什么 | 接线/设置 | 记录 | 判据 / 失败处理 |
|---|---|---|---|---|
| **T1** | 端口导纳扫频 | 信号源 + 已知串联电阻 `R_ref`（建议 1 kΩ，1% 金属膜）+ 双通道锁相/示波器；先开路/短路/已知 RC 校准测量链 | 每个端口的 `f, V_p, V_R` 复数；夹具开短路记录 | `Y=V_R/(R_ref·V_p)`；共振峰应出现在 1–10 kHz；若相位基准偏 >2° 先重校夹具 |
| **T2** | 全端口复响应矩阵 | 逐个端口小信号激励（≤10 mV），其余端口接**近短路**（电荷放大输入）或已知负载 | N×N 的 `Y_jk(f)`，含相位 | 矩阵秩、条件数；互易性；非对角元给出串扰与直通 |
| **T3** | ring-down | 在 f₀ 激励到稳态后**快速断开**（FET 开关），连续采样≥10τ | 原始载波或 IQ（保留参考频率）、开关时刻、采样率 | `Q=πf₀τ_A`；两模态近时用双指数拟合；残差 >5% 说明有第二模态 |
| **T4** | 多负载重复 T1/T3 | 换 2–3 个已知检测负载 `R_L`/`C_L` | 同 T1/T3 | 区分裸机械阻尼与电负载反作用（§3.7）；**不能把带载 γ 直接当裸阻尼** |
| **T5** | 电学标度 + 位移标尺 | 已知电容 `C_cal` 注入电荷测前端复增益；有条件时加 LDV/电容测微 | 前端增益/相位；壳上位移（测点、方向） | 无位移标尺 → **只报 κ、γ、ω₀、BVD，不报 m、Θ** |
| **T6** | Bryan 与低速死区 | 转台（他们已有温控转台），正反转、5–6 档速率（含 ±0.01、±0.1、±1、±10 °/s）、多初始方位 | 参考角 `Ψ_ref(t)`、解调 IQ、控制命令 | `θ−θ₀=−B(Ψ_ref−Ψ₀)`；低速段若驻波不动先判"锁定/死区"，不能判 B≈0 |
| **T7** | 温度与留出验证 | 温箱：恒温、升温、降温、驻留、再启动；不同速率 | f、Q、C₀、零偏 vs T | 用整段轨迹做留出，不随机打散；报外推失效区 |

**仪器最小集**（按你实验室现有设备）：信号源 + 示波器（≥2 通道，带 FFT）+ 动态频谱分析仪 + 精密电阻 + 转台 + 温箱。
**完整集**：阻抗分析仪（或锁相放大器）、LDV、精密电容箱、低噪声电荷放大器评估板。

### 3.6 三个关键公式（照抄可用）

**导纳回归（透明线性最小二乘）**
由独立 ring-down 得 `ω₀, γ`，令 `s_l=jω_l`、`D_l=s_l²+2γs_l+ω₀²`，则
```
Y_l = G₀ + s_l·C₀ + (s_l/D_l)·κ
```
设计矩阵三列 `[1, s_l, s_l/D_l]`，实虚部上下堆叠，列归一化后解实最小二乘，**必须同时报残差、秩、条件数**。只画拟合曲线不算。

**ring-down 的 IQ 回归**
`z_{k+1} = ρ z_k`，`ρ = Σ z_k* z_{k+1} / Σ|z_k|²` → `γ=−ln|ρ|/Δt`、`ω_d=arg(ρ)/Δt`、`ω₀=√(ω_d²+γ²)`。
注意：解调后几 Hz 的残余频率要**加回参考频率**；采样要满足相位无混叠。

**负载反作用（避免重复计入）**
`ΔZ = Θ_s² s/(Y_L+sC_s)`；标量负载 `Y_L=G` 时
`Δk = Θ_s²ω²C_s/(G²+ω²C_s²)`，`Δc = Θ_s²G/(G²+ω²C_s²)`。
所以换了前端，频率和 Q 都会变——**带载测的 Q 不能直接回填成裸机械 Q**。

### 3.8 数据与不确定度规范（每条参数都要带）

```
参数名 | 值 | 单位 | 参考面(开路/短路/近短路) | 频带 | 激励幅度 | 温度 | 重复次数 | 95% 置信区间 | 可辨识状态
```
**可辨识状态**只有三种：`identified`（有独立标尺或唯一解）、`bounded`（只能给区间）、`not-identifiable`（落在规范自由度里，例如 m 与 Θ 的尺度）。
**禁止**把 `not-identifiable` 写成 `identified`；这正是已有文档 §3 的反例要防的事。

2. **定驱动调制方案**（数字 vs 模拟），并补 (u_E, u_Q, u_V) → 电极的映射矩阵。这是全系统第一优先级的架构决策。
3. **拿表头做 T0–T3**（两周计划）。在拿到 f₀/Q/Δf 之前，所有电路指标都是猜的。
4. **把延迟合同写死**：7 ms 的总延迟里 FIR 占 2 ms、控制流水占 3 ms，先砍流水再加带宽。
5. **Simulink 库依赖修好**，让 `v10_2_cn_modular` 在干净会话能打开；否则半年后连你自己都跑不起来。
6. **把 SELFTEST 从 MATLAB 搬进 RTL**，并让 `passFaultSafety` 变成 1。这是"可靠"二字的最低门槛。
