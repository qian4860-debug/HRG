# 跨资料库压电/全角相关一级引用筛查

完成核验：564条筛入候选引用对应377个Zotero题录条目，新建266个、复用111个。187条跨母论文重复引用仍保留关系。校验入口：`python research/all_piezo_cited_20261029/check_delivery.py`。这是自动初筛候选导入完成，不是所有文件的全文科学相关性复核完成。

范围：D盘全角陀螺资料目录及Zotero storage中可访问PDF，按SHA去重。本轮扫描242个字节对象，通过开篇筛查与DOI题名核对取得47篇母文献的1371条出版方登记参考文献；被引文献按DOI补查题录后，再按题名/原引文筛选候选。

这是自动化相关性初筛，不是全部文献逐篇通读。候选包括直接相关及可借鉴的压电换能、模态、全角和振动陀螺方法；不能将所有候选视为已证明适用于压电半球全角。无DOI、扫描件、未匹配母文献以及尚未取得的正文仍有覆盖缺口。

`parents.json`保存母文献路径及出版方参考文献记录；`selected_edges.json`保存筛入候选与母文献的对应关系。未选中或未解析的引文保存在忽略的本地工作目录，不据此判断其一定无关。
