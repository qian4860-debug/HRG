运行18个预先声明的合成工况。使用原质量面板完全相同的计算和门限；每个工况输出同版式PNG、中文文字面板、HTML、逐帧CSV及JSON。原模型只在内存中修改参数，运行结束不保存，不覆盖用户现有质量报告。

全部工况及原始参数见`stress_cases.m`和`evidence/cases.json`：

- 基线：0.5rad/s、无额外白噪声、零频裂/阻尼不均匀。
- ADC输入白噪声：5μV每采样RMS，3个独立种子；另测50μV、500μV。不是V/√Hz，也没有代替真实AFE有色噪声模型。
- 输入角速度：0、+0.05、−0.5、+2rad/s；每次为恒定角速度，不是同次仿真的角速度阶跃。
- 模态频裂：0.001、0.01Hz，刚度主轴0.61rad。
- 本征阻尼半差：0.0002、0.002/s，阻尼主轴−0.29rad；保持平均阻尼不变。
- 检测或驱动标定：两通道±1%增益、±0.5°相位误差；只改变控制器使用的标定，不改变plant真值。
- 组合等级1：5μV、0.001Hz频裂、0.0002/s阻尼半差、检测标定±0.1%/±0.05°；等级2将这四类误差各放大10倍。组合点输入仍为0.5rad/s。

## 统一判定

源窗口中心评分，每个完整帧只计一次；后40%有效帧用于稳态统计。有效率≥95%，平均能量偏差<5%，正交及锁相检测残差RMS各<1e-3，机体角度RMS<0.1°，时间戳偏差<1e-6μs，无DAC截幅。没有调整原门限，没有真值偏置/延迟拟合。

质量门限未通过不等于仿真执行失败。所有质量失败点、失败项和图表均保留；另对每个工况核对Simulink与MATLAB逐拍执行一致性。源码中的复数标定按实部/虚部分开记录，避免JSON丢失相位信息。

## 查看结果

打开`evidence/index.html`：先查看对比图和总表，再点击工况进入同一质量面板。`summary.csv`可用于后续筛选，`all_results.json`含全部报告及参数，`scoreboard.json`记录18个执行一致性结果。

Python/NumPy执行`check_delivery.py`，从每个工况CSV独立复算能量、正交、锁相、角度RMS及时间戳单位，重新判定固定门限，核对源模型未改变。`--seal`只在明确审查交付后使用。

本次是0.8s合成离散点检查，不是完整笛卡尔积、极限搜索、噪声概率认证或硬件验收。不能从3个噪声种子推断置信区间，也不能从短记录宣称ARW、长期零偏或含各向异性时的低速全范围性能。真实表头仍需独立实测参数及台架验证。
